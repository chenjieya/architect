## 1. Linux用户分类

### 1.1 系统用户

- **UID范围**：0 和 1~999
- **root用户**：UID为0，拥有最高权限
- **系统进程用户**：UID 1~999，用于系统服务进程，不能用于登录系统。

`id root` 查看用户ID、 初始组、 附加组
![image.png](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/20251118171147642.png)

### 1.2 普通用户

- **UID范围**：1000~65536
- 用于日常操作和普通应用程序

> 创建用户会默认也创建一个和用户同名的组。

## 2. 用户配置文件

### 2.1 /etc/passwd 文件

存储用户基本信息，但不包含密码。

**文件格式示例：**

```
root:x:0:0:root:/root:/bin/bash
```

**各字段含义：**

- **用户名**：用户登录名
- **密码占位符**：x表示密码存储在/etc/shadow文件中
- **UID**：用户ID
- **GID**：主组ID
- **描述信息**：用户全名或描述（通常无意义）
- **家目录**：用户的主工作目录
- **Shell环境**：用户登录后使用的shell
  - `/bin/bash`：可登录的bash shell
  - `/sbin/nologin`：禁止登录
  - `/bin/false`：禁止登录

## 3. 用户管理命令

### 3.1 创建用户

```bash
# 基本创建用户
useradd username

# 创建用户时指定详细信息
useradd -g groupname -d /home/username -s /bin/bash -e 2015-07-01 username
```

**参数说明：**

- `-g`：指定主组
- `-d`：指定家目录
- `-s`：指定shell环境
- `-e`：设置账号过期时间

### 3.2 设置用户密码

```bash
# 交互式设置密码
passwd username

# 非交互式设置密码
echo "password" | passwd --stdin username
```

### 3.3 修改用户信息

```bash
# 修改账号过期时间
usermod -e 2024-12-31 username

# 查看用户密码信息
chage -l username
```

### 3.4 删除用户

```bash
# 删除用户及其家目录
userdel -r username
```

> **注意：** `-r`参数会同时删除用户的家目录。家目录很重要，`history`等历史记录都存在家目录下面

## 4. 用户组管理

### 4.1 创建和删除用户组

```bash
# 创建用户组
groupadd groupname

# 删除用户组
groupdel groupname
```

> **注意：** 当组中有关联用户时，无法删除该组

### 4.2 修改用户组关系

```bash
# 修改用户的主组（会移除原来的附加组）
usermod -g groupname username

# 修改用户的附加组（会覆盖原来的附加组）
usermod -G groupname username

# 同时指定多个附加组
usermod -G testalvis,testgroup testuser
```

## 5. 权限管理

### 5.1 权限表示方法

**权限位说明：**

```
l r w x r w x r w x
│ │ │ │ │ │ │ │ │ │
│ │ │ │ │ │ │ │ └── 其他用户执行权限 (others execute)
│ │ │ │ │ │ │ └─── 其他用户写权限 (others write)
│ │ │ │ │ │ └───── 其他用户读权限 (others read)
│ │ │ │ │ │
│ │ │ │ │ └─────── 所属组执行权限 (group execute)
│ │ │ │ └───────── 所属组写权限 (group write)
│ │ │ └─────────── 所属组读权限 (group read)
│ │ │
│ │ └───────────── 所属用户执行权限 (user execute)
│ └─────────────── 所属用户写权限 (user write)
└───────────────── 所属用户读权限 (user read)
│
└───────────────── 文件类型标识
```

**文件类型标识：**

- `-`：普通文件
- `d`：目录
- `l`：符号链接
- `s`：socket文件
- `p`：pipe文件
- `b`：块设备文件
- `c`：字符设备文件

### 5.2 权限修改方法

#### 5.2.1 字符表示法

```bash
# 添加执行权限
chmod u+x filename

# 移除写权限
chmod g-w filename

# 设置特定权限
chmod u=rwx,g=rx,o=r filename

# 清空所有权限
chmod u=- filename
```

**权限标识符：**

- `u`：用户（user）
- `g`：用户组（group）
- `o`：其他用户（others）
- `a`：所有用户（all）

**权限操作符：**

- `+`：添加权限
- `-`：移除权限
- =: 设置权限（覆盖原有权限）

#### 5.2.2 数字表示法

```bash
# 设置完全权限 (rwxrwxrwx)
chmod 777 filename

# 设置用户可读写执行，组可读执行，其他无权限 (rwxr-x---)
chmod 750 filename
```

**权限数值：**

- `r`（读）= 4
- `w`（写）= 2
- `x`（执行）= 1

## 6. 所有权管理

### 6.1 修改文件所有者

```bash
# 修改文件所有者
chown username filename

# 递归修改目录及其内容的所有者
chown -R username directory

# 同时修改所有者和所属组
chown username:groupname filename
```

### 6.2 修改文件所属组

```bash
# 修改文件所属组
chgrp groupname filename

# 递归修改目录及其内容的所属组
chgrp -R groupname directory
```

## 9. 权限匹配规则

**重要权限匹配顺序：**

1. **用户权限**：如果文件属于当前用户，直接应用用户权限
2. **组权限**：如果文件不属于当前用户但当前用户属于文件所属组，应用组权限
3. **其他用户权限**：以上都不满足时，应用其他用户权限

**注意：** 权限匹配具有优先级，一旦匹配成功就不会继续向后匹配。

## 10. umask权限掩码

### 10.1 umask作用

umask用于设置新建文件和目录的默认权限。

### 10.2 计算方法

```bash
# 查看当前umask值
umask

# 目录默认权限 = 777 - umask
# 文件默认权限 = 666 - umask（自动去掉执行权限）
```

**示例：**
如果umask为0022：

- 目录权限：777 - 022 = 755 (rwxr-xr-x)
- 文件权限：666 - 022 = 644 (rw-r--r--)

## 11. 文件隐藏属性

### 11.1 chattr命令

```bash
# 添加不可修改属性
chattr +i filename

# 移除不可修改属性
chattr -i filename
```

**i属性效果：**

- 不能修改文件内容
- 不能删除文件
- 不能重命名文件
- 不能创建软链接
- 不能修改文件权限

## 12. 重要提示

1. **家目录重要性**：用户的`history`等历史记录都存储在家目录中
2. **用户创建默认行为**：创建用户时会自动创建一个同名的用户组
3. **权限操作谨慎**：使用`-R`参数递归修改权限时要特别小心
4. **系统用户保护**：不要随意修改系统用户的属性和权限
