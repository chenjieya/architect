## 1. 概述

Java 是**静态类型、强类型**语言：变量要先声明类型，类型不匹配会在**编译期**报错。本节先弄清这类语言的特点，再掌握**成员变量**与**局部变量**的区别、八种基本类型与 `String` 引用类型，以及默认值规则。

## 2. 核心概念

### 2.1 Java 是什么类型的语言（本课必知）

| 术语                              | 说明                                                                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **静态类型**（Statically typed）  | 变量**声明时就要写类型**（如 `int age`），类型在编译期确定；改存别的类型要换变量或强转，不能 `int x = 1` 后再 `x = "hi"` |
| **动态类型**（Dynamically typed） | 变量类型在**运行期**才根据赋值决定；Python、JavaScript 典型（JS 用 `let` 时同一变量可先后指向不同类型）                  |
| **强类型**（Strongly typed）      | 类型**不匹配的操作**会被语言拒绝（或要求显式转换）；如 Java 不允许 `int + "abc"` 直接相加                                |
| **弱类型**（Weakly typed）        | 运算时容易发生**隐式类型转换**；如 JavaScript 中 `"1" + 2` 得到 `"12"`                                                   |

**易混说明（不要搞反）**：

| 维度        | Java                   | Python / JS（典型）             |
| ----------- | ---------------------- | ------------------------------- |
| 静态 / 动态 | **静态**：先写 `int`   | **动态**：`x=1` 再 `x="a"` 可以 |
| 强 / 弱     | **强**：类型错在编译期 | JS **弱**：字符串与数字常自动拼 |

「**静态**」在这里指 **类型写死在源码里**，不是指「程序不能动」；「**编译型 / 解释型**」是另一套分法（Java 源码经 `javac` 编译成字节码，再由 JVM 执行），与本表的「静态类型」**不是同一个词**。

### 2.2 变量放在哪：成员变量 vs 局部变量

| 术语                            | 说明                                                                                                                                                                              |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **成员变量**（Member variable） | 写在**类体里、方法外面**的变量，也叫**字段（field）**；属于「对象或类的一份数据」。本课示例里未写 `static` 的称为**实例成员变量**；写了 `static` 的称为**类变量（静态成员变量）** |
| **局部变量**（Local variable）  | 写在**方法里**或 **`{ }` 块里**的变量（含**方法参数**）；只在当前方法/块执行期间存在，出了范围就不能用                                                                            |
| **生命周期**                    | 成员变量随对象或类存在而存在；局部变量在方法/块**进入时创建、离开时销毁**                                                                                                         |
| **默认值**                      | **成员变量**未手动赋值时，Java 给默认值（`int`→0 等）；**局部变量没有默认值**，使用前必须自己赋值                                                                                 |

| 对比项       | 成员变量                                             | 局部变量                   |
| ------------ | ---------------------------------------------------- | -------------------------- |
| 声明位置     | 类 `{ }` 内、方法外                                  | 方法内或 `if`/`for` 等块内 |
| 谁在用       | 整个类的多个方法都可访问（受访问修饰符限制，后续学） | 通常只在声明它的方法/块内  |
| 未赋值能否用 | 有默认值，可读（引用为 `null` 时调用方法会出错）     | **不能**，编译器要求先赋值 |
| 本课示例     | `TypeDemo` 里的 `count`、`flag`                      | `main` 里的 `age`、`x`     |

**实例成员变量与对象**：未写 `static` 的成员变量在 **实例化**（`new 类名()`，后续面向对象章展开）后，成为**该对象自己的属性**，每个对象各有一份。写了 `static` 的成员变量属于**类**，全类通常共享一份，不是每个对象各拷贝。

**类外、类定义之前能否定义变量**：**不能**。在 `class { }` 之外（无论在类**前面**还是**后面**）写 `int x = 1;` 均会编译错误。类之前只允许 `package`、`import` 等，然后是类定义；变量只能写在 **类里方法外**（成员变量）或 **方法/块内**（局部变量）。

### 2.3 类型与字面量

| 术语                  | 说明                                                                          |
| --------------------- | ----------------------------------------------------------------------------- |
| 基本类型（Primitive） | 直接存值的类型，共 **8 种**                                                   |
| 引用类型（Reference） | 变量存**对象引用**（可理解为指向堆中对象的地址），如 `String`、数组、自定义类 |
| 整型                  | `byte`、`short`、`int`、`long`                                                |
| 浮点型                | `float`、`double`                                                             |
| 字符型                | `char`，表示单个 Unicode 字符                                                 |
| 布尔型                | `boolean`，仅 `true` / `false`                                                |
| 字面量后缀            | 长整型加 `L`，单精度浮点加 `f`（如 `3.14f`）                                  |

### 2.4 八种基本类型（范围与占用，了解即可）

| 类型      | 字节（约） | 取值范围（要点）                         |
| --------- | ---------- | ---------------------------------------- |
| `byte`    | 1          | -128～127                                |
| `short`   | 2          | 约 ±3 万                                 |
| `int`     | 4          | 约 ±21 亿，**最常用整型**                |
| `long`    | 8          | 更大整数，字面量常写 `100L`              |
| `float`   | 4          | 单精度，字面量需 `f`                     |
| `double`  | 8          | 双精度，**默认小数类型**                 |
| `char`    | 2          | 单个字符，如 `'A'`、`'中'`               |
| `boolean` | JVM 相关   | 仅 `true` / `false`，**不能与 0/1 互换** |

`String` **不是**基本类型，是**引用类型**的类；`"hello"` 是字符串字面量。

## 3. 语法与写法

```java
public class TypeDemo {
    // ========== 成员变量（字段）：在类里、方法外 ==========
    int count;           // 实例成员变量，默认 0
    boolean flag;        // 默认 false
    String name;         // 引用类型成员，默认 null
    double price;        // 默认 0.0

    public static void main(String[] args) {
        // args 也是 main 的局部变量（参数）

        // ========== 局部变量：在方法里 ==========
        int age = 18;              // 声明类型 int → 静态类型
        long id = 20260001L;
        double score = 95.5;
        float rate = 0.15f;
        char grade = 'A';
        boolean passed = true;
        String message = "及格";   // 引用类型局部变量

        // age = "十八";           // 错误：强类型，不能把 String 赋给 int

        // 局部变量必须先赋值再用
        // System.out.println(x);  // 错误：x 未初始化
        int x = 1;

        // 成员变量可通过 对象.成员 访问；在 main 里演示需先有对象（后续面向对象章展开）
        // 此处仅演示局部变量与成员变量「写在哪」不同
        System.out.println(age + " " + message);
    }
}
```

### 3.1 如何一眼区分

```text
class TypeDemo {
    int count;              ← 成员变量（类的大括号内、任何方法之外）
    public static void main(...) {
        int age = 18;       ← 局部变量（在某个方法的大括号内）
        if (...) {
            int blockVar;   ← 也是局部变量（在 if 的块里）
        }
    }
}
```

### 3.2 引用类型初识

```java
String s1 = "Java";
String s2 = s1;
s2 = "Python";   // s1 仍为 "Java"，s2 指向新对象
```

多个引用变量可指向同一对象（后续章节再深入内存图）。

## 4. 常见用法

1. **整数默认用 `int`**，不够再用 `long`
2. **小数默认用 `double`**，需节省或明确单精度时用 `float`
3. **文本用 `String`**，不用 `char` 拼整句（单字符才用 `char`）
4. **金额等精确计算**：本课先用 `double` 入门；高精度用 `BigDecimal`（后续课程）

## 5. 易错点

- **把「静态类型」理解成「程序不能动」**：静态类型指**类型在写代码时确定**；与编译型/解释型是不同概念
- **成员变量与局部变量规则混用**：以为 `main` 里 `int x;` 也有默认值 → 局部变量**必须赋值**
- **从 Python/JS 来，省略类型**：Java **必须**写 `int age`，不能写 `age = 18` 让编译器猜
- **在类外写变量**：像 Python 模块顶层 `x=0` 在 Java 非法；须写在类中（成员）或方法中（局部）
- **在 `main` 里直接用实例成员**：`main` 是静态方法，访问实例成员前通常要先有对象（后续章练习）
- **整数默认是 `int`**：超过 `int` 范围的字面量要写 `L`，如 `3000000000L`
- **小数默认是 `double`**：赋给 `float` 必须加 `f`，如 `3.14f`
- **局部变量未初始化就使用**：编译错误 `variable x might not have been initialized`
- **把 `boolean` 当 0/1**：Java 不允许 `if (1)`，必须 `if (true)` 或布尔表达式
- **`char` 用双引号**：`"A"` 是 `String`，`'A'` 才是 `char`

## 6. 本节小结

- Java：**静态类型**（先声明类型）+ **强类型**（类型错编译不过）；别与「编译型」混为一谈
- **成员变量**在类里、有默认值；**局部变量**在方法/块里、**必须显式赋值**
- 8 种基本类型 + `String` 等引用类型；日常整数 `int`、小数 `double`
- `long`/`float` 字面量注意 `L` / `f` 后缀
