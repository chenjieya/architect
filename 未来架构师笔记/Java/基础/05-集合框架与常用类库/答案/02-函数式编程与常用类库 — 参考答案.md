## 2. L2 原理应用

### 2.1

**答**：

1. **现象**：无业务输出。
2. **Stream 阶段**：只写了中间操作 `filter`、`map`，未调用终端操作。
3. **结论**：中间操作惰性，须补充终端操作，如 **`collect(Collectors.toList())`** 或 **`forEach`**。

### 2.2

**答**：

1. Lambda 必须依赖 **函数式接口** 类型（赋值左侧或方法参数类型）。
2. 该接口有且仅有 **一个抽象方法**（可有 default/static 方法）。

### 2.3

**答**：

- **`ofNullable(null)`** → 得到 **empty**，不抛异常。
- **`of(null)`** → 抛出 **`NullPointerException`**。

### 2.4

**答**：

1. **原因**：实际分隔符为 `/`，与 pattern 中的 `-` 及整体格式不一致。
2. **正确 pattern**：`yyyy/MM/dd HH:mm:ss`（或与实际字符串完全一致的格式）。

### 2.5

**答**：

1. **原因**：写入时若未指定 **UTF-8**，可能使用系统默认编码；记事本按另一编码打开导致乱码。
2. **修复**：读写均使用 **`StandardCharsets.UTF_8`**（`Files.write` / `Files.readAllLines` / `newBufferedReader` 均指定）。

### 2.6

**答**：

1. 在遍历 **同一 `orders` 流** 的同时向 **`orders` 添加元素**，逻辑混乱且可能引发 **并发修改** 或无限增长等问题。
2. 应 **`collect(Collectors.toList())`** 收集到新列表，或先 collect 再赋值，**不要**在 forEach 中修改被流化的源集合。

### 2.7

**答**：

- **`Period.ofMonths(12)`**：**日历日期**间隔 → **会员到期**（`memberExpire`）。
- **`Duration.ofHours(2)`**：**时间长度**间隔 → **会议结束**（`end`）。

### 2.8

**答**：

1. **现象**：50 元素 parallel 更慢。
2. **推理**：`parallelStream` 有 **线程创建、任务拆分与合并** 开销；数据量很小时计算量不足以摊平开销。
3. **结论**：默认使用 **串行 `stream()`**；仅大数据且压测验证收益后再用 parallel。

### 2.9

**答**：

- **有值时**：`orElse` 与 `orElseGet` **都不会** 使用默认值分支；`expensiveDefault()` **不会** 因 Optional 无值而执行。
- **注意**：`orElse(expensiveDefault())` 在 **调用 orElse 前** 就会先计算实参（若写成方法调用），与 `orElseGet` 的延迟不同；题目若强调「无值才计算」，应选 **`orElseGet`**。

### 2.10

**答**：try-with-resources 在 try 块结束或异常时 **自动关闭资源**，并妥善处理 **关闭时的次要异常**，避免泄漏与手动 finally 遗漏。

## 3. L3 场景实战

### 3.1 [面试]

**答要点**：

- 函数式接口：**仅一个抽象方法** 的接口。
- Lambda 简化 **匿名内部类** 的冗长写法。
- 场景：**`Comparator.comparing(Student::getName)`** 排序，或 **`LambdaDemo`** 中 `StringProcessor`。

### 3.2 [面试]

**答要点**：

- **中间操作**（filter/map）**惰性**，只建管道；**终端操作**（collect/forEach）**触发执行**。
- 只有中间操作时 **流水线未执行**，故无结果输出。

### 3.3 [面试]

**答要点**：

- **`of`**：值**必非 null**。
- **`ofNullable`**：值可能 null，null → empty。
- **`empty`**：明确无值。
- **`get()`** 无值抛异常；应用 **orElse / orElseGet / ifPresent**。

### 3.4 [面试]

**答要点**：

- **LocalDate**：仅日期；**LocalTime**：仅时间；**LocalDateTime**：日期+时间（无时区）。
- **Period**：日历间隔（月、年）；**Duration**：时间长度（小时、分钟）。

### 3.5 [面试·扩展]

**答要点**：

- 收益场景：**数据量大**、计算**较耗时**、已**压测**验证。
- 初学默认串行：小数据 **线程开销 > 收益**，易变慢且难排查。

### 3.6 [面试]

**答要点**：

- try-with-resources：**自动 close**，防资源泄漏。
- UTF-8：避免 Windows **默认编码** 与读写不一致导致 **中文乱码**。

### 3.7 [工作]

**答要点**：

- `orders.stream()`
- `.filter(o -> "PAID".equals(o.getStatus()))`（或等价）
- `.map(Order::getOrderNo)`
- `.collect(Collectors.toList())`

### 3.8 [面试]

**答要点**：

- **`Student::getName`** 是 **方法引用**。
- 与 Lambda 等价，都是提供 **比较所需键** 的简写；`comparing` 内部用方法引用生成 Comparator。

### 3.9 [面试]

**答要点**：

- **`readAllLines`**：小到中等文件，一次性载入内存。
- **`BufferedReader`**：较大文件，**逐行**、内存友好。
- 相对路径在 IDEA 运行通常相对 **项目根目录**。

### 3.10 [工作]

**答要点**：

- **`ifPresent(n -> ...)`** 有值打印欢迎语。
- 无值默认：**`orElse("访客")`** 或 **`orElseGet(() -> "访客")`**。
- 或组合：`orElse` 得字符串再处理（写法二选一即可）。
