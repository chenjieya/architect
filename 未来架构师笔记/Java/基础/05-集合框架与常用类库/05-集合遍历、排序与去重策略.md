## 1. 概述

本节说明 **List / Set / Map** 的常用遍历方式、使用 **`Comparable`/`Comparator`** 排序，以及用 **`Set`** 或 **`HashSet`** 包装实现 **去重** 的基本策略（本章不展开 Stream API）。

## 2. 核心概念

| 术语                              | 说明                                                          |
| --------------------------------- | ------------------------------------------------------------- |
| 增强 for（for-each）              | `for (String s : list)`，简洁遍历 `Iterable`                  |
| `Iterator`                        | 迭代器；可在遍历中 **`remove()`** 安全删除                    |
| `ConcurrentModificationException` | 在迭代中**结构性修改**集合（非 Iterator 删除）时抛出          |
| `Comparable`                      | 元素自身实现 `compareTo`，自然排序                            |
| `Comparator`                      | 外部比较器，定义 `compare(a, b)`                              |
| `Collections.sort`                | 对 `List` 排序；可传 `Comparator`                             |
| 去重                              | 利用 `Set` 不重复特性，如 `new HashSet<>(list)` 再转回 `List` |
| `entrySet()`                      | `Map` 的键值对集合，用于遍历 Map                              |

## 4. 语法与写法

### 4.1 List 遍历

```java
// 文件：CollectionIterateDemo.java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class CollectionIterateDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("a");
        list.add("");
        list.add("b");

        for (String s : list) {
            System.out.println(s);
        }

        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            String s = it.next();
            if (s.isEmpty()) {
                it.remove();
            }
        }
        System.out.println(list);  // [a, b]
    }
}
```

### 4.2 Comparable 与 Collections.sort

```java
// 文件：Student.java
public class Student implements Comparable<Student> {
    private final String id;
    private final String name;

    public Student(String id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public int compareTo(Student other) {
        return this.id.compareTo(other.id);
    }

    public String getName() {
        return name;
    }

    @Override
    public String toString() {
        return id + "-" + name;
    }
}
```

```java
// 文件：SortDedupDemo.java
import java.util.*;

public class SortDedupDemo {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student("002", "李四"));
        students.add(new Student("001", "张三"));
        Collections.sort(students);
        System.out.println(students);

        Collections.sort(students, new Comparator<Student>() {
            @Override
            public int compare(Student a, Student b) {
                return a.getName().compareTo(b.getName());
            }
        });
        System.out.println(students);
    }
}
```

## 5. 常见用法

1. **只读遍历**：for-each
2. **边遍历边删**：`Iterator.remove()`
3. **列表排序**：元素实现 `Comparable` 或传入 `Comparator`
4. **列表去重**：`new ArrayList<>(new HashSet<>(list))`；要保持顺序可用 `LinkedHashSet`（认识）

## 6. 易错点

- **for-each 里对 List 调 `remove(i)`**：触发 **并发修改异常**
- **`Comparator.compare` 返回 0**：表示相等；排序不稳定时相等元素顺序可能保持（了解）
- **去重后顺序丢失**：`HashSet` 不保证原 List 顺序；要顺序用 **`LinkedHashSet`**
- **对 `Map` 只遍历 `keySet` 却需要值**：用 **`entrySet`** 一次取键值

## 7. 本节小结

- 遍历：**for-each** 简单；需删除用 **`Iterator.remove()`**
- 排序：**`Comparable`** 或 **`Collections.sort(list, comparator)`**
- 去重：**`Set`** / **`HashSet` 包装**；注意顺序需求
