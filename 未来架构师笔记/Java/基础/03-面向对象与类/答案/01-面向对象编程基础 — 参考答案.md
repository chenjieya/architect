## 2. L2 原理应用

### 2.1

**答**：

- **现象**：输出 `张三`。
- **推理**：`s2 = s1` 使两引用指向同一对象，`setName` 改的是同一实例。
- **修复**：需要独立对象时写 `Student s2 = new Student();`（再分别 `setName`）。

### 2.2

**答**：

- **现象**：`new User()` 编译错误，提示构造器不匹配。
- **原因**：只定义了 `User(String name)`，默认无参构造不存在。
- **修复**：改为 `User u = new User("张三");`，或在 `User` 中显式添加无参构造。

### 2.3

**答**：

- **原因**：手写有参构造后，编译器不再提供默认无参构造。
- **修复思路（任选其一）**：① 显式添加 `public Book() { ... }`；② 调用处改为 `new Book("标题", 0.0)` 等有参形式。

### 2.4

**答**：

- **现象**：先实例块日志、后构造器日志；实例块里 `x` 为 0。
- **推理**：顺序符合「默认值 → 实例块 → 构造器」；构造器末尾才把 `x` 赋为 10，故构造器打印时若在未赋值前打印仍为 0。
- **结论**：实例块在构造器体执行之前运行；成员先默认值再被构造器修改。

### 2.5

**答**：

- **原因 1**：`super(name)` 必须是构造器**第一行**，不能放在 `this.dept` 之后。
- **原因 2**：父类无无参构造，子类必须显式调用 `super(name)`，且位置合法。
- **修正前两行**：

```java
public Employee(String name, String dept) {
    super(name);
```

（随后再 `this.dept = dept;`）

### 2.6

**答**：

- **结论**：封装方向对，但缺少对外接口。
- **应补**：如 `deposit`、`withdraw`、`getBalance` 等 `public` 方法，在方法内校验并操作 `balance`。

### 2.7

**答**：**编译错误**（递归调用 `this()`，构造器无法完成）。

### 2.8

**答**：

- **级别**：默认（包访问）。
- **概括**：仅**同一包**内可见；比 `private` 宽、比 `public` 窄；不能跨包访问。

## 3. L3 场景实战

### 3.1 [面试]

**答要点**：

- **类**：一类事物的抽象模板（字段 + 方法定义）。
- **对象**：类的具体实例，有独立状态。
- **创建**：`类名 变量 = new 类名(构造参数);`

### 3.2 [面试]

**答要点**：

- **封装**：隐藏内部实现，通过受控方法访问数据。
- **`private` 字段**：防止外部绕过规则直接改状态；把校验集中在方法中，提高可维护性与安全性。

### 3.3 [面试]

**答要点**：

- **区别**：构造器与类同名、无返回类型、在 `new` 时自动调用；用于初始化对象。
- **无参 `new`**：仅有带参构造时**不能**无参 `new`，因为默认无参构造未自动生成。

### 3.4 [面试]

**答要点**：

- **`this`**：当前对象；区分同名成员；`this()` 调用本类其他构造器。
- **`super`**：访问父类构造或方法；`super()` 先完成父类部分初始化。
- **首行**：保证父类（或本类委托链）先初始化，再执行子类字段赋值，避免子类使用未初始化的父类成员。

### 3.5 [面试·扩展]

**答要点**：

- **不准确**：基本类型 `int` 等不是对象，是值；`String` 是引用类型对象。
- **本章**：用 `new` 创建的是类实例对象；基本类型变量存值本身。

### 3.6 [面试]

**答要点**：

- **重载**：多个构造器参数不同，方便不同创建场景。
- **`this()`**：无参构造首行调用两参构造，赋值逻辑只写一处，减少重复。

### 3.7 [工作]

**答要点**（示例）：

1. 字段改为 `private`。
2. 提供带校验的 `public` 方法（如 `setTotal`/`deposit`）操作数据。
3. 用构造器或方法保证创建后总额合法（如非负）。

### 3.8 [面试]

**答要点**：

- **\` == \`**：比较引用是否指向**同一对象**（地址语义）。
- **内容相同**：本章不够；需要逐字段比较或后续学习 `equals` 约定（未展开重写规则）。
