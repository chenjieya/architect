> 所属：面向对象编程基础 · Java 面向对象与核心类库

## 1. 概述

本节说明 **封装（Encapsulation）**：把数据藏在类内部，通过 **访问修饰符** 与 **getter/setter** 控制外部如何读写，减少非法状态与随意改字段带来的错误。

## 2. 核心概念

| 术语                          | 说明                                                                             |
| ----------------------------- | -------------------------------------------------------------------------------- |
| 封装（Encapsulation）         | 隐藏对象内部实现细节，对外只暴露**必要、安全**的接口                             |
| 访问修饰符（Access Modifier） | 控制类、成员能否被其他代码访问：`public`、`private`、`protected`、默认（包访问） |
| `public`                      | 任何位置都可访问                                                                 |
| `private`                     | 仅**本类**内部可访问                                                             |
| `protected`                   | 本类、同包、**子类**可访问（子类细节见第 2 章）                                  |
| 默认（包访问）                | 无关键字时，仅**同一包**内可访问                                                 |
| getter                        | 读取私有字段的 `getXxx()` 方法                                                   |
| setter                        | 写入私有字段的 `setXxx()` 方法，常带**校验**                                     |

## 3. 语法与写法

### 3.1 私有字段 + 公开方法

```java
// 文件：BankAccount.java
public class BankAccount {
    private String owner;
    private double balance;

    public String getOwner() {
        return owner;
    }

    public void setOwner(String owner) {
        if (owner == null || owner.isBlank()) {
            return;   // 简单校验：拒绝空名
        }
        this.owner = owner;
    }

    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("金额必须为正");
            return;
        }
        balance += amount;
    }

    public boolean withdraw(double amount) {
        if (amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }
}
```

### 3.2 调用方只通过方法操作

```java
// 文件：BankAccountDemo.java
public class BankAccountDemo {
    public static void main(String[] args) {
        BankAccount acc = new BankAccount();
        acc.setOwner("王五");
        acc.deposit(1000);
        // acc.balance = -999;  // 编译错误：balance 是 private
        System.out.println(acc.getBalance());
    }
}
```

### 3.3 修饰符对比（成员）

| 修饰符      | 本类 | 同包其他类 | 子类（不同包） | 任意类 |
| ----------- | ---- | ---------- | -------------- | ------ |
| `private`   | ✅   | ❌         | ❌             | ❌     |
| 默认        | ✅   | ✅         | ❌             | ❌     |
| `protected` | ✅   | ✅         | ✅             | ❌     |
| `public`    | ✅   | ✅         | ✅             | ✅     |

初学阶段：**字段优先 `private`，对外用 `public` 方法**。

## 4. 常见用法

1. **余额、库存不能为负**：在 `deposit`/`withdraw` 或 setter 里判断，拒绝非法赋值
2. **只读属性**：只提供 `getId()`，不提供 `setId()`，ID 在构造时确定
3. **格式化输出**：`getDisplayName()` 内部拼接字段，调用方不必知道存储格式

## 5. 易错点

- **字段 `public` 到处改**：`acc.balance = -1` 能编译通过，破坏业务规则——应改为 `private` + 方法校验
- **getter/setter 命名不规范**：字段 `name` 应对应 `getName()`/`setName()`，不要写成 `getname()`
- **setter 不做校验**：外部仍可传入 `null`、负数，需在 setter 或业务方法里拦截
- **在本类外访问 `private`**：同类不同对象可以互访私有成员（少见）；**不同类**不能直接访问对方 `private` 字段

## 6. 本节小结

- **封装** = 数据隐藏 + 受控访问
- 字段常用 `**private`**；用 **getter/setter\*\* 或业务方法对外提供安全接口
- 四个修饰符控制可见范围；初学以 `**public` 类 + `private` 字段\*\* 为主
