## 1. else if 顺序错误

某同学用 `BranchDemo` 思路写成绩分支，顺序如下：

```java
int score = 95;
if (score >= 60) {
    System.out.println("及格");
} else if (score >= 90) {
    System.out.println("优秀");
} else {
    System.out.println("不及格");
}
```

输出为「及格」而非「优秀」。请按 **现象 → 推理 → 结论 → 修改方式** 说明原因，并写出一种正确顺序（列出两个 `else if` 条件即可）。

## 2. switch 忘记 break

传统写法：

```java
int day = 2;
switch (day) {
    case 1:
        System.out.println("Mon");
        break;
    case 2:
        System.out.println("Tue");
    case 3:
        System.out.println("Wed");
        break;
    default:
        System.out.println("Other");
}
```

实际可能连续打印多行。说明 **为何 case 2 会连到 case 3**（术语 + 执行流），以及两种修复方式（一种加 break，一种改为 JDK 17 箭头写法示例一行）。

## 3. 死循环

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
}
```

程序无法正常结束。说明 **缺少哪类语句**、循环变量 `i` 应如何变化，并补全一行使循环打印 0～4 后结束。

## 4. break 与 continue 输出

```java
for (int i = 0; i < 6; i++) {
    if (i == 3) {
        break;
    }
    if (i % 2 == 0) {
        continue;
    }
    System.out.println(i);
}
```

不运行程序，推断打印出的数字有哪些，并分步说明 **i=0、1、2、3** 时各自走哪条分支、是否打印。

## 5. 嵌套循环次数

```java
int count = 0;
for (int i = 0; i < 4; i++) {
    for (int j = 0; j < 3; j++) {
        count++;
    }
}
```

说明 **`count` 最终值** 及计算过程（不是 4+3）；若内层在 `j==1` 时 `break`（无标签），`count` 与「内层完整跑 3 次」相比变大还是变小？一句话说明。
