## 3. 三、编译、main 与 JIT

### 3.1 （填空）编译 `App.java`：`______`；运行：`______`（类名，无扩展名）。

### 3.2 （填空）Java 程序标准入口方法签名：

```java
public static void main(______________)
```

### 3.3 （判断）**JIT** 是 `javac` 在编译 `.java` 时使用的优化技术。（ ）

### 3.4 （简答）以下代码 `javac` 能否通过？`java Test` 能否运行？各一句话说明原因。

```java
public class Test {
    public void main(String[] args) {
        System.out.println("ok");
    }
}
```

### 3.5 （读输出）`java HelloWorld hello` 运行下列程序，输出几行？内容是什么？

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("参数个数: " + args.length);
        for (String arg : args) {
            System.out.println(arg);
        }
    }
}
```
