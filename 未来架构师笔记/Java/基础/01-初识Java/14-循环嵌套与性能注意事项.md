> 所属：流程控制 · Java 语言基础入门

## 1. 概述

本节说明**循环嵌套**（循环内再写循环）的常见模式、输出规律，以及编写时注意的执行次数与简单性能习惯（不涉及复杂算法课）。

## 2. 核心概念

| 术语                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| 嵌套循环            | 在一个循环的**循环体内部**再包含另一个循环                   |
| 外层循环 / 内层循环 | 先进入外层每一次迭代，内层循环**完整执行一遍**               |
| 执行次数（本阶段）  | 若外层 `n` 次、内层每次 `m` 次，内层体约执行 **n × m** 次    |
| 早停（Early exit）  | 已得结果时用 `break` 结束循环，避免无意义迭代                |
| 循环不变量外提      | 循环内**每次相同**的计算移到循环外，减少重复工作（入门了解） |

## 3. 语法与写法

### 3.1 二重循环：打印矩形

```java
public class NestedLoopDemo {
    public static void main(String[] args) {
        int rows = 3;
        int cols = 4;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

**输出**：3 行，每行 4 个 `*`。

### 3.2 九九乘法表（一行公式）

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    System.out.println();
}
```

内层上限随 `i` 变化，总打印次数为 `1+2+…+9 = 45` 项。

### 3.3 带 break 的嵌套搜索

```java
int target = 7;
boolean found = false;
outer:
for (int i = 0; i < 10 && !found; i++) {
    for (int j = 0; j < 10; j++) {
        if (i * 10 + j == target) {
            System.out.println("找到: " + i + "," + j);
            found = true;
            break outer;
        }
    }
}
```

### 3.4 循环变量勿重名

内外层应使用**不同变量名**（如 `i` 与 `j`），避免遮蔽与误用：

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {  // 推荐 j，不要再用 i
        System.out.println(i + "," + j);
    }
}
```

## 4. 常见用法

1. **二维结构遍历**：行列、坐标网格（为第 4 章二维数组打基础）。
2. **组合枚举**：外层固定一种选择，内层枚举另一种（本阶段规模小即可）。
3. **图案打印**：星号三角、矩形等控制台练习。
4. **计数统计**：双重循环内用计数器累加满足条件的次数。

## 5. 性能注意事项（入门）

| 建议              | 说明                                                                |
| ----------------- | ------------------------------------------------------------------- |
| 注意规模          | 二重循环约 **n×m** 次；若 n、m 都很大，运行时间明显变长             |
| 能 break 则 break | 已找到答案时不要继续内层空转                                        |
| 避免空循环体干等  | 无意义的 `while (true) { }` 会占满 CPU                              |
| 不变计算外提      | 例：循环内反复 `Math.sqrt(固定值)` 可移到循环外（后续优化会系统讲） |
| 先正确后优化      | 初学以逻辑正确为主；数据量小时差异可忽略                            |

**本阶段不要求** Big-O 形式化证明；记住「嵌套越深、次数乘起来越快」即可。

## 6. 易错点

- **内外层变量混淆**：内层误用外层变量导致边界错误或死循环。
- **只 break 内层**：找到目标后只 `break` 内层，外层仍继续——需 `break outer` 或标志变量。
- **执行次数算错**：以为二重各 10 次共 20 次，实际内层体约 **100** 次。
- **println 在错误层级**：`println` 写在内层导致一行过多输出；换行应常放在**内层循环结束后、外层仍进行中**。
- **无限外层**：外层条件永真且内层无退出 → 程序无法结束。

## 7. 本节小结

- 嵌套循环：外一层、内一层**完整执行**，总次数约为各层次数之**积**（矩形网格）
- 内外层用**不同索引变量**；打印图案时注意换行位置
- 搜索场景可用 **break + 标签** 或布尔标志**早停**
- 入门阶段：**逻辑正确优先**；规模变大时再考虑减少无效迭代
