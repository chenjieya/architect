## 2. L2 原理应用

### 2.1

**现象**：`avg` 打印为 `3.0` 而非 `3.5`。  
**推理**：`total` 与 `count` 均为 `int`，`total / count` 先做 **整数除法**，结果为 `3`，再自动提升为 `double` 赋给 `avg`，小数部分已在除法时截断。  
**结论**：问题在 **运算阶段** 已是整数除，而非赋值给 `double` 能挽回。  
**修改示例**（任一种）：`double avg = total / 2.0;` 或 `double avg = (double) total / count;`

### 2.2

**现象**：`methodVar` 可能未初始化。  
**推理**：**成员变量** `classVar` 有默认值 0；**局部变量** `methodVar` 无默认值，且若 `classVar <= 0` 时 `if` 不执行赋值，存在路径未赋值。  
**结论**：编译器要求局部变量在每条执行路径上 **明确赋值** 后才可使用。  
**改法示例**：声明时赋初值 `int methodVar = 0;`，或在 `else` 中赋值，或去掉 `if` 直接赋值。

### 2.3

**现象**：`&` 时可能 `ArithmeticException: / by zero`。  
**推理**：`&` 对布尔操作数 **不短路**，左右都会计算，故仍执行 `10 / n`。`&&` 在 `n != 0` 为 `false` 时 **不计算右侧**，避免除零。  
**结论**：条件判断应使用 **`&&` / `||`** 实现短路安全逻辑。

### 2.4

**现象**：`byte sum = b1 + b2` 编译错误。  
**推理**：`byte` 参与 `+` 运算时 **提升为 int**，表达式类型为 `int`，不能隐式赋给 `byte`。  
**结论**：用 `int sum = b1 + b2;`，或 `byte sum = (byte)(b1 + b2);`（须保证结果在 byte 范围内）。

### 2.5

**现象**：内层 `int x = 2` 重复声明失败。  
**推理**：同一方法作用域内 **不能重复声明同名** 局部变量；内层块不能与外层同名再声明。  
**思路**：内层改用不同名如 `int innerX = 2;`，或只用 `x = 2;` 赋值（不重新声明）。

### 2.6

**现象**：第一行输出 **50**；第二行输出 **11**（字符串）。  
**推理**：

- `1 + '1'`：**无 String**，`+` 为 **算术**；`'1'` **提升为 int** 49 → `1 + 49 = 50`。
- `"1" + '1'`：左侧为 **String**，`+` 为 **拼接**；`'1'` 转为字符串 `"1"` → `"11"`。  
   **结论**：Java 用 **是否出现 String** 区分算术与拼接；不会在纯算术式里把 `int` 隐式变 `String`，否则 `1+2` 等基础运算语义会混乱。要文本拼接须显式引入 `"..."`。

## 3. L3 场景实战

### 3.1 [面试]

**要点**：

- **静态类型**：声明时确定类型，**编译期**检查（Java）
- **动态类型**：运行期根据赋值决定类型（Python、JS 典型）
- Java 是静态类型；与「编译型/解释型」是不同维度

### 3.2 [面试]

**要点**：

- **强类型**：类型不匹配操作被拒绝或须显式转换
- JS **弱类型**：如 `"1" + 2` → `"12"` 等隐式转换多
- 好处：更多错误在 **编译期** 暴露，代码意图更清晰，利于大型项目维护

### 3.3 [面试]

**要点**：

- **成员变量**：类里、方法外；有默认值；生命周期与对象/类相关
- **局部变量**：方法或块内（含参数）；**无默认值**，使用前须赋值；随方法/块结束而失效

### 3.4 [面试]

**要点**：

- **基本类型**：直接存值，8 种，如 `int`、`boolean`
- **引用类型**：变量存对象引用，如 `String`、数组、自定义类

### 3.5 [面试]

**要点**：

- `==`：**比较**是否相等
- `=`：**赋值**
- `if` 条件必须是 `boolean`；`x = 1` 是 `int` 赋值，Java 不允许

### 3.6 [面试]

**要点**：

- **短路**：`&&` 左为 `false` 不计算右；`||` 左为 `true` 不计算右
- **`&` / `|`**：布尔运算时两边都计算，不短路

### 3.7 [面试·扩展]

**要点**：

- Java：`int / int` → `int`，`5/2` 为 `2`
- Python 3：`/` 为真除法，`5/2` 为 `2.5`
- Java 得 `2.5`：`5/2.0`、`(double)5/2` 等

### 3.8 [面试]

**要点**：

- **widening**：小→大，**自动**
- **narrowing**：大→小，**显式** `(类型)`，可能截断/溢出

### 3.9 [工作]

**可向同事说明的差异（任两条及以上）**：

1. Java 是 **静态类型、强类型**，须先写 `int score`；Python 可后赋不同类型。
2. **局部变量无默认值**，必须先赋值；成员变量才有默认值。
3. `if` 条件必须是 **布尔表达式**。

**修改示例**：

```java
public class Demo {
    public static void main(String[] args) {
        int score = 75;
        if (score >= 60) {
            System.out.println("及格");
        }
    }
}
```
