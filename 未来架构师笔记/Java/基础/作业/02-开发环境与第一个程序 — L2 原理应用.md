## 2. PATH 顺序推理

Path 中（靠前优先）：

1. `C:\Program Files (x86)\Common Files\Oracle\Java\javapath`
2. `%JAVA_HOME%\bin`（`JAVA_HOME` 指向 JDK 17）

`java -version` 仍显示 1.8。

**问**：最可能原因？如何验证与修复？

```bash
javac HelloWorld.java
```

## 4. main 缺 static

```java
public class Test {
    public void main(String[] args) {
        System.out.println("ok");
    }
}
```

`javac` 通过，`java Test` 报 `Main method not found`。

**问**：为何编译能过、运行失败？JVM 在找什么签名？

## 5. JAVA_HOME 未配置

某台电脑现象：

- 终端 `java -version`、`javac -version` 均显示 17，命令行编译运行正常
- 执行 `echo %JAVA_HOME%`（PowerShell：`echo $env:JAVA_HOME`）输出为空 **问**：仅配置 Path、不设置 `JAVA_HOME`，可能带来什么问题？应如何补全配置？（结合四层排查模型回答；提示：`JAVA_HOME` 供 IDEA 等工具定位 JDK 根目录）
