## 2. L2 原理与应用

### 2.1

**答**：

- **现象**：`ArrayIndexOutOfBoundsException`
- **推理**：长度为 3 时下标合法为 0、1、2；`arr[3]` 越界
- **结论**：不能使用下标 3
- **合法表达式**：`arr[arr.length - 1]` 或 `arr[2]`

### 2.2

**答**：

- **现象**：`NullPointerException`
- **推理**：`new int[2][]` 只创建两行引用槽，`table[0]` 仍为 `null`
- **结论**：必须先为行分配列数组
- **修复示例**：`table[0] = new int[3];` 再访问 `table[0][0]`

### 2.3

**答**：

- **输出**：`DENY`
- **== 比较**：是否指向**同一对象**；`input` 由 `new String("admin")` 创建，与字面量 `expected` 内容相同但通常**不是同一引用**
- **正确写法**：`input.equals(expected)` 或 `"admin".equals(input)`

### 2.4

**答**：

- **现象**：n 很大时明显变慢、产生大量临时 `String`
- **原因**：`String` 不可变，每次 `s = s + i` 都 **new 新串** 并复制已有内容
- **改进**：

```java
int[] arr = {1, 2, 3};
StringBuilder sb = new StringBuilder();
for (int i = 0; i < arr.length; i++) {
    if (i > 0) sb.append(",");
    sb.append(arr[i]);
}
String s = sb.toString();
```

### 2.5

**答**：

- **问题**：无 `@` 时 `at` 为 -1，仍 `substring(0)` 语义错误
- **条件示例**：`at > 0 && at < email.length() - 1` 再截取（或先 `at != -1`）

### 2.6

**答**：

- **现象**：堆上**旧** `{1,2,3}` 对象没有被拉长；`arr` 最后指向 **bigger** 新对象
- **推理**：变长靠 **新数组 + 拷贝 + 改引用**，不是改原对象 `length`
- **结论**：`bigger[0]==1` 说明旧元素已拷贝；旧数组若无引用由 GC 回收

### 2.7

**答**：

- **`x` 为 1**：`y = x` 拷贝**数值**，改 `y` 不影响 `x`
- **`a[0]` 为 99**：`b = a` 拷贝**门牌号**，同一堆数组，改 `b[0]` 即改 `a[0]`
- **结论**：基本类型变量存值；引用类型变量存引用，实体在堆上共享

### 2.8

**答**：

- `append` 修改的是 **StringBuilder** 缓冲区，不是 `String`
- `"Hi"` 字面量对应的 `String` 仍不可变；Builder 是另一类可变对象
- `toString()` 生成**新的** `String` 赋给 `s`；业务最终用不可变 `String`

## 3. L3 场景实战

### 3.1

**答要点**：

1. **不能**对原对象改 `length`；`length` 只读
2. **`new` 更长的新数组** → **循环拷贝**旧元素 → **`arr = 新数组`**（换门牌，不是拉长旧对象）
3. 旧数组无引用后由 GC 回收（知道即可）

### 3.2

**答要点**：

- 数组在堆上占**连续**空间，`arr[i]` 依赖固定长度与偏移
- 定长保证下标访问简单、可预测；要更多元素用 **新数组拷贝**（本章范围）

### 3.3

**答要点**：

- **含义**：创建后不能改内部字符；「修改」通过 new 新 `String` 实现
- **好处任一条**：常量池复用、线程安全、适合作 Map 键、避免意外篡改等

### 3.4

**答要点**：

- `==`：是否**同一对象**（引用）
- `equals`：**字符内容**是否相同
- 登录名要比对用户输入的文字，不能依赖 `==`（`new String` 与字面量内容同但 `==` 可能为 false）

### 3.5

**答要点**：

- `String` 仍不可变；循环里用 **StringBuilder** 当可变草稿，`append` 累积
- 循环结束后 **`toString()`** 一次得到正式 `String`
- 避免循环中 `s = s + ...` 反复 new 大串

### 3.6

**答要点**：

- **循环内**多次拼接、数组转 `"1,2,3,4,5"`、拼日志行/CSV 等
- 单次 `"a"+b` 可继续用 `+`

### 3.7

**答要点**：

- `a == b`：**一般为 true**（相同字面量常同一常量池对象）
- `a == c`：**一般为 false**（`new` 出新对象）
- 比内容：`a.equals(c)` 或 `"hi".equals(c)`

### 3.8

**答要点**：

1. `name == null`
2. `name = name.trim()`
3. `isEmpty()` / `isBlank()`
4. `length` 范围等业务规则

- **先 trim**：否则 `" "` 的 `isEmpty()` 为 false，会被当成有效名
