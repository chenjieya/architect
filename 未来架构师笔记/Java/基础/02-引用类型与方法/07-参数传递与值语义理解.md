## 1. 概述

本节说明 Java **总是按值传递（pass-by-value）**：给形参的是**值的拷贝**（基本类型拷数值，引用类型拷**门牌号**）。理解这一点才能解释「改形参不影响实参变量」与「改堆上对象会影响外部」两类现象。

## 2. 核心概念

| 术语                    | 说明                                                                |
| ----------------------- | ------------------------------------------------------------------- |
| 值传递（Pass-by-Value） | 调用时把实参的**值**复制一份赋给形参；形参与实参是**两个独立变量**  |
| 基本类型实参            | 传递的是**数值本身**的拷贝；方法内改形参**不影响**调用方的变量      |
| 引用类型实参            | 传递的是**引用（门牌号）**的拷贝；两个变量可指向**同一堆对象**      |
| 形参重新赋值            | 在方法里 `形参 = 新值` 只改**方法内**的局部变量，**不改**调用方变量 |
| 通过引用改对象          | 用形参访问堆对象并改其内容（如 `arr[0]=9`），**调用方可见**         |

## 3. 语法与写法

### 3.1 基本类型：改形参不影响实参

```java
public class ParamPassDemo {
    public static void main(String[] args) {
        int x = 10;
        bump(x);
        System.out.println("main 里 x = " + x);  // 仍是 10
    }

    public static void bump(int n) {
        n = n + 1;
        System.out.println("方法里 n = " + n);   // 11
    }
}
```

### 3.2 引用类型：改堆上内容 vs 改门牌

```java
public static void main(String[] args) {
    int[] nums = {1, 2, 3};
    changeElement(nums);
    System.out.println(nums[0]);   // 9 — 堆上数组被改了

    int[] a = {1, 2, 3};
    reassign(a);
    System.out.println(a[0]);      // 1 — main 里 a 仍指向原数组
}

public static void changeElement(int[] arr) {
    arr[0] = 9;   // 通过门牌改堆上元素
}

public static void reassign(int[] arr) {
    arr = new int[]{9, 9, 9};   // 只让形参 arr 指向新数组，main 的 a 不变
}
```

### 3.3 String 作为参数

`String` 不可变；方法里 `s = s + "!"` 是让形参指向**新 String**，**不改**调用方变量所指内容：

```java
public static void appendExclaim(String s) {
    s = s + "!";
}

public static void main(String[] args) {
    String msg = "Hi";
    appendExclaim(msg);
    System.out.println(msg);   // Hi
}
```

### 3.4 数组整体替换若要让 main 生效

Java 无法让形参替换调用方的**变量绑定**；要在 `main` 里接收新数组：

```java
public static int[] doubleSize(int[] old) {
    int[] bigger = new int[old.length * 2];
    for (int i = 0; i < old.length; i++) {
        bigger[i] = old[i];
    }
    return bigger;   // 调用方：arr = doubleSize(arr);
}
```

## 4. 常见用法

1. **传入数组统计**：方法内遍历 `int[]`，改元素或只读均可，需明确是否允许改原数组。
2. **传入 String 校验**：只读 `equals`、`trim`，不在方法里依赖「改调用方 String 变量」。
3. **返回新结果**：需要「换一个新对象」时，用 **return** 交回，而不是指望形参 reassign 影响外面。
4. **调试打印**：在方法入口打印形参，确认收到的是拷贝还是同一引用。

## 5. 易错点

- **误以为 Java 有引用传递**：常说「数组是引用传递」——准确说法是 **引用类型的值（门牌号）按值传递**。**处理**：记「永远是值传递；引用类型传的是门牌拷贝」。
- **在方法里 `arr = new int[...]` 期望 main 的数组变量也变**：不会；只有 **`return` 新数组** 或 **改 `arr[i]`** 两种影响方式。**处理**：要换数组对象就 `return`。
- **基本类型期望被方法改回**：`void swap(int a, int b)` 交换形参对 main **无效**。**处理**：交换需用数组/返回结果等（本阶段用 `return` 或传入数组下标）。
- **null 实参**：引用形参可以是 `null`，对 `null` 解引用 → `NullPointerException`。**处理**：方法开头可判 `if (arr == null) return;`。

## 6. 本节小结

- Java **只有值传递**：基本类型传**数拷贝**；引用类型传**门牌号拷贝**
- 改形参变量本身（赋值、reassign）**不影响**调用方局部变量
- 通过引用改**堆上对象内容**（如 `arr[0]`）**会影响**外部
- 需要新对象时 **`return`**，不要指望形参 reassign 改 main 里的引用变量
