## 1. 数组下标越界

```java
int[] arr = {5, 10, 15};
System.out.println(arr[3]);
```

说明运行期会出现什么异常、为什么下标 3 非法，并写出**合法**访问最后一个元素的下标表达式。

## 2. 二维数组未初始化行

```java
int[][] table = new int[2][];
System.out.println(table[0][0]);
```

按 **现象 → 推理 → 结论 → 修复** 说明错误原因，并补全一行代码使 `table[0]` 能安全存 3 个 `int`。

## 3. == 与 equals

```java
String expected = "admin";
String input = new String("admin");
if (input == expected) {
    System.out.println("OK");
} else {
    System.out.println("DENY");
}
```

不运行程序，推断输出哪一行；说明 **== 比较的是什么**（为何 `input` 与 `expected` 内容相同却可能进不了 OK 分支）；写出一种正确的「内容相同则 OK」判断写法。

## 4. 循环里 String 拼接

某程序在循环中执行：

```java
String s = "";
for (int i = 0; i < n; i++) {
    s = s + i;
}
```

当 `n` 很大时变慢。用 **现象 → 原因（与 String 不可变相关）→ 改进写法** 说明，并写出用 `StringBuilder` 把 `int[] arr = {1,2,3}` 拼成 `"1,2,3"` 的循环骨架（含 `toString()`）。

## 5. substring 与 indexOf

```java
String email = "user";
int at = email.indexOf("@");
String domain = email.substring(at + 1);
```

说明运行期可能发生什么问题；若要求「有 @ 且 @ 不在首尾才截取域名」，写出 `if` 条件应包含哪些判断（用 `at` 与 `email.length()` 表达即可）。

## 6. 数组「变长」：拷贝门牌号

```java
int[] arr = {1, 2, 3};
int[] bigger = new int[arr.length + 2];
for (int i = 0; i < arr.length; i++) {
    bigger[i] = arr[i];
}
bigger[3] = 4;
bigger[4] = 5;
arr = bigger;
```

说明：堆上数组对象有没有被「拉长」？`arr` 最后指向哪里？`bigger[0]` 为 1 说明拷贝了什么？（用 **现象 → 推理 → 结论** 格式。）

## 7. 基本类型赋值 vs 引用赋值

```java
int x = 1;
int y = x;
y = 2;

int[] a = {10, 20};
int[] b = a;
b[0] = 99;
```

分别说明执行后 `x`、`a[0]` 的值，并解释 **为什么一个互不影响、一个会一起变**（联系变量格里存的是「值」还是「门牌号」）。
