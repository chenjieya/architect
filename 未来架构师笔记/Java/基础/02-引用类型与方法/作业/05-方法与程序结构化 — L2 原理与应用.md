## 1. 基本类型形参

```java
public static void main(String[] args) {
    int x = 5;
    increment(x);
    System.out.println(x);
}
public static void increment(int n) {
    n = n + 10;
}
```

不运行程序，推断输出；用 **现象 → 推理（传递机制）→ 结论** 说明为何 `main` 里 `x` 没有变成 15。

---

## 2. 数组形参 reassign

```java
public static void main(String[] args) {
    int[] data = {1, 2, 3};
    replace(data);
    System.out.println(data.length);
}
public static void replace(int[] arr) {
    arr = new int[10];
}
```

推断 `main` 中 `data.length` 输出几；说明 **为何** 方法内 `arr = new int[10]` 没有改变 `main` 里 `data` 的长度；若要让 `main` 使用长度为 10 的新数组，应如何改（用文字描述 return + 赋值即可）。

---

## 3. 数组形参改元素

```java
public static void main(String[] args) {
    int[] data = {1, 2, 3};
    setFirst(data, 99);
    System.out.println(data[0]);
}
public static void setFirst(int[] arr, int value) {
    arr[0] = value;
}
```

推断输出；对比第 2 题，说明 **改 `arr[0]`** 与 **形参 reassign** 为何结果不同（用「门牌号 / 堆上实体」表述）。

## 4. 非 void 漏 return

```java
public static int sign(int n) {
    if (n > 0) {
        return 1;
    } else if (n < 0) {
        return -1;
    }
    // 缺少对 n == 0 的处理
}
```

说明编译器会报什么类问题、如何补全使 `n == 0` 时返回 0。

## 5. 重载匹配

某类中有：

```java
public static void log(String msg) { ... }
public static void log(String msg, int code) { ... }
```

调用 `log("timeout", 504)` 会匹配哪一个重载？若只有 `log(String msg)`，调用 `log("timeout", 504)` 会怎样？说明编译期如何选版本。

## 6. 递归终止

```java
public static int badSum(int n) {
    return n + badSum(n + 1);
}
```

说明运行 `badSum(1)` 可能出现什么异常、**根本原因**是什么；写出 `sumToN(n)`（1～n 之和）应具有的 **基准条件** 一行（不要求完整方法体）。

## 7. ScoreMenu 未接 return

某同学写了：

```java
public static void addScore() {
    // ... 读入 score 合法 ...
    appendScore(scores, score);
    System.out.println("已录入");
}
```

`appendScore` 会 `return` 新数组，但 `addScore` 如上。现象：录入后「查看全部」仍为空。按 **现象 → 原因 → 修复** 写出应改哪一行、改成什么形式。

## 8. String 形参与不可变

```java
public static void main(String[] args) {
    String msg = "Hi";
    appendExclaim(msg);
    System.out.println(msg);
}
public static void appendExclaim(String s) {
    s = s + "!";
}
```

推断输出；结合 String **不可变** 与 **值传递**，说明为何 `appendExclaim` 没有让 `msg` 变成 `"Hi!"`；若要让调用方得到新串，方法签名应如何改（提示：返回类型与 `return`）。
