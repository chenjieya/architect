### 2.3 （读代码）下列代码中，`main` 里 `nums[0]` 输出几？

```java
public static void main(String[] args) {
    int[] nums = {1, 2, 3};
    changeElement(nums);
    System.out.println(nums[0]);

public static void changeElement(int[] arr) {
    arr[0] = 9;
}
```

```java
    System.out.println(a[0]);
}
public static void reassign(int[] arr) {
    arr = new int[]{9, 9, 9};
}
```

## 3. 三、方法重载

### 3.1 （填空）方法重载要求：方法名相同，且 **\_\_** 列表不同。

### 3.2 （判断）仅返回类型不同、方法名与参数列表完全相同的两方法，可以构成合法重载。（ ）

### 3.3 （选择）下列哪组属于合法重载？

- A. `void print(int x)` 与 `int print(int x)`
- B. `void print(int x)` 与 `void print(String x)`
- C. `void print(int x, int y)` 与 `void print(int x, int y)`（完全相同）
- D. 以上 B 正确

### 3.5 （判断）方法重载是在**编译期**根据实参类型与个数选择具体方法的。（ ）

### 3.6 （填空）Java 没有 Python 式形参默认值；少传参时常用 **\_\_** 代替。

### 3.7 （判断）Java 支持可变参数语法，例如 `public static int sum(int... nums)`。（ ）
