FTP 使用介绍

1、各类 ftp

FTP（文件传输协议）常用的网络协议之一，为系统提供了通过网络与远程服务器进行文件传输的简便方法

1)wuftp

2)proftp

3)pureftp

4)vsftp

FTP 服务器包名称为 vsftpd（Very secure File Transfer Protocol Daemon），服务名称也叫 vsftpd

2、ftp 软件管理

1）yum install vsftpd.x86_64 或 rpm -ivh vsftpd-xxxxxxxx.rpm

2）启动和关闭 service vsftpd start / stop /restart systemctl start/stop/restart vsftpd.service

3） systemctl enable vsftpd.service //保持开机启动

3、相关参数配置

1）rhel7 下默认配置为匿名 FTP 服务器，仅允许匿名客户端下载，并且禁用本地用户，禁止上传 rhel8 下默认没开匿名。

​ 配置文件：/etc/vsftpd/vsftpd.conf

​ 共享路径 位于/var/ftp/

​ 配置修改后，需重新启动服务

2）监听地址和端口 listen_address=ip

​ 地址对于单个 IP，开启服务，默认即在这个 IP 下监听

​ 对于多个 IP，未指定话，则在所有 IP 下监听，可根据需要，做指定 listen_port=端口号

​ 默认是 21

​ listen=yes

​ listen_ipv6=no 之后才能指定 IP 监听

3）匿名用户 anonymous_enable=YES|NO

​ anon_root=路径 //默认匿名用户的家目录为/var/ftp

​ 本地用户 local_enable=YES|NO

​ 控制 vsftpd 所在的系统的用户是否可以登录 vsftpd.默认为 YES

​ userlist_enable=YES|NO //默认 NO

​ userlist_file=/etc/vsftpd/user_list //默认就为该文件，不用配置

​ userlist_deny=YES|NO //默认为 YES,user_list 中记录的都是被拒绝的名单

4）配置例子

配置例子(白名单形式)：

anonymous_enable=NO

local_enable=YES

userlist_enable=YES

userlist_deny=no

同时在/etc/vsftpd/user_list 文件中只写入 testuser

配置效果：testuser 就可以登录 ftp 了

提醒：1） 如果用户是/sbin/nologin,需要在/etc/shells 加入一行/sbin/nologin，要不然登录失败

​ 2）/etc/vsftpd/ftp_users 中列出的用户还是不可以登录

5）日志

xferlog_enable=YES|NO 默认为 YES

xferlog_std_format=YES|NO 建议设置为 NO，自带的配置文件是 YES,产生的日志文件为

/var/log/xferlog 格式解析复杂.如果设置为 NO ,那日志文件就变成了/var/log/vsftpd.log

系统上有自带的配置文件例子可供大家参考/usr/share/doc/vsftpd
