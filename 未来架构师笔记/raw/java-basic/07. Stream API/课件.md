# Stream API

## 课程目标

- 理解 Stream API 的概念和作用

- 掌握 Stream 的创建方式（从集合、数组、值）

- 掌握常用的终端操作（forEach、collect、toList、reduce、count）

- 掌握常用的中间操作（filter、map、sorted、distinct、limit）

  

------

## 什么是 Stream API

回顾：**函数式编程**就是将函数作为一等公民，即允许把方法当作参数传递、赋值给变量。

**Stream API** 是 Java 8 引入的一套用于处理集合数据的**函数式编程**工具。它允许我们以**声明式**的方式对数据源（如集合、数组）进行复杂的查询和变换操作，类似于 SQL 语句的`查询`风格。

Stream 本身**不存储数据**，而是从数据源（如 集合、数组）获取数据，通过**流水线**（Pipeline）的方式依次执行一系列操作，最终得到结果。

### 为什么需要 Stream API

在 Stream 出现之前，对集合的操作通常依赖 **for 循环** 或 **Iterator**，代码冗长且容易出错。

```java
// 假设存在一组Student对象
// 传统循环方式：筛选出成绩 ≥ 80 的学生姓名，并转为大写
List<String> names = new ArrayList<>();
for (Student s : students) {
    if (s.getScore() >= 80) {
        names.add(s.getName().toUpperCase());
    }
}

// Stream 方式：更简洁、更可读
List<String> names = students.stream()
        .filter(s -> s.getScore() >= 80)
        .map(s -> s.getName().toUpperCase())
        .collect(Collectors.toList());//去掉
```



### 核心特点

| 特点         | 说明                                           |
| ------------ | ---------------------------------------------- |
| **声明式**   | 只描述“做什么”，不描述“怎么做”                 |
| **流水线**   | 多个操作链接成一个流水线，按顺序执行           |
| **内部迭代** | Stream 自己控制迭代过程，无需显式写循环        |
| **惰性求值** | 中间操作是惰性的，只有终端操作触发时才真正执行 |
| **不可变**   | Stream 不会修改数据源，而是产生新的结果        |

## Stream 的创建

### 从集合创建

使用 `Collection` 接口的 `stream()`方法：

```java
List<String> list = Arrays.asList("a", "b", "c");
Stream<String> stream = list.stream();          // 顺序流

Set<Integer> set = new HashSet<>(Arrays.asList(1, 2, 3));
Stream<Integer> setStream = set.stream();
```



### 从数组创建

使用 `Arrays.stream()` 或 `Stream.of()`：

```java
int[] nums = {1, 2, 3, 4};
IntStream intStream = Arrays.stream(nums);  // 基本类型有专用流

String[] words = {"hello", "world"};
Stream<String> stream = Arrays.stream(words);

// 或者使用 Stream.of
Stream<String> stream2 = Stream.of("hello", "world");
Stream<Integer> stream3 = Stream.of(1, 2, 3);
```



### 从值创建

使用 `Stream.of()` 直接传入多个值：

```java
Stream<Integer> stream = Stream.of(1, 2, 3, 4, 5);
Stream<String> stream2 = Stream.of("a", "b", "c");
```

> [!NOTE]
>
> - `Stream` 是泛型接口，只能处理**引用类型**。
> - 对于基本类型（`int`、`long`、`double`），Java 提供了 `IntStream`、`LongStream`、`DoubleStream` 以提高性能

## 终端操作（Terminal Operations）

终端操作会**触发流执行**，并产生最终结果（如收集到集合、计算值、打印等）。终端操作执行后，流就**不可再用**。

### `forEach` —— 遍历

对每个元素执行操作。

```java
Stream.of("a", "b", "c")
      .forEach(System.out::println);
```



### `collect` —— 收集

将流转换为集合或其他容器（**最常用**）。

```java
import java.util.stream.Collectors;

Stream<String> stream = Stream.of("apple", "banana", "apple", "orange");

// 收集为 List
List<String> list = stream.collect(Collectors.toList());
System.out.println("toList 结果: " + list); // [apple, banana, apple, orange]

// 收集为 Set
Set<String> set = stream.collect(Collectors.toSet());
System.out.println("toSet 结果: " + set);

List<Student> students = Arrays.asList(
        new Student(1, "Alice"),
     		new Student(2, "Bob"),
     		new Student(3, "Charlie"),
     		new Student(2, "Bob")    // 故意重复，用于演示 toSet 去重
);
// 收集为 Map（需指定键和值）
Map<Integer, String> map = students.stream()
        .collect(Collectors.toMap(Student::getId, Student::getName));

// 收集为指定容器
ArrayList<String> arrayList = stream.collect(Collectors.toCollection(ArrayList::new));
System.out.println("toCollection(ArrayList::new) 结果: " + arrayList);
```



### `toList()`（Java 16+）

Java 16 引入了 `Stream.toList()` 作为更简洁的方式。

```java
List<String> list = stream.toList(); // 返回不可变 List
```



### `reduce` —— 归约

将流中的元素反复操作，最终得到一个值（如求和、求积等）。

```java
// 求和
int sum = Stream.of(1, 2, 3, 4)
        .reduce(5, Integer::sum);  // 10

// 字符串连接
String concat = Stream.of("a", "b", "c")
        .reduce("", (s1, s2) -> s1 + s2); // "abc"

// 求最大值（使用 Optional）
Optional<Integer> max = Stream.of(1, 2, 3, 4)
        .reduce(Integer::max);
max.ifPresent(System.out::println); // 4
```

> [!NOTE]
>
> 补充数据类型：`Optional` 是一个**容器对象**，它可能包含一个非空值，也可能为空（`null`）。它由 Java 8 引入，核心设计初衷是**通过类型系统明确表示“值可能存在也可能不存在”**，从而迫使调用者显式处理缺失情况。



### `count` —— 计数

返回流中元素个数。

```java
long count = Stream.of(1, 2, 3).count(); // 3
```



### `anyMatch` / `allMatch` / `noneMatch` —— 匹配

判断元素是否满足条件（返回 `boolean`）。

```java
List<Integer> nums = Arrays.asList(1, 2, 3, 4);
boolean anyEven = nums.stream().anyMatch(n -> n % 2 == 0); // true
boolean allPositive = nums.stream().allMatch(n -> n > 0); // true
boolean noneNegative = nums.stream().noneMatch(n -> n < 0); // true
```



### `findFirst` / `findAny` —— 查找

返回第一个或任意一个元素（返回 `Optional`）。

```java
Optional<Integer> first = Stream.of(1, 2, 3).findFirst(); // 1
Optional<Integer> any = Stream.of(1, 2, 3).findAny();  // 非确定性
```



### `min` / `max` —— 最值

返回最小/最大值（需提供 `Comparator`）。

```java
Optional<Integer> min = Stream.of(3, 1, 4, 1, 5)
        .min(Integer::compareTo);
Optional<Integer> max = Stream.of(3, 1, 4, 1, 5)
        .max(Integer::compareTo);
```



## 中间操作（Intermediate Operations）

中间操作返回一个新的 Stream，可以**链式**调用多个中间操作。**注意：** 中间操作不会立即执行，只有遇到终端操作时才会触发。

### `filter` —— 筛选

保留满足条件的元素。

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);
numbers.stream()
       .filter(n -> n % 2 == 0)   // 只保留偶数
       .forEach(System.out::println); // 2, 4, 6
```



### `map` —— 映射

将每个元素转换为另一种形式（一对一转换）。

```java
List<String> words = Arrays.asList("hello", "world");
words.stream()
     .map(String::toUpperCase)
     .forEach(System.out::println); // HELLO, WORLD

// 提取对象属性
List<Student> students = ...;
students.stream()
        .map(Student::getName)  // 提取姓名
        .forEach(System.out::println);
```



### `flatMap` —— 扁平映射

将每个元素映射为一个流，然后将所有流合并为一个流（一对多转换）。

```java
List<List<Integer>> nested = Arrays.asList(
        Arrays.asList(1, 2),
        Arrays.asList(3, 4),
        Arrays.asList(5, 6)
);
nested.stream()
      .flatMap(List::stream)   // 扁平化
      .forEach(System.out::println); // 1,2,3,4,5,6

// 拆分词为字母
String[] words = {"hello", "world"};
Arrays.stream(words)
      .flatMap(w -> Arrays.stream(w.split("")))
      .forEach(System.out::println); // h,e,l,l,o,w,o,r,l,d
```



### `distinct` —— 去重

移除重复元素。

```java
List<Integer> nums = Arrays.asList(1, 2, 2, 3, 3, 3);
nums.stream()
    .distinct()
    .forEach(System.out::println); // 1,2,3
```



### `sorted` —— 排序

按自然顺序或自定义 `Comparator` 排序。

```java
List<Integer> nums = Arrays.asList(3, 1, 4, 1, 5);
nums.stream()
    .sorted()                     // 自然排序（升序）
    .forEach(System.out::println); // 1,1,3,4,5

// 自定义比较器（降序）
nums.stream()
    .sorted(Comparator.reverseOrder())
    .forEach(System.out::println); // 5,4,3,1,1
```



### `limit` / `skip` —— 截取

- `limit(n)`：取前 n 个元素
- `skip(n)`：跳过前 n 个元素

```java
Stream.iterate(0, i -> i + 1)
      .limit(10)          // 取前10个
      .skip(3)            // 跳过前3个
      .forEach(System.out::println); // 3,4,5,6,7,8,9
```



### `peek` —— 查看（调试用）

对每个元素执行操作，通常用于调试（如打印日志），不改变元素。

```java
List<Integer> result = Stream.of(1, 2, 3)
        .peek(System.out::println)   // 打印每个元素
        .map(n -> n * 2)
        .collect(Collectors.toList());
```

## Stream 操作经典示例

### 示例1：筛选和转换

```java
class Student {
        private String name;
        private int age;
        private int score;

        public Student(String name, int age, int score) {
            this.name = name;
            this.age = age;
            this.score = score;
        }

        public String getName() { return name; }
        public int getAge() { return age; }
        public int getScore() { return score; }
}

List<Student> students = Arrays.asList(
        new Student("Alice", 18, 95),
        new Student("Bob", 19, 82),
        new Student("Charlie", 18, 91),
        new Student("David", 20, 88),
        new Student("Eva", 19, 97),
        new Student("Frank", 18, 60),
        new Student("Grace", 20, 94),
        new Student("Henry", 19, 73)
);

// 筛选出成绩 ≥ 90 的学生姓名，并转为大写，按姓名排序，取前5个
List<String> topNames = students.stream()
        .filter(s -> s.getScore() >= 90)
        .map(Student::getName)
        .map(String::toUpperCase)
        .sorted()
        .limit(5)
        .toList();
```



### 示例2：分组和统计

```java
// 按年龄分组，统计每组的平均分
Map<Integer, Double> avgByAge = students.stream()
        .collect(Collectors.groupingBy(
                Student::getAge,
                Collectors.averagingDouble(Student::getScore)
        ));
```

## 注意事项

> [!CAUTION]
>
> - Stream **不会修改数据源**。
> - 一个 Stream **只能被消费一次**，终端操作后流即关闭，再次使用会抛出 `IllegalStateException`。
> - 中间操作是**惰性**的，如果没有终端操作，中间操作不会执行。

### 作业二：分组与统计

阅读以下代码，写出输出结果。

```java
import java.util.*;
import java.util.stream.*;

class Product {
    String category;
    double price;
    Product(String category, double price) {
        this.category = category;
        this.price = price;
    }
    public String getCategory() { return category; }
    public double getPrice() { return price; }
}

public class Homework2 {
    public static void main(String[] args) {
        List<Product> products = Arrays.asList(
            new Product("Electronics", 1200.0),
            new Product("Books", 25.0),
            new Product("Electronics", 800.0),
            new Product("Books", 35.0),
            new Product("Clothing", 50.0)
        );
        Map<String, Double> avgPrice = products.stream()
                .collect(Collectors.groupingBy(
                        Product::getCategory,
                        Collectors.averagingDouble(Product::getPrice)
                ));
        avgPrice.forEach((k, v) -> System.out.println(k + " -> " + v));
    }
}
```
