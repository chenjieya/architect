## 什么是注解

**注解（Annotation）** 是 Java 5 引入的一种**元数据**（Metadata）机制，它允许我们在代码中添加**标记**或**配置信息**，而这些信息本身并不直接影响程序的逻辑，但可以被编译器、开发工具或框架在编译时或运行时读取和处理。

> [!NOTE]
>
> 所谓元数据就是 **“用于描述数据的数据”**，这个概念在各种语言以及大模型领域都适用。
>
> 例如**书的正文内容** = **数据**（具体信息）。而**图书馆的索书号、书名、作者、出版日期、摘要、在哪个书架** = **元数据**（描述这本书的辅助信息）。
> 没有元数据，数据就像散落在地上的无尽文字，无法检索、无法归类、无法理解。

注解本质上是一种**特殊的接口**，用 `@interface` 关键字定义。

### 注解的作用

| 作用                 | 说明                                                |
| -------------------- | --------------------------------------------------- |
| **给编译器提供信息** | 如 `@Override` 告诉编译器该方法覆盖了父类方法       |
| **编译期处理**       | 在编译时生成代码、配置文件等（如 Lombok）           |
| **运行时处理**       | 通过反射在运行时读取注解，用于配置框架（如 Spring） |
| **代码文档化**       | 可被 javadoc 工具提取生成文档                       |

## 内置注解（Built-in Annotations）

Java 提供了几个常用的内置注解，位于 `java.lang` 包中。

### `@Override`

标记方法**覆盖**（重写）了父类或接口中的方法。如果方法签名与父类不匹配，编译器会报错。

```java
class Animal {
    public void speak() {
        System.out.println("Animal speaks");
    }
}

class Dog extends Animal {
    @Override
    public void speak() {   // 正确覆盖
        System.out.println("Dog barks");
    }

    // @Override
    // public void speak(String sound) { }  // 编译错误：方法签名不匹配
}
```

### `@Deprecated`

标记某个元素（类、方法、字段等）已过时，不推荐使用，但仍然可以使用。编译器会生成警告。

```java
public class OldClass {
    @Deprecated
    public void oldMethod() {
        // 旧实现
    }

    public void newMethod() {
        // 新实现
    }
}

// 使用
OldClass obj = new OldClass();
obj.oldMethod();  // 编译器警告
obj.newMethod();
```

### `@SuppressWarnings`

抑制编译器警告。通常用于已知无法避免的警告（如未使用变量、泛型转换等）。

```java
public class SuppressDemo {
    @SuppressWarnings("unused")
    public void test() {
        int unused = 10;   // 通常会有警告，此处被抑制
    }

    @SuppressWarnings({"unchecked", "rawtypes"})
    public void rawType() {
        List list = new ArrayList();   // 抑制 raw type 警告
        list.add("hello");
    }
}
```

### `@FunctionalInterface`

标记接口为**函数式接口**（即只有一个抽象方法的接口），编译器会检查是否符合规范。

```java
@FunctionalInterface
public interface Calculator {
    int calculate(int a, int b);
    // int another();  // 编译错误：函数式接口只能有一个抽象方法
}
```

> [!NOTE]
>
> 函数式接口相关内容可以回顾`Lambda表达式`这一节内容

## 元注解（Meta-Annotations）

**元注解**是用于**修饰注解**的注解，它们控制注解的行为和适用范围。所有元注解都位于 `java.lang.annotation` 包中。

### `@Target`

指定注解可以应用的**目标位置**（如类、方法、字段等）。

```java
import java.lang.annotation.Target;
import java.lang.annotation.ElementType;

@Target(ElementType.METHOD)   // 该注解只能用于方法
public @interface MyMethodAnnotation {
}

// 使用
// @MyMethodAnnotation   // 错误：不能用于类
public class Demo {
    @MyMethodAnnotation    // 正确
    public void test() {}
}
```

**常用 `ElementType` 取值：**

| 取值              | 目标             |
| ----------------- | ---------------- |
| `TYPE`            | 类、接口、枚举   |
| `FIELD`           | 字段（成员变量） |
| `METHOD`          | 方法             |
| `PARAMETER`       | 方法参数         |
| `CONSTRUCTOR`     | 构造方法         |
| `LOCAL_VARIABLE`  | 局部变量         |
| `ANNOTATION_TYPE` | 注解类型         |
| `PACKAGE`         | 包               |

多个目标可用花括号指定：`{ElementType.METHOD, ElementType.FIELD}`

### `@Retention`

指定注解的**保留策略**，即注解信息保留到哪个阶段。

```java
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;

@Retention(RetentionPolicy.RUNTIME)   // 注解在运行时保留（可通过反射读取）
public @interface RuntimeAnnotation {
}
```

**`RetentionPolicy` 取值：**

| 取值      | 说明                                                 |
| --------- | ---------------------------------------------------- |
| `SOURCE`  | 只保留在源码中，编译时丢失（如 `@SuppressWarnings`） |
| `CLASS`   | 保留在字节码中，但 JVM 加载时丢失（默认值）          |
| `RUNTIME` | 保留在运行时，可通过反射读取（用于框架配置）         |

### `@Documented`

使注解信息出现在生成的 Javadoc 文档中。

```java
import java.lang.annotation.Documented;

@Documented
public @interface DocAnnotation {
    String value();
}

// 使用该注解的类，在 Javadoc 中会显示注解信息
```

### `@Inherited`

允许子类**继承**父类上的注解（仅对类继承有效，对接口无效）。

```java
import java.lang.annotation.Inherited;

@Inherited
public @interface InheritedAnnotation {
}

@InheritedAnnotation
class Parent {}

class Child extends Parent {}  // Child 自动拥有该注解
```

## 自定义注解

### 定义注解

使用 `@interface` 关键字，可定义**属性**（类似方法声明）。

```java
import java.lang.annotation.*;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Log {
    // 属性：没有默认值，使用时必须指定
    String value();

    // 属性：有默认值，可选
    int level() default 1;
}
```



### 使用自定义注解

```java
public class Service {
    @Log(value = "执行 save 操作", level = 2)
    public void save() {
        System.out.println("保存数据...");
    }

    @Log("执行 delete 操作")   // 当只有一个 value 属性时，可以省略 value= 
    public void delete() {
        System.out.println("删除数据...");
    }
}
```



### 读取注解（运行时通过反射）

```java
import java.lang.reflect.Method;

public class AnnotationReader {
    public static void main(String[] args) throws Exception {
        Method[] methods = Service.class.getDeclaredMethods();
        for (Method method : methods) {
            if (method.isAnnotationPresent(Log.class)) {
                Log log = method.getAnnotation(Log.class);
                System.out.println("方法: " + method.getName());
                System.out.println("  value: " + log.value());
                System.out.println("  level: " + log.level());
            }
        }
    }
}
// 输出：
// 方法: save
//   value: 执行 save 操作
//   level: 2
// 方法: delete
//   value: 执行 delete 操作
//   level: 1
```

> [!NOTE]
>
> - 注解属性支持的类型：基本类型、`String`、`Class`、枚举、注解类型以及以上类型的数组。
> - 若属性名为 `value`，使用时可以省略属性名。

## 注解的应用场景

| 场景          | 说明                                              |
| ------------- | ------------------------------------------------- |
| **框架配置**  | Spring 的 `@Controller`、`@Service`、`@Autowired` |
| **ORM 映射**  | JPA 的 `@Entity`、`@Table`、`@Column`             |
| **测试框架**  | JUnit 的 `@Test`、`@Before`、`@After`             |
| **编译检查**  | `@Override`、`@FunctionalInterface`               |
| **代码生成**  | Lombok 的 `@Getter`、`@Setter`、`@Data`           |
| **日志/监控** | 自定义 `@Log` 记录方法调用                        |

------

## 注意事项

> [!CAUTION]
>
> - 注解本身**不包含业务逻辑**，它只是标记。需要配合**注解处理器**（编译期）或**反射**（运行时）才能真正发挥作用。
> - 注解不能继承（但可以通过 `@Inherited` 让子类继承父类的注解）。
> - 注解的属性值必须是**常量表达式**（编译期确定）。
