## 面向对象编程概述

面向对象编程（Object-Oriented Programming，OOP）是一种编程范式，它将程序组织为**对象**的集合，每个对象包含**数据**（属性）和**行为**（方法）。

### 核心概念

| 概念                      | 说明                           | 生活中的例子                       |
| ------------------------- | ------------------------------ | ---------------------------------- |
| **类（Class）**           | 对象的蓝图或模板               | 建筑设计图                         |
| **对象（Object）**        | 类的具体实例                   | 根据图纸建造的房子                 |
| **封装（Encapsulation）** | 隐藏内部实现细节，暴露必要接口 | 汽车的方向盘和踏板                 |
| **继承（Inheritance）**   | 子类复用父类的属性和方法       | 子承父业                           |
| **多态（Polymorphism）**  | 同一接口，不同实现             | 人都会“说话”，但不同人说话方式不同 |

> [!NOTE]
>
> 本讲聚焦于**类和对象**的基本概念，封装、继承、多态将在下一节中详细展开。

## 类的基本定义

### 类的组成

一个类通常包含以下组成部分：

- **属性（字段/成员变量）**：描述对象的状态
- **方法**：描述对象的行为
- **构造方法**：用于创建和初始化对象

```java
/**
 * 学生类示例
 */
public class Student {
    // 1. 属性（成员变量）
    String name;
    int age;
    String studentId;

    // 2. 方法（行为）
    public void study() {
        System.out.println(name + " 正在学习");
    }

    public void introduce() {
        System.out.println("我是 " + name + "，今年 " + age + " 岁");
    }
}
```



### 类的命名规范

| 规范       | 说明                     | 示例                           |
| ---------- | ------------------------ | ------------------------------ |
| 使用名词   | 类名应表示一个事物或概念 | `Student`, `Car`, `Order`      |
| 大驼峰命名 | 每个单词首字母大写       | `StudentInfo`, `ShoppingCart`  |
| 有意义     | 名称应清晰表达类的含义   | 避免 `Data`, `Info` 等模糊名称 |

## 对象的创建和使用

### 创建对象

使用 `new` 关键字创建对象，即**实例化**（Instantiation）。

```java
public class StudentDemo {
    public static void main(String[] args) {
        // 创建 Student 对象
        Student s1 = new Student();
        Student s2 = new Student();

        // 给属性赋值
        s1.name = "Alice";
        s1.age = 20;
        s1.studentId = "2024001";

        s2.name = "Bob";
        s2.age = 22;
        s2.studentId = "2024002";

        // 调用方法
        s1.introduce();  // 我是 Alice，今年 20 岁
        s1.study();      // Alice 正在学习

        s2.introduce();  // 我是 Bob，今年 22 岁
    }
}
```

> [!NOTE]
>
> - `new` 关键字在堆内存中分配空间，创建对象。
> - 每个对象拥有独立的属性副本，修改一个对象不影响另一个。



### 对象引用和 null

```java
Student s1 = new Student();
Student s2 = s1;        // s2 和 s1 指向同一个对象
s2.name = "Charlie";
System.out.println(s1.name);  // Charlie（s1 也受影响）

Student s3 = null;      // null 表示不指向任何对象
// s3.study();          // 会抛出 NullPointerException
if (s3 != null) {
    s3.study();         // 安全调用
}
```

## 构造方法（Constructor）

构造方法是一种**特殊的方法**，用于在创建对象时初始化对象的状态。

### 构造方法的特征

- 方法名与类名**完全相同**
- **没有返回值类型**（包括 `void`）
- 在 `new` 创建对象时**自动调用**
- 如果不提供，编译器会生成默认无参构造方法

```java
public class Student {
    String name;
    int age;
    String studentId;

    // 无参构造方法
    public Student() {
        System.out.println("调用无参构造方法");
    }

    // 有参构造方法
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("调用有参构造方法");
    }

    public Student(String name, int age, String studentId) {
        this.name = name;
        this.age = age;
        this.studentId = studentId;
    }
}
```



### 构造方法的使用

```java
public class ConstructorDemo {
    public static void main(String[] args) {
        // 调用无参构造
        Student s1 = new Student();  // 调用无参构造方法

        // 调用有参构造
        Student s2 = new Student("Alice", 20);  // 调用有参构造方法

        Student s3 = new Student("Bob", 22, "2024002");
        s3.introduce();
    }
}
```



### 构造方法重载（Overload）

构造方法也可以重载，提供多种初始化方式。

```java
public class Person {
    private String name;
    private int age;
    private String address;

    // 无参构造
    public Person() {
        this("Unknown", 0, "Unknown");  // 调用其他构造
    }

    // 带姓名和年龄的构造
    public Person(String name, int age) {
        this(name, age, "Unknown");
    }

    // 全参构造
    public Person(String name, int age, String address) {
        this.name = name;
        this.age = age;
        this.address = address;
    }
}
```

> [!CAUTION]
>
> - 如果定义了有参构造方法，系统**不会**自动生成无参构造方法。建议显式定义无参构造。
> - 构造方法中可以使用 `this()` 调用其他构造方法，但必须是第一条语句。

## this 关键字

`this` 关键字在实例方法或构造方法中，指向**当前对象**。

### this 的使用场景

1. **区分成员变量和局部变量**（当它们同名时）

```java
public class Person {
    private String name;

    public Person(String name) {
        this.name = name;  // this.name 是成员变量，name 是参数
    }
}
```



2. **在构造方法中调用另一个构造方法**

```java
public class Person {
    private String name;
    private int age;

    public Person() {
        this("Unknown", 0);  // 调用另一个构造方法
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```



3. **作为方法的返回值（链式调用）**

```java
public class Builder {
    private String value;

    public Builder setValue(String value) {
        this.value = value;
        return this;  // 返回当前对象，支持链式调用
    }
}

// 使用
Builder b = new Builder().setValue("hello").setValue("world");
```

> [!CAUTION]
>
> `this` 不能在静态方法中使用（因为静态方法不属于对象）。

## 静态成员（static）

`static` 修饰的成员属于**类**，而不是某个具体对象。

### 静态变量

```java
public class Counter {
    // 实例变量：每个对象拥有独立副本
    private int instanceCount;

    // 静态变量：所有对象共享
    public static int totalCount = 0;

    public Counter() {
        instanceCount++;
        totalCount++;
    }

    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        Counter c3 = new Counter();

        System.out.println(c1.instanceCount);  // 1
        System.out.println(c2.instanceCount);  // 1
        System.out.println(c3.instanceCount);  // 1

        System.out.println(Counter.totalCount); // 3（类名访问）
        System.out.println(c1.totalCount);      // 3（对象访问，不推荐）
    }
}
```



### 静态方法

```java
public class MathHelper {
    // 静态方法：可以直接通过类名调用
    public static int add(int a, int b) {
        return a + b;
    }

    // 静态方法中不能使用 this，只能访问静态成员
    public static void printInfo() {
        System.out.println("MathHelper 工具类");
        // System.out.println(this);  // 编译错误
    }
}

// 调用
int sum = MathHelper.add(5, 3);  // 类名调用
```



### 静态常量（final）

```java
public class Constants {
    public static final double PI = 3.141592653589793;
    public static final int MAX_USERS = 1000;
}
```



### 静态 vs 实例成员总结

| 特性        | 静态成员         | 实例成员           |
| ----------- | ---------------- | ------------------ |
| 属于        | 类               | 对象               |
| 内存分配    | 类加载时分配一次 | 每次创建对象分配   |
| 访问方式    | 类名.成员        | 对象.成员          |
| `this` 可用 | 否               | 是                 |
| 生命周期    | 类加载到类卸载   | 对象创建到垃圾回收 |

> [!NOTE]
>
> - 静态方法只能直接访问静态成员，不能直接访问实例成员。
> - 实例方法可以访问静态成员和实例成员。

## 代码块

### 初始化块

初始化块在创建对象时执行，用于初始化实例成员。

```java
public class Person {
    private String name;
    private int age;

    // 实例初始化块：每次创建对象时执行
    {
        System.out.println("执行实例初始化块");
        this.age = 0;
    }

    // 静态初始化块：类加载时执行一次
    static {
        System.out.println("执行静态初始化块");
    }

    public Person(String name) {
        this.name = name;
        System.out.println("执行构造方法");
    }

    public static void main(String[] args) {
        Person p1 = new Person("Alice");
        Person p2 = new Person("Bob");
    }
}
// 输出：
// 执行静态初始化块
// 执行实例初始化块
// 执行构造方法
// 执行实例初始化块
// 执行构造方法
```

执行顺序：**静态初始化块 → 实例初始化块 → 构造方法**
