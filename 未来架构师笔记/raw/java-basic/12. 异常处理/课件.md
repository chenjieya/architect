## 什么是异常

**异常（Exception）** 是程序在运行过程中发生的**意外事件**，它会中断程序的正常执行流程。Java 提供了一套完善的异常处理机制，使得程序能够**优雅地处理错误**，而不是直接崩溃。

### 异常 vs 错误

| 概念                  | 说明                                    | 示例                           |
| --------------------- | --------------------------------------- | ------------------------------ |
| **异常（Exception）** | 程序可以捕获并处理的意外情况            | 文件不存在、网络断开、数组越界 |
| **错误（Error）**     | 程序无法处理的严重问题，通常由 JVM 引发 | 内存溢出、栈溢出、虚拟机错误   |

> [!NOTE]
>
> 错误（`Error`）通常不是应用程序能够处理或应该处理的，因此异常处理主要针对 `Exception` 及其子类。



### 为什么需要异常处理

1. **程序健壮性**：避免程序因意外情况而崩溃。
2. **用户友好**：给出有意义的错误提示，而不是晦涩的底层错误信息。
3. **资源释放**：确保在错误发生时也能正确释放资源（如文件流、数据库连接）。
4. **业务逻辑分离**：将正常逻辑与错误处理逻辑分开，提高代码可读性。

## Java 异常体系

Java 的异常继承体系如下：

```java
java.lang.Object
    └── java.lang.Throwable
            ├── java.lang.Error              // 严重错误，一般不捕获
            │       ├── VirtualMachineError
            │       ├── OutOfMemoryError
            │       └── ...
            └── java.lang.Exception          // 可处理的异常
                    ├── RuntimeException     // 非检查异常（运行时异常）
                    │       ├── NullPointerException
                    │       ├── IndexOutOfBoundsException
                    │       ├── ArithmeticException
                    │       └── ...
                    └── 其他 Exception       // 检查异常（编译时异常）
                            ├── IOException
                            ├── SQLException
                            ├── FileNotFoundException
                            └── ...
```



### 检查异常（Checked Exception）vs 非检查异常（Unchecked Exception）

| 类型           | 说明                                                  | 编译时检查 | 常见示例                                                     |
| -------------- | ----------------------------------------------------- | ---------- | ------------------------------------------------------------ |
| **检查异常**   | 必须**显式处理**（try-catch 或 throws），否则编译报错 | 是         | `IOException`, `SQLException`, `FileNotFoundException`       |
| **非检查异常** | 不强制处理，通常由编程错误导致                        | 否         | `NullPointerException`, `ArithmeticException`, `ArrayIndexOutOfBoundsException` |
| **错误**       | 与异常类似，但表示严重问题，不推荐捕获                | 否         | `OutOfMemoryError`, `StackOverflowError`                     |

```java
// 检查异常：必须处理
import java.io.*;

public void readFile() throws IOException {  // 必须声明或捕获
    FileReader fr = new FileReader("file.txt");
}

// 非检查异常：可以不处理（但建议处理）
public void divide(int a, int b) {
    int result = a / b;  // 若 b=0，抛出 ArithmeticException（运行时异常）
}
```

> [!CAUTION]
>
> - **检查异常**必须处理，体现了 Java 的“**编译时安全**”哲学。
> - **非检查异常**通常是程序逻辑错误导致，应当通过改进代码来避免，而不是简单地捕获。

## 异常处理关键字

| 关键字    | 说明                                               |
| --------- | -------------------------------------------------- |
| `try`     | 包裹可能抛出异常的代码块                           |
| `catch`   | 捕获并处理特定类型的异常                           |
| `finally` | 无论是否发生异常，都会执行的代码块（用于资源释放） |
| `throw`   | 手动抛出一个异常对象                               |
| `throws`  | 在方法声明处声明可能抛出的异常类型（交由上层处理） |

## try-catch 块

### 基本语法

```java
try {
    // 可能抛出异常的代码
} catch (异常类型1 变量名) {
    // 处理异常类型1
} catch (异常类型2 变量名) {
    // 处理异常类型2
}
```



### 捕获单个异常

```java
public class TryCatchDemo {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[5]);  // 数组索引越界
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("捕获到异常: " + e.getMessage());
        }
        System.out.println("程序继续执行");
    }
}
```



### 捕获多个异常

```java
public class MultiCatch {
    public static void main(String[] args) {
        try {
            int[] arr = null;
            System.out.println(arr.length);   // NullPointerException
            int result = 10 / 0;              // ArithmeticException（如果前句不抛）
        } catch (NullPointerException e) {
            System.out.println("空指针异常: " + e.getMessage());
        } catch (ArithmeticException e) {
            System.out.println("算术异常: " + e.getMessage());
        }
        System.out.println("程序结束");
    }
}
```



### 多异常合并

使用 `|` 合并多个异常类型，要求这些异常没有继承关系。

```java
try {
    // 可能抛出 IOException 或 SQLException
} catch (IOException | SQLException e) {
    // 处理两种异常，e 是 final 的
    System.out.println("IO或SQL异常: " + e.getMessage());
}
```

## finally 块

`finally` 块中的代码**无论是否发生异常，都会执行**，通常用于释放资源（关闭文件流、数据库连接等）。

```java
public class FinallyDemo {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[1]);  // 正常
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("捕获异常");
        } finally {
            System.out.println("finally 块总是执行");
        }
    }
}
// 输出：2
// finally 块总是执行
```



### finally 与 return

如果 `finally` 块中有 `return`，会覆盖 `try` 或 `catch` 中的 `return`。

```java
public class FinallyReturn {
    public static int test() {
        try {
            return 1;
        } finally {
            return 2;   // 覆盖了 try 中的 return
        }
    }
    public static void main(String[] args) {
        System.out.println(test());  // 输出 2
    }
}
```

> [!CAUTION]
>
> - 不要在 `finally` 中使用 `return`，这会掩盖异常或意外改变返回值。
> - `finally` 块中抛出的异常会抑制 `try` 块中抛出的异常。

## throw 和 throws

### throw —— 手动抛出异常

使用 `throw` 关键字主动抛出一个异常对象。

```java
public class ThrowDemo {
    public static void validateAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄必须在 0~150 之间");
        }
        System.out.println("年龄合法: " + age);
    }

    public static void main(String[] args) {
        validateAge(25);   // 正常
        // validateAge(200);  // 抛出 IllegalArgumentException
    }
}
```



### throws —— 声明方法可能抛出异常

在方法签名中使用 `throws` 声明该方法可能抛出的异常类型，通知调用者处理。

```java
import java.io.*;

public class ThrowsDemo {
    // 声明可能抛出 IOException，交给调用者处理
    public static void readFile(String path) throws IOException {
        FileReader fr = new FileReader(path);
        // 读取操作...
    }

    public static void main(String[] args) {
        try {
            readFile("test.txt");  // 调用者必须处理
        } catch (IOException e) {
            System.out.println("文件读取失败: " + e.getMessage());
        }
    }
}
```



### 检查异常的传递

如果方法内部可能抛出检查异常，有两种方式：

1. **捕获处理**（try-catch）
2. **声明抛出**（throws），交由上层调用者处理

```java
// 方式1：内部捕获
public void method1() {
    try {
        FileReader fr = new FileReader("file.txt");
    } catch (FileNotFoundException e) {
        System.out.println("文件不存在");
    }
}

// 方式2：声明抛出
public void method2() throws FileNotFoundException {
    FileReader fr = new FileReader("file.txt");
}
```

> [!NOTE]
>
> - `throws` 可以声明多个异常类型，用逗号分隔。
> - 子类重写父类方法时，抛出的异常不能比父类更宽泛（不能抛出父类未声明的新检查异常）。

## 自定义异常

当 Java 内置的异常无法准确描述业务错误时，可以自定义异常类。

### 创建自定义异常

自定义异常需要继承 `Exception`（检查异常）或 `RuntimeException`（非检查异常）。

```java
// 自定义检查异常
public class AgeOutOfRangeException extends Exception {
    public AgeOutOfRangeException() {
        super("年龄超出合法范围");
    }

    public AgeOutOfRangeException(String message) {
        super(message);
    }
}

// 自定义非检查异常
public class InsufficientBalanceException extends RuntimeException {
    public InsufficientBalanceException(String message) {
        super(message);
    }
}
```



### 使用自定义异常

```java
public class BankAccount {
    private double balance;

    public BankAccount(double balance) {
        this.balance = balance;
    }

    public void withdraw(double amount) throws InsufficientBalanceException {
        if (amount > balance) {
            throw new InsufficientBalanceException("余额不足，当前余额: " + balance);
        }
        balance -= amount;
        System.out.println("取款成功，剩余: " + balance);
    }

    public static void main(String[] args) {
        BankAccount account = new BankAccount(100.0);
        try {
            account.withdraw(150.0);
        } catch (InsufficientBalanceException e) {
            System.out.println("错误: " + e.getMessage());
        }
    }
}
```

## try-with-resources（自动资源管理）

Java 7 引入了 `try-with-resources`，用于自动关闭实现了 `AutoCloseable` 接口的资源（如文件流、数据库连接、网络套接字等）。

### 传统 try-finally 方式

```java
import java.io.*;

public class OldResource {
    public static void readFile(String path) {
        BufferedReader reader = null;
        try {
            reader = new BufferedReader(new FileReader(path));
            String line = reader.readLine();
            System.out.println(line);
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            if (reader != null) {
                try {
                    reader.close();   // 需要再次 try-catch
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}
```



### try-with-resources 方式

资源对象在 `try` 后面的括号中声明，**自动调用 `close()`**，代码更简洁安全。

```java
import java.io.*;

public class TryWithResources {
    public static void readFile(String path) {
        try (BufferedReader reader = new BufferedReader(new FileReader(path))) {
            String line = reader.readLine();
            System.out.println(line);
        } catch (IOException e) {
            e.printStackTrace();
        }
        // reader 自动关闭
    }
}
```



### 多个资源

多个资源用分号分隔，关闭顺序与声明顺序相反。

```java
try (FileInputStream fis = new FileInputStream("in.txt");
     FileOutputStream fos = new FileOutputStream("out.txt")) {
    // 使用两个流
} catch (IOException e) {
    e.printStackTrace();
}
```

## 异常处理最佳实践

| 实践                           | 说明                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| **捕获具体异常**               | 不要捕获 `Exception` 或 `Throwable` 这种通用类型，应捕获具体子类 |
| **记录异常日志**               | 使用日志框架（如 SLF4J）记录异常信息，便于排查问题           |
| **不要忽略异常**               | 空的 catch 块（不处理异常）是严重的错误实践                  |
| **尽早抛出，晚捕获**           | 异常在合适的层级抛出，在合适的层级捕获处理                   |
| **避免在 finally 中抛出异常**  | 可能掩盖原始异常                                             |
| **使用自定义异常表达业务错误** | 让异常更有语义                                               |

```java
// 反例：捕获通用异常
try {
    // ...
} catch (Exception e) {  // 不推荐
    // 会捕获所有异常，包括不该处理的
}

// 正例：捕获具体异常
try {
    // ...
} catch (FileNotFoundException e) {
    // 处理文件不存在
} catch (IOException e) {
    // 处理其他 IO 异常
}
```

### 作业四：try-with-resources 改写

以下代码使用了传统的 try-finally 管理资源，请将其改写为 try-with-resources 形式。

```java
import java.io.*;

public class Homework4 {
    public static void copyFile(String src, String dest) {
        FileInputStream in = null;
        FileOutputStream out = null;
        try {
            in = new FileInputStream(src);
            out = new FileOutputStream(dest);
            byte[] buffer = new byte[1024];
            int len;
            while ((len = in.read(buffer)) != -1) {
                out.write(buffer, 0, len);
            }
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                if (in != null) in.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
            try {
                if (out != null) out.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
}
```
