## 为什么要学Java？

### 语言特性：成熟的技术特性

- 强大的语言特性：性能与并发能力、稳定与强类型安全、生态成熟
- 广泛的应用范围：Java是企业级系统的基石，绝大多数企业的核心业务系统（如金融、电商、ERP等）都基于Java构建

### AI整合集成：庞大的人员需求

- Java在**“AI工程化”**这后半程的价值无可替代。AI要真正产生价值，必须与这些现有系统深度融合，而Java正是实现这种融合的最佳桥梁

- 市场对人才的需求也在发生变化。传统的、只做增删改查（CRUD）的Java岗位确实在减少，但市场对 **“懂AI的Java工程师”** 需求极其旺盛

  

## 怎么学Java？

### 全栈时代的要求

- 企业不需要你对某一项技术非常精通，而是需要全面的技术体系
- 企业不需要你掌握详细的“古法编程”，但需要你知道如何基于场景来选择特定的Java技术

### 关注知识体系

#### 知识体系的重要性：两个身边的真实同事面试示例

- A同学
  - 动手能力强，但缺乏系统的知识沉淀，针对问题没有解决方案
  - 面试11次，一面失败5次，二面失败6次，三面失败2次，历时半年仍未入职，已放弃
- B同学
  - 技术水平与A同学相当，但对技术概念和原理有自己的总结和思想，能够实现技术选型
  - 每一面都顺利通过，一次性走完所有流程，历时1个半月入职闲鱼

#### 知识体系的三个层次：体会

- 知道这个技术
- 应用这个技术
- 选择这个技术（当下）

#### 知识体系的相通性（触类旁通）：两个案例分析

##### 案例1：响应式/事件驱动

- 场景描述：

  你去网红奶茶店买奶茶。你点完单，店员给你一张小票（上面有取餐号），然后让你不用在柜台前死等，可以去旁边逛一逛。等到奶茶做好了，店员主动喊号，你听到号再去取。

    前端（你的手机 / 网页）：
    你在网页上点击“查询物流”按钮。前端不会让网页卡住干等，而是发起请求后，先让页面可以继续滚动。等后端把数据传回来了，前端触发一个回调事件，才去更新页面上的物流信息。
  
    后端（Java 服务器）：
    双十一大量下单，后端不会一个请求占用一个线程去死等数据库返回，而是把请求注册成一个“待办事件”。等数据库查完了，主动触发事件把结果扔回给前端。这个过程中，后端线程被释放出来去处理别的请求。

- 两者的相通点：

  以前是“你主动去问”（轮询/同步阻塞），现在是“做好了通知你”（回调/事件驱动）。 前后端都在做同一件事：不浪费资源干等着，而是等事情做完了，通过“喊号”（事件）来通知对方。前端避免了页面卡死，后端避免了线程堆积。

##### 案例2：代理/拦截器

- 场景描述：

  你是公司老板（业务代码）。你不需要亲自订机票、筛选推销电话、安排会议室，这些事都由你的行政秘书（代理Proxy）在中间处理。所有找你的人（调用方）都先经过秘书，秘书觉得重要才转给你，你只管专心做核心决策，甚至不知道秘书帮你挡掉了多少杂事。

    前端（Vue 的数据代理）：
    你在代码里写 this.name = "小明"（你想改个数据）。但 Vue 在背后用“代理”拦截了这个赋值动作，它偷偷额外做了两件事：① 把页面上的文字自动更新成“小明”；② 把这次修改记录到日志里。而你作为开发者，根本不知道代理的存在，你以为只是在改变量。
  
    后端（Spring 的 AOP 事务代理）：
    你在 Java 里写 userService.saveUser()（你想保存一个用户）。但 Spring 在背后用“代理”拦截了这个方法调用，它偷偷额外做了两件事：① 在调用前开启数据库事务；② 在调用成功后提交事务（失败则回滚）。而你作为开发者，根本不知道代理的存在，你以为只是在调用一个普通保存方法。

- 两者的相通点：

  核心逻辑不变（改数据 / 存用户），但前后端都在“核心操作”外面套了一个透明的“拦截层”。 这个拦截层可以在你不察觉的情况下，帮你把“附带工作”（更新界面、管理事务、打印日志、校验权限）给做了。这就像秘书帮你挡掉琐事，让你只专心干活。

| 技术点              | 前端像什么               | 后端像什么               | 共通本质（一句话）           |
| ------------------- | ------------------------ | ------------------------ | ---------------------------- |
| **响应式/事件驱动** | 等快递到了再通知你下楼   | 等数据库查完了再通知前端 | 别傻等，干完了喊我           |
| **代理/拦截器**     | 改数据时顺便自动刷新网页 | 存数据时顺便自动管理事务 | 你做核心事，中间人帮你干杂事 |
