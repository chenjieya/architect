## `final` 的精细化

### final 修饰变量

```java
// 基本类型：值不可变
final int MAX_SIZE = 100;
// MAX_SIZE = 200;  // 编译错误

// 引用类型：引用不可变，但对象内容可变
final List<String> list = new ArrayList<>();
list.add("hello");  // ✅ 对象内容可以修改
// list = new ArrayList<>();  // ❌ 引用不能重新赋值

// 空白final：声明时不赋值，构造方法中赋值
public class BlankFinal {
    private final int value;

    public BlankFinal(int value) {
        this.value = value;
    }
}
```

### final 修饰方法

```java
class Parent {
    // 该方法不可被子类重写
    public final void importantMethod() {
        System.out.println("重要方法，不能修改");
    }

    public void normalMethod() {
        System.out.println("普通方法");
    }
}

class Child extends Parent {
    // @Override
    // public void importantMethod() {}  // ❌ 编译错误：不能重写final方法

    @Override
    public void normalMethod() {}  // ✅ 可以重写
}
```

### final 修饰类

```java
// 不可被继承的类（如 String、Integer 就是 final 类）
final class ImmutableClass {
    private final String value;

    public ImmutableClass(String value) {
        this.value = value;
    }
}

// class ChildClass extends ImmutableClass {}  // ❌ 编译错误
```

### 最佳实践总结

| 场景     | 建议                              |
| -------- | --------------------------------- |
| 常量值   | 使用 `public static final`        |
| 方法参数 | 不希望被修改时加 `final`          |
| 实例字段 | 不可变对象中加 `final`            |
| 核心方法 | 不希望被子类重写时加 `final`      |
| 工具类   | 使用 `final class` + 私有构造方法 |

> [!NOTE]
>
> 现代Java中，`final` 让代码意图更清晰，有助于JVM优化和防止错误。



## 枚举（enum）

### 什么是枚举

枚举是一种**特殊的类**，用于定义一组**固定的常量**。它提供类型安全的常量定义方式，比传统的`public static final`更强大、更安全。

**为什么需要枚举：**

- 让代码更易读、更安全（限定取值范围）
- 可附加方法和字段，不仅仅是常量
- 编译器会检查赋值是否合法

### 定义枚举

```java
// 基本枚举
public enum Season {
    SPRING, SUMMER, AUTUMN, WINTER
}

// 枚举带字段和方法
public enum Status {
    SUCCESS(0, "成功"),
    FAILURE(1, "失败"),
    PENDING(2, "处理中");

    private final int code;
    private final String message;

    Status(int code, String message) {
        this.code = code;
        this.message = message;
    }

    public int getCode() { return code; }
    public String getMessage() { return message; }

    public static Status fromCode(int code) {
        for (Status s : Status.values()) {
            if (s.code == code) return s;
        }
        throw new IllegalArgumentException("Unknown code: " + code);
    }
}
```

### 使用枚举

```java
public class EnumDemo {
    public static void main(String[] args) {
        // 基本使用
        Season season = Season.SUMMER;
        System.out.println("当前季节: " + season);

        // 带字段的枚举
        Status status = Status.SUCCESS;
        System.out.println("状态码: " + status.getCode());
        System.out.println("状态信息: " + status.getMessage());

        // 遍历枚举
        for (Status s : Status.values()) {
            System.out.println(s + " -> " + s.getCode());
        }

        // 通过代码获取枚举
        Status found = Status.fromCode(1);
        System.out.println("找到状态: " + found);

        // 枚举的比较
        System.out.println(status == Status.SUCCESS); // true
        System.out.println(status.equals(Status.SUCCESS)); // true
    }
}
```

### 枚举 vs 常量类

| 对比       | 常量类（`public static final`） | 枚举（enum）       |
| ---------- | ------------------------------- | ------------------ |
| 类型安全   | ❌ 任何int/string都合法          | ✅ 只能是枚举值     |
| 方法扩展   | ❌ 不支持                        | ✅ 可添加字段和方法 |
| 遍历       | ❌ 需手动实现                    | ✅ `values()`方法   |
| 编译器检查 | ❌ 运行时才能发现错误            | ✅ 编译期检查       |



## 文本块（Text Blocks）

### 什么是文本块

**文本块（Text Blocks）** 是Java 15引入的特性，用于简化多行字符串的编写。它以`"""`开头和结尾，保留换行和缩进。

**在文本块之前：**

```java
String html = "<html>\n" +
              "    <body>\n" +
              "        <h1>Hello</h1>\n" +
              "    </body>\n" +
              "</html>";
```

**使用文本块：**

```java
String html = """
              <html>
                  <body>
                      <h1>Hello</h1>
                  </body>
              </html>
              """;
```

### 基本语法

```java
// 基本文本块
String json = """
              {
                  "name": "Alice",
                  "age": 25,
                  "city": "Beijing"
              }
              """;

// 嵌入表达式（使用 String.format 或 formatted）
String name = "Bob";
int age = 30;
String message = """
                 姓名: %s
                 年龄: %d
                 状态: 活跃
                 """.formatted(name, age);

// 行末去除换行（使用 \）
String singleLine = """
                    这是一行 \
                    虽然写了两行 \
                    但实际是一行
                    """;
System.out.println(singleLine);  // "这是一行 虽然写了两行 但实际是一行"
```

> [!NOTE]
> 文本块的缩进规则：**最左的非空格缩进**决定了所有行的基础缩进。上面的例子中，`<html>`是整段文本缩进最少的行（有4个空格），这4个空格会被自动移除。



## Record类

### 什么是Record

**Record**是Java 14引入的**数据载体类**，用于代替传统的Java Bean类（只有字段、构造方法、getter、equals/hashCode/toString）。Record会自动生成构造方法、访问器、`equals()`、`hashCode()`和`toString()`方法。

### Record vs 传统Java Bean

**传统Java Bean（代码冗长）：**

```java
public class Person {
    private final String name;
    private final int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }

    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }

    @Override
    public boolean equals(Object o) {
        // 繁琐的实现...
    }

    @Override
    public int hashCode() {
        // 繁琐的实现...
    }
}
```

**使用Record（极简）：**

```java
public record Person(String name, int age) {}
```

### 使用Record

```java
public record Person(String name, int age) {
    // 可以添加自定义构造方法（校验逻辑）
    public Person {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄必须在0~150之间");
        }
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("姓名不能为空");
        }
    }

    // 可以添加自定义方法
    public String greeting() {
        return "你好，我是" + name + "，今年" + age + "岁";
    }
}

public class RecordDemo {
    public static void main(String[] args) {
        Person person = new Person("Alice", 25);
        // 自动生成的访问器（注意命名：与字段名一致，而非传统的getXxx）
        System.out.println(person.name());
        System.out.println(person.age());
        // 自动生成的toString
        System.out.println(person);  // Person[name=Alice, age=25]
        // 自动生成的equals和hashCode
        Person p2 = new Person("Alice", 25);
        System.out.println(person.equals(p2));  // true
        // 自定义方法
        System.out.println(person.greeting());
    }
}
```

### 适用场景

| 适用场景            | 不适用场景                    |
| ------------------- | ----------------------------- |
| 数据传输对象（DTO） | 需要可变状态的对象            |
| 值对象（VO）        | 有复杂业务逻辑的领域对象      |
| 方法多返回值        | 需要继承其他类的对象          |
| 临时数据聚合        | 需要被JPA/Hibernate管理的实体 |



## Optional 容器类

### 什么是Optional

**Optional**是Java 8引入的容器类，用于**明确表示一个值可能存在也可能不存在**。它旨在减少`NullPointerException`，强制开发者处理空值情况。

### 创建Optional

```java
// 创建非空Optional（值为null会抛出异常）
Optional<String> opt1 = Optional.of("hello");

// 创建可能为空的Optional
Optional<String> opt2 = Optional.ofNullable(getName());

// 创建空Optional
Optional<String> opt3 = Optional.empty();
```

### 使用Optional

```java
public class OptionalDemo {
    public static void main(String[] args) {
        // 1. isPresent() + get()（不推荐，等于传统的null检查）
        Optional<String> opt = Optional.ofNullable("hello");
        if (opt.isPresent()) {
            System.out.println(opt.get());
        }

        // 2. 推荐方式：函数式处理
        // ifPresent：存在则执行
        opt.ifPresent(value -> System.out.println("值: " + value));

        // 3. orElse：存在则返回原值，否则返回默认值
        String result = Optional.ofNullable(getName())
                .orElse("默认值");

        // 4. orElseGet：存在则返回原值，否则通过Supplier生成默认值
        String result2 = Optional.ofNullable(getName())
                .orElseGet(() -> "计算生成的默认值");

        // 5. orElseThrow：存在则返回原值，否则抛出异常
        String result3 = Optional.ofNullable(getName())
                .orElseThrow(() -> new RuntimeException("值不存在"));

        // 6. map：存在则转换，不存在则返回空Optional
        Optional<Integer> length = Optional.ofNullable("hello")
                .map(String::length);  // Optional[5]

        // 7. filter：存在且满足条件则返回自身，否则返回空Optional
        Optional<String> filtered = Optional.ofNullable("hello")
                .filter(s -> s.length() > 3);  // Optional[hello]

        // 8. flatMap：存在则通过函数返回Optional，否则返回空Optional
        Optional<Integer> result4 = Optional.ofNullable("123")
                .flatMap(s -> {
                    try {
                        return Optional.of(Integer.parseInt(s));
                    } catch (NumberFormatException e) {
                        return Optional.empty();
                    }
                });
    }

    private static String getName() {
        return null;  // 模拟可能为空
    }
}
```

### 最佳实践

```java
// ❌ 错误：使用Optional作为字段、方法参数或集合元素
public class User {
    private Optional<String> name;  // 不推荐！
}

public void process(Optional<User> user) { }  // 不推荐！
List<Optional<String>> list;  // 不推荐！

// ✅ 正确：Optional只用于方法返回值
public Optional<User> findUser(String id) {
    // 可能返回空，明确告知调用者
}

// ✅ 正确：链式处理
public String getCity(String userId) {
    return findUser(userId)
        .map(User::getAddress)
        .map(Address::getCity)
        .orElse("未知城市");
}
```



## `==` 与 `equals` 的终极对比

### 核心区别

| 对比     | `==`                             | `equals()`               |
| -------- | -------------------------------- | ------------------------ |
| 基本类型 | 比较**值**                       | 不适用                   |
| 引用类型 | 比较**内存地址**（是否同一对象） | 比较**内容**（逻辑相等） |
| 能否重写 | ❌ 不能                           | ✅ 可以                   |

### 详细示例

```java
public class EqualsDemo {
    public static void main(String[] args) {
        // ========== 基本类型 ==========
        int a = 5;
        int b = 5;
        System.out.println(a == b);  // true（比较值）

        // ========== 引用类型 ==========
        String s1 = "hello";
        String s2 = "hello";
        String s3 = new String("hello");

        System.out.println(s1 == s2);  // true（字符串常量池复用）
        System.out.println(s1 == s3);  // false（不同对象）
        System.out.println(s1.equals(s3));  // true（内容相同）

        // ========== 自定义类 ==========
        Person p1 = new Person("Alice", 25);
        Person p2 = new Person("Alice", 25);
        System.out.println(p1 == p2);  // false（不同对象）
        System.out.println(p1.equals(p2));  // true（如果重写了equals）

        // ========== 重要：Integer 缓存 ==========
        Integer i1 = 127;
        Integer i2 = 127;
        System.out.println(i1 == i2);  // true（-128~127缓存）

        Integer i3 = 128;
        Integer i4 = 128;
        System.out.println(i3 == i4);  // false（超出缓存范围）
        System.out.println(i3.equals(i4));  // true

        // ========== null 处理 ==========
        String str = null;
        // str.equals("hello");  // NullPointerException!
        System.out.println("hello".equals(str));  // false（安全）
        System.out.println(Objects.equals(str, "hello"));  // false（安全）
    }
}

class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Person p = (Person) obj;
        return age == p.age && Objects.equals(name, p.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }
}
```

### 判断规则速查

```
== 判断规则：
1. 基本类型 → 比较值
2. 引用类型 → 比较地址（是否同一对象）

equals 判断规则：
1. 默认（Object类） → 同 ==
2. 重写后（如String、Integer、自定义类） → 比较内容
3. 调用前务必确保对象非null → 用 Objects.equals()
```



## assert 断言语法

### 什么是断言

**断言（assert）** 是Java中的一种**调试工具**，用于在开发阶段检测程序中的假定条件是否为真。断言默认是禁用的，需要JVM参数启用。

```java
// 基本语法
assert 条件;

// 带错误信息的断言
assert 条件 : "错误消息";
```

### 基本使用

```java
public class AssertDemo {
    public static int divide(int a, int b) {
        // 断言：除数不能为0
        assert b != 0 : "除数不能为0";
        return a / b;
    }

    public static int factorial(int n) {
        // 断言：n 不能为负数
        assert n >= 0 : "n必须是非负数";
        if (n == 0 || n == 1) return 1;
        return n * factorial(n - 1);
    }

    public static void process(int value) {
        // 断言：value 在有效范围内
        assert value >= 0 && value <= 100 : "value必须在0~100之间";
        System.out.println("处理值: " + value);
    }

    public static void main(String[] args) {
        // 默认：断言被禁用，不会执行
        System.out.println(divide(10, 0));  // 算术异常

        // 启用断言的方式见下文
    }
}
```

### 启用断言

Java命令启动：

```java
# 启用所有类的断言
java -ea AssertDemo

# 启用特定类的断言
java -ea:com.example.AssertDemo AssertDemo

# 启用特定包的断言
java -ea:com.example... AssertDemo

# 禁用特定包的断言
java -ea -da:com.example.legacy... AssertDemo
```

IDEA中的设置步骤：

```java

选择目标配置：在弹出的窗口左侧，选择你想要启用断言的运行/调试配置。

添加VM参数：
- 在右侧窗口，点击 “Modify options”**（修改选项），然后在下拉菜单中选择 **“Add VM options”**（添加VM选项）。这会在界面中显示一个“VM options”输入框。

输入参数：在 “VM options” 文本框中，输入 `-ea` 或 `-enableassertions`
```

### 断言 vs 异常

| 对比     | assert       | 异常（Exception） |
| -------- | ------------ | ----------------- |
| 适用阶段 | 开发期调试   | 生产期处理        |
| 默认状态 | 禁用         | 总是启用          |
| 用途     | 检测程序错误 | 处理运行期错误    |
| 捕获     | 不应该被捕获 | 可以被捕获处理    |

> [!CAUTION]
> 不要在生产环境中依赖断言来处理业务逻辑，因为断言可能被禁用。使用异常来处理运行时错误。



## 常用工具类

### Objects 工具类

`Objects` 提供操作对象的静态方法，安全处理 null。

```java
import java.util.Objects;

public class ObjectsDemo {
    public static void main(String[] args) {
        // 1. equals：安全比较（处理null）
        System.out.println(Objects.equals("hello", "hello"));  // true
        System.out.println(Objects.equals(null, "hello"));     // false
        System.out.println(Objects.equals("hello", null));     // false

        // 2. hashCode：安全获取hashCode
        System.out.println(Objects.hashCode("hello"));  // 99162322
        System.out.println(Objects.hashCode(null));     // 0

        // 3. hash：计算多个字段的hashCode
        System.out.println(Objects.hash("Alice", 25));  // 组合hash

        // 4. requireNonNull：检查非空，为空则抛异常
        String name = null;
        // String result = Objects.requireNonNull(name);  // NullPointerException
        // String result2 = Objects.requireNonNull(name, "名称不能为空");

        // 5. toString：安全toString（null返回"null"）
        System.out.println(Objects.toString(null));  // "null"
        System.out.println(Objects.toString(null, "默认值"));  // "默认值"

        // 6. compare：安全比较
        String a = "apple";
        String b = "banana";
        System.out.println(Objects.compare(a, b, String::compareTo));  // -1

        // 7. isNull / nonNull
        System.out.println(Objects.isNull(null));    // true
        System.out.println(Objects.nonNull(null));   // false
    }
}
```

### Collections 工具类

`Collections` 提供操作集合的静态方法（排序、查找、同步包装、不可变包装等）。

```java
import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {
        // ========== 排序 ==========
        List<Integer> numbers = new ArrayList<>(Arrays.asList(3, 1, 4, 1, 5));
        Collections.sort(numbers);  // 升序
        System.out.println(numbers);  // [1, 1, 3, 4, 5]
        Collections.sort(numbers, Collections.reverseOrder());  // 降序

        // ========== 查找 ==========
        int index = Collections.binarySearch(numbers, 3);  // 需先排序
        System.out.println("位置: " + index);

        // ========== 不可变集合 ==========
        List<String> unmodifiable = Collections.unmodifiableList(
            new ArrayList<>(Arrays.asList("a", "b", "c"))
        );
        // unmodifiable.add("d");  // UnsupportedOperationException!

        // ========== 同步集合（线程安全包装） ==========
        List<String> syncList = Collections.synchronizedList(new ArrayList<>());
        Map<String, String> syncMap = Collections.synchronizedMap(new HashMap<>());

        // ========== 初始化 ==========
        List<Integer> emptyList = Collections.emptyList();  // 空列表
        Set<String> singleton = Collections.singleton("唯一");  // 单元素集合

        // ========== 填充和复制 ==========
        List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
        Collections.fill(list, "x");  // [x, x, x]
        Collections.copy(new ArrayList<>(list), list);  // 复制

        // ========== 最大/最小 ==========
        System.out.println(Collections.max(numbers));  // 最大值
        System.out.println(Collections.min(numbers));  // 最小值

        // ========== 频率统计 ==========
        System.out.println(Collections.frequency(numbers, 1));  // 出现次数

        // ========== 旋转 ==========
        Collections.rotate(numbers, 2);  // 循环右移2位
    }
}
```

### Arrays 工具类

`Arrays` 提供操作数组的静态方法（排序、查找、填充、转换等）。

```java
import java.util.Arrays;

public class ArraysDemo {
    public static void main(String[] args) {
        // ========== toString ==========
        int[] arr = {3, 1, 4, 1, 5};
        System.out.println(Arrays.toString(arr));  // [3, 1, 4, 1, 5]

        // ========== 排序 ==========
        Arrays.sort(arr);
        System.out.println(Arrays.toString(arr));  // [1, 1, 3, 4, 5]

        // ========== 二分查找 ==========
        int index = Arrays.binarySearch(arr, 3);
        System.out.println("位置: " + index);

        // ========== 填充 ==========
        Arrays.fill(arr, 0);
        System.out.println(Arrays.toString(arr));  // [0, 0, 0, 0, 0]

        // ========== 复制 ==========
        int[] copy = Arrays.copyOf(arr, 10);  // 扩容复制
        int[] range = Arrays.copyOfRange(arr, 0, 3);  // 截取复制

        // ========== 比较（deepEquals处理多维数组） ==========
        int[][] matrix1 = {{1, 2}, {3, 4}};
        int[][] matrix2 = {{1, 2}, {3, 4}};
        System.out.println(Arrays.equals(matrix1, matrix2));        // false
        System.out.println(Arrays.deepEquals(matrix1, matrix2));    // true

        // ========== 转字符串（多维） ==========
        System.out.println(Arrays.deepToString(matrix1));  // [[1, 2], [3, 4]]

        // ========== 数组转List ==========
        List<Integer> list = Arrays.asList(1, 2, 3, 4, 5);
        // list.add(6);  // UnsupportedOperationException!

        // ========== 并行操作 ==========
        Arrays.parallelSort(arr);          // 并行排序
        Arrays.parallelSetAll(arr, i -> i * 2);  // 并行设置
    }
}
```



## 代码风格与规范（Google Java Style）

### 为什么需要代码规范

- **统一性**：团队所有成员代码风格一致，降低认知负荷
- **可读性**：代码更容易阅读、理解和维护
- **代码审查**：减少风格讨论，聚焦业务逻辑

### Google Java Style 核心要点

#### 缩进与空格

```java
// ✅ 使用4个空格缩进（不使用Tab）
// ✅ 每行最大长度100字符
// ✅ 大括号换行风格：K&R风格

public class Example {  // { 不换行
    public void method() {  // { 不换行
        if (condition) {
            // 代码
        } else {
            // 代码
        }
    }
}
```

#### 命名规范

| 类型     | 规范                     | 示例                          |
| -------- | ------------------------ | ----------------------------- |
| 类名     | 大驼峰（PascalCase）     | `ClassName`, `UserService`    |
| 方法名   | 小驼峰（lowerCamelCase） | `getUserById()`               |
| 变量名   | 小驼峰                   | `userName`, `totalCount`      |
| 常量名   | 全大写+下划线            | `MAX_SIZE`, `DEFAULT_TIMEOUT` |
| 包名     | 全小写                   | `com.example.util`            |
| 类型参数 | 单个大写字母             | `T`, `E`, `K`, `V`            |

#### 导入语句

