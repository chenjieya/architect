# 抽象类和接口

## 课程目标

- 理解抽象类的概念、定义和使用场景
- 理解接口的概念、定义和实现
- 能够根据设计需要选择抽象类或接口

------



## 抽象类（Abstract Class）

抽象类是不能被实例化的类，用于定义一些公共的抽象方法，由子类实现。

### 为什么需要抽象类

在继承层次结构中，某些父类过于抽象，不应该被实例化。例如 `Shape` 类，它的 `area()` 方法无法给出有意义的实现，只有具体的子类（如 `Circle`、`Rectangle`）才知道如何计算面积。抽象类正是为了这种场景而设计。

### 定义抽象类和方法

使用 `abstract` 关键字修饰类和方法。

```java
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法（没有方法体）：计算面积
    public abstract double area();

    // 抽象方法（没有方法体）：计算周长
    public abstract double perimeter();

    // 普通方法（子类可继承）
    public void displayColor() {
        System.out.println("颜色: " + color);
    }
}
```



### 子类实现抽象方法

```java
public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }
}

public class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }
}
```



### 抽象类的使用

```java
public class ShapeDemo {
    public static void main(String[] args) {
        // Shape s = new Shape("red");  // 编译错误：不能实例化抽象类
        
        Shape[] shapes = {
            new Circle("红色", 5.0),
            new Rectangle("蓝色", 3.0, 4.0)
        };
        
        for (Shape s : shapes) {
            System.out.println("面积: " + s.area());
            System.out.println("周长: " + s.perimeter());
            s.displayColor();
        }
    }
}
```



### 抽象类要点

| 要点     | 说明                                               |
| -------- | -------------------------------------------------- |
| 实例化   | 不能实例化，只能被继承                             |
| 抽象方法 | 子类必须实现所有抽象方法？？？，除非子类也是抽象类 |
| 具体方法 | 可以包含具体方法，供子类直接使用或重写             |
| 构造方法 | 可以有构造方法（供子类调用）                       |
| 成员变量 | 可以有任意类型的成员变量                           |

> [!NOTE]
>
> - 抽象类可以没有抽象方法（但通常不这么用）。
> - 抽象方法不能是 `private` 或 `final`（因为需要被子类实现）。

## 接口（Interface）

接口是一种完全抽象的类型，只包含常量和抽象方法。

### 定义接口

使用 `interface` 关键字定义接口。

```java
public interface Drawable {
    // 常量（默认为 public static final）
    String TYPE = "图形";

    // 抽象方法（默认为 public abstract）
    void draw();
}
```



### 实现接口（implements）

注意：一个类可以实现多个接口。

```java
public class Circle extends Shape implements Drawable {
    // ... 继承 Shape 的代码 ...

    @Override
    public void draw() {
        System.out.println("画一个圆形");
    }
}

public class Rectangle extends Shape implements Drawable, Comparable<Rectangle> {
    // 实现多个接口
    @Override
    public void draw() {
        System.out.println("画一个矩形");
    }

    @Override
    public int compareTo(Rectangle o) {
        return Double.compare(this.area(), o.area());
    }
}
```



### 接口中的默认方法（Java 8）

默认方法允许接口提供方法的默认实现，避免修改所有实现类。

```java
public interface Movable {
    void move();

    // 默认方法
    default void stop() {
        System.out.println("停止移动");
    }
}

class Car implements Movable {
    @Override
    public void move() {
        System.out.println("汽车行驶");
    }
    // 可以选择重写 stop()
}
```



### 接口中的静态方法（Java 8）

静态方法属于接口本身，通过接口名调用。

```java
public interface Utility {
    static void printMessage(String msg) {
        System.out.println(msg);
    }
}

// 调用
Utility.printMessage("Hello");
```

> [!NOTE]
>
> - Java 8 起，接口可以包含 `default` 方法和 `static` 方法。
> - Java 9 起，接口可以包含 `private` 方法（用于辅助默认方法和静态方法）。



### 接口中的私有方法（Java 9）

```java
public interface Calculator {
    default int add(int a, int b) {
        return sum(a, b);
    }

    private int sum(int a, int b) {
        return a + b;
    }
}
```



### 接口的多实现与多态

接口也可以实现多态。

```java
public class InterfaceDemo {
    public static void main(String[] args) {
        Drawable d1 = new Circle("红色", 5.0);
        Drawable d2 = new Rectangle("蓝色", 3, 4);
        
        d1.draw();
        d2.draw();
        d1.printInfo();  // 调用默认方法
        
        Drawable.printMessage("Hello");  // 调用接口静态方法
    }
}
```

## 抽象类 vs 接口

| 特性       | 抽象类                       | 接口                                                         |
| ---------- | ---------------------------- | ------------------------------------------------------------ |
| 关键字     | `abstract class`             | `interface`                                                  |
| 实例化     | 不能                         | 不能                                                         |
| 多继承     | 单继承                       | 多实现                                                       |
| 成员变量   | 可以定义任意变量             | 只能是 `public static final` 常量                            |
| 方法       | 可以有抽象和具体方法         | 抽象方法（默认 `public abstract`），Java 8+ 可以有默认方法和静态方法 |
| 构造方法   | 有                           | 无                                                           |
| 访问修饰符 | 可以使用各种修饰符           | 方法默认 `public`，Java 9 +可以为 `private`                  |
| 使用场景   | 提供通用的基础实现，代码复用 | 定义行为契约，支持多继承                                     |

> [!IMPORTANT]
>
> 选择指导：
>
> - **抽象类**：当多个类有共同的代码（字段或方法实现）时，使用抽象类。
> - **接口**：当需要定义一种行为契约，且不同类型的类都需要实现时，使用接口。
> - **通用原则**：通常优先使用接口，以支持更灵活的设计。Java推崇“`面向接口编程`”。
>



## 综合示例：绘图系统（抽象类 + 接口）

```java
// 抽象类
abstract class Shape {
    protected String color;
    public Shape(String color) { this.color = color; }
    public abstract double area();
    public void displayColor() { System.out.println("颜色: " + color); }
}

// 接口
interface Drawable {
    void draw();
    default void printInfo() { System.out.println("这是一个可绘制的图形"); }
}

// 子类实现继承和接口
class Circle extends Shape implements Drawable {
    private double radius;
    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }
    @Override
    public double area() { return Math.PI * radius * radius; }
    @Override
    public void draw() { System.out.println("画圆形，面积: " + area()); }
}

class Rectangle extends Shape implements Drawable, Comparable<Rectangle> {
    private double width, height;
    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }
    @Override
    public double area() { return width * height; }
    @Override
    public void draw() { System.out.println("画矩形，面积: " + area()); }
    @Override
    public int compareTo(Rectangle o) {
        return Double.compare(this.area(), o.area());
    }
}

public class GraphicsDemo {
    public static void main(String[] args) {
        Drawable[] items = {
            new Circle("红色", 5.0),
            new Rectangle("蓝色", 3.0, 4.0)
        };
        for (Drawable d : items) {
            d.draw();
            d.printInfo();
            if (d instanceof Shape) {
                ((Shape) d).displayColor();
            }
            System.out.println();
        }
    }
}
```
