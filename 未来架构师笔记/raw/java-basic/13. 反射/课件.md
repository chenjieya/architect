## 什么是反射

**反射（Reflection）** 是 Java 语言提供的一种**运行时**机制，它允许程序在运行时**获取**任何类的内部信息（如构造方法、成员方法、字段、注解等），并且可以**动态创建**对象、调用方法、修改字段值。

反射使得 Java 具有了**动态性**，是许多框架（如 Spring、MyBatis、JUnit）的核心技术基础。

### 为什么需要反射

在常规编程中，我们使用 `new` 关键字创建对象，使用 `.` 调用方法，所有这些都在**编译时**确定。反射则允许我们在**运行时**才决定要操作哪个类、哪个方法，实现更加灵活的程序设计。

```java
// 常规方式（编译时确定）
Student s = new Student();
s.setName("Alice");

// 反射方式（运行时确定）
Class<?> clazz = Class.forName("Student");
Object obj = clazz.newInstance();
Method method = clazz.getMethod("setName", String.class);
method.invoke(obj, "Alice");
```

## 获取 `Class` 对象

Java 中每个类在运行时都有一个对应的 `Class` 对象，它包含了该类的完整元数据。获取 `Class` 对象有三种方式：

### 1. 通过 `类名.class`

适用于已知类名的场景，编译时确定。

```java
Class<Student> clazz1 = Student.class;
Class<Integer> clazz2 = int.class;  // 基本类型也可以
```



### 2. 通过 `对象.getClass()`

通过已有对象获取其类信息。

```java
Student s = new Student();
Class<?> clazz = s.getClass();
```



### 3. 通过 `Class.forName(String className)`

使用类的**全限定名**（包名 + 类名）动态加载类，最常用，编译时不需要该类存在。

```java
try {
    Class<?> clazz = Class.forName("com.example.Student");
} catch (ClassNotFoundException e) {
    e.printStackTrace();
}
```

## 通过反射获取类信息

### 获取构造方法

| 方法                                                 | 说明                                   |
| ---------------------------------------------------- | -------------------------------------- |
| `getConstructors()`                                  | 获取所有 **public** 构造方法           |
| `getDeclaredConstructors()`                          | 获取所有构造方法（包括 private）       |
| `getConstructor(Class<?>... parameterTypes)`         | 获取指定参数的 public 构造方法         |
| `getDeclaredConstructor(Class<?>... parameterTypes)` | 获取指定参数的构造方法（包括 private） |

### 获取成员方法

| 方法                                                         | 说明                                           |
| ------------------------------------------------------------ | ---------------------------------------------- |
| `getMethods()`                                               | 获取所有 **public** 方法（包括继承的）         |
| `getDeclaredMethods()`                                       | 获取当前类所有方法（包括 private，不包括继承） |
| `getMethod(String name, Class<?>... parameterTypes)`         | 获取指定 public 方法                           |
| `getDeclaredMethod(String name, Class<?>... parameterTypes)` | 获取指定方法（包括 private）                   |

### 获取字段

| 方法                            | 说明                                   |
| ------------------------------- | -------------------------------------- |
| `getFields()`                   | 获取所有 **public** 字段（包括继承的） |
| `getDeclaredFields()`           | 获取当前类所有字段（包括 private）     |
| `getField(String name)`         | 获取指定 public 字段                   |
| `getDeclaredField(String name)` | 获取指定字段（包括 private）           |

### 获取注解（后面课程介绍）

| 方法                                      | 说明                       |
| ----------------------------------------- | -------------------------- |
| `getAnnotations()`                        | 获取所有注解（包括继承的） |
| `getDeclaredAnnotations()`                | 获取当前类上直接声明的注解 |
| `getAnnotation(Class<T> annotationClass)` | 获取指定类型的注解         |

## 通过反射创建对象

> 使用 `Constructor.newInstance()`

```java
Class<?> clazz = Class.forName("com.example.Student");
// 获取无参构造
Constructor<?> constructor = clazz.getConstructor();
Student s = (Student) constructor.newInstance();

// 获取有参构造
Constructor<?> constructor2 = clazz.getConstructor(String.class, int.class);
Student s2 = (Student) constructor2.newInstance("Alice", 25);
```

## 通过反射调用方法

使用 `Method.invoke(Object obj, Object... args)` 执行方法。

```java
Class<?> clazz = Class.forName("com.example.Student");
Object obj = clazz.newInstance();

// 获取 setName 方法
Method setName = clazz.getMethod("setName", String.class);
setName.invoke(obj, "Alice");

// 获取 getName 方法
Method getName = clazz.getMethod("getName");
String name = (String) getName.invoke(obj);
System.out.println(name);  // Alice
```



### 调用私有方法

```java
Method privateMethod = clazz.getDeclaredMethod("privateMethod");
privateMethod.setAccessible(true);  // 取消访问检查
privateMethod.invoke(obj);
```

> [!CAUTION]
>
> `setAccessible(true)` 可以破坏封装性，应谨慎使用，仅在必要时（如框架开发、单元测试）使用。

## 通过反射访问字段

### 访问 public 字段

```java
Class<?> clazz = Class.forName("com.example.Student");
Object obj = clazz.newInstance();

Field field = clazz.getField("publicField");
field.set(obj, "value");
Object value = field.get(obj);
System.out.println(value);
```



### 访问 private 字段

```java
Field field = clazz.getDeclaredField("privateField");
field.setAccessible(true);   // 取消访问检查
field.set(obj, "newValue");
Object value = field.get(obj);
System.out.println(value);
```

## 反射操作数组

反射可以动态创建和操作数组。

```java
import java.lang.reflect.Array;

// 创建 int[] 数组，长度为 5
Object array = Array.newInstance(int.class, 5);
// 设置元素
Array.set(array, 0, 10);
Array.set(array, 1, 20);
// 获取元素
int value = Array.getInt(array, 0);
System.out.println(value);  // 10
System.out.println(Array.getLength(array));  // 5
```

## 反射的优缺点

### 优点

- **动态性**：可在运行时决定要操作哪个类、方法，提高灵活性。
- **框架基础**：为众多 Java 框架（Spring、Hibernate、JUnit）提供了底层支持。
- **通用功能实现**：可编写通用的工具类（如 JSON 解析器、ORM 映射器）。

### 缺点

- **性能开销**：反射操作比常规调用慢（尤其是 `setAccessible(true)` 和 `invoke`），性能敏感场景需注意。
- **破坏封装**：`setAccessible(true)` 可以访问私有成员，可能破坏设计原则。
- **安全隐患**：反射可绕过访问控制，可能引发安全问题。
- **代码可读性差**：代码变得晦涩，难以调试。
- **编译时检查缺失**：方法名、字段名以字符串形式存在，编译时无法检查拼写错误，容易引发运行时异常。

> [!CAUTION]
>
> 在考虑引入反射功能时需要综合评估应用场景的需求，谨慎使用

## 典型应用场景

| 场景             | 说明                                  |
| ---------------- | ------------------------------------- |
| **开发框架**     | Spring 的依赖注入、AOP 等基于反射实现 |
| **ORM 框架**     | 将数据库表字段映射到 Java 对象属性    |
| **单元测试**     | JUnit 通过反射执行 `@Test` 方法       |
| **动态代理**     | 通过 `Proxy` 和反射实现接口的动态代理 |
| **配置文件解析** | 根据配置文件中的类名动态加载类        |
| **开发工具**     | IDE 的代码补全、调试器都使用反射      |
