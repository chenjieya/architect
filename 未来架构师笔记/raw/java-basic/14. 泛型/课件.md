## 什么是泛型

**泛型（Generics）** 是 Java SE 5 引入的特性，允许在定义类、接口和方法时使用**类型参数**（Type Parameter）。类型参数在使用时被具体的类型（如 `String`、`Integer`）替换，从而让代码能够适用于多种数据类型。

泛型的本质是**参数化类型**，即“类型”本身可以作为参数传递。

### 为什么需要泛型

在引入泛型之前，Java 使用 `Object` 类型来实现通用代码，但存在两个严重问题：

**问题 1：类型不安全**

```java
// 没有泛型时：使用 Object 存储
List list = new ArrayList();
list.add("hello");
list.add(123);        // 可以存入任何类型

String s = (String) list.get(0);  // 需要强制转换
// String s2 = (String) list.get(1); // 运行时 ClassCastException！
```



**问题 2：需要强制类型转换**

每次从集合中取出元素，都必须手动转换为目标类型，繁琐且容易出错。

**使用泛型后的改进：**

```java
// 使用泛型：指定元素类型
List<String> list = new ArrayList<>();
list.add("hello");
// list.add(123);   // 编译错误！类型不匹配

String s = list.get(0);   // 无需强制转换
```

## 泛型类（Generic Class）

### 定义泛型类

在类名后面使用尖括号 `<T>` 声明一个或多个类型参数。

```java
public class Box<T> {
    private T content;

    public void set(T content) {
        this.content = content;
    }

    public T get() {
        return content;
    }

    public static void main(String[] args) {
        Box<String> stringBox = new Box<>();
        stringBox.set("Hello");
        System.out.println(stringBox.get());  // Hello

        Box<Integer> intBox = new Box<>();
        intBox.set(123);
        System.out.println(intBox.get());     // 123
    }
}
```



### 类型参数命名约定

| 名称      | 含义                        |
| --------- | --------------------------- |
| `T`       | Type（类型）                |
| `E`       | Element（元素，常用于集合） |
| `K`       | Key（键，常用于 Map）       |
| `V`       | Value（值，常用于 Map）     |
| `N`       | Number（数字）              |
| `S, U, V` | 第 2、3、4 个类型参数       |

### 泛型类的实例化

```java
// Java 7 之前
Box<String> box1 = new Box<String>();

// Java 7+ 菱形语法（类型推断）
Box<String> box2 = new Box<>();   // 可以省略右边的类型参数
```

> [!NOTE]
>
> 泛型类型参数**必须是引用类型**，不能是基本类型（如 `int`、`double`）。
>
> ```java
>Box<int> box = new Box<>();   // 编译错误！
> Box<Integer> box = new Box<>(); // 正确：使用包装类
> ```

## 泛型方法（Generic Method）

### 定义泛型方法

泛型方法的类型参数声明在**返回值类型之前**，用尖括号 `<>` 括起来。

```java
public class GenericMethodDemo {
    // 泛型方法：交换数组中的两个元素
    public static <T> void swap(T[] array, int i, int j) {
        T temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }

    // 泛型方法：返回泛型数组中的第一个元素
    public static <T> T getFirst(T[] array) {
        if (array == null || array.length == 0) {
            return null;
        }
        return array[0];
    }

    public static void main(String[] args) {
        String[] words = {"Hello", "World", "!"};
        swap(words, 0, 1);
        System.out.println(Arrays.toString(words)); // [World, Hello, !]

        Integer[] nums = {10, 20, 30};
        Integer first = getFirst(nums);
        System.out.println(first); // 10
    }
}
```



### 泛型方法 vs 泛型类

| 特性           | 泛型类                   | 泛型方法             |
| -------------- | ------------------------ | -------------------- |
| 类型参数作用域 | 整个类                   | 仅该方法             |
| 声明位置       | 类名后面                 | 返回值类型前面       |
| 使用场景       | 类的多个方法共享同一类型 | 单个方法需要类型参数 |

```java
public class GenericClass<T> {
    private T value;

    // 类级别的类型参数 T
    public T getValue() { return value; }

    // 独立的泛型方法：类型参数 U 与类无关
    public <U> U convert(U input) {
        return input;
    }
}
```

## 泛型接口（Generic Interface）

### 定义泛型接口

```java
public interface Pair<K, V> {
    K getKey();
    V getValue();
}

// 实现泛型接口
public class OrderedPair<K, V> implements Pair<K, V> {
    private K key;
    private V value;

    public OrderedPair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    @Override
    public K getKey() { return key; }

    @Override
    public V getValue() { return value; }

    public static void main(String[] args) {
        Pair<String, Integer> pair = new OrderedPair<>("age", 25);
        System.out.println(pair.getKey() + " = " + pair.getValue());
    }
}
```

## 类型通配符（Wildcard）

使用 `?` 表示**未知类型**，用于泛型参数中的灵活匹配。

### 无界通配符：`<?>`

表示任意类型，常用于方法参数中。

```java
public static void printList(List<?> list) {
    for (Object obj : list) {
        System.out.println(obj);
    }
}

// 调用
List<String> names = Arrays.asList("Alice", "Bob");
List<Integer> nums = Arrays.asList(1, 2, 3);
printList(names); // 可以传入 String 列表
printList(nums);  // 可以传入 Integer 列表
```

> [!CAUTION]
>
> 使用 `List<?>` 时，**不能添加元素**（除了 `null`），因为类型未知，无法保证类型安全。
>
> ```java
>List<?> list = new ArrayList<String>();
> // list.add("hello");  // 编译错误！
> list.add(null);         // 可以添加 null
> ```

### 上界通配符：`<? extends T>`

表示类型必须是 `T` 或其子类，可以**读取**但不能**写入**。

```java
// 计算数字列表的总和
public static double sumList(List<? extends Number> list) {
    double sum = 0;
    for (Number n : list) {
        sum += n.doubleValue();
    }
    return sum;
}

// 调用
List<Integer> ints = Arrays.asList(1, 2, 3);
List<Double> doubles = Arrays.asList(1.5, 2.5);
System.out.println(sumList(ints));    // 6.0
System.out.println(sumList(doubles)); // 4.0
```

### 下界通配符：`<? super T>`

表示类型必须是 `T` 或其父类，可以**添加** `T` 类型的元素。

```java
// 向列表中添加整数
public static void addIntegers(List<? super Integer> list) {
    list.add(10);
    list.add(20);
    list.add(30);
}

// 调用
List<Number> numbers = new ArrayList<>();
addIntegers(numbers);  // 可以添加

List<Object> objects = new ArrayList<>();
addIntegers(objects);  // 也可以添加
```



### PECS 原则（Producer-Extends, Consumer-Super）

| 场景                 | 推荐通配符      | 说明                      |
| -------------------- | --------------- | ------------------------- |
| 读取数据（Producer） | `<? extends T>` | 从容器中取出 `T` 或其子类 |
| 写入数据（Consumer） | `<? super T>`   | 向容器中放入 `T` 或其父类 |

```java
// Producer：读取数据，使用 extends
// Consumer：消费数据，使用 super
public static void copy(List<? extends Number> src, List<? super Number> dest) {
    for (Number n : src) {
        dest.add(n);
    }
}
```

> [!NOTE]
>
> 泛型和多态特性紧密结合，注意配合使用。

## 泛型的使用限制

### 不允许类型参数实例化

```java
public class MyClass<T> {
    // public T create() {
    //     return new T();  // 编译错误！
    // }
}
```

解决方案：通过传入 `Class<T>` 对象，使用反射。

```java
public T create(Class<T> clazz) throws Exception {
    return clazz.newInstance();
}
```



### 不允许创建泛型数组

```java
// T[] array = new T[10];  // 编译错误
```

解决方案：使用 `ArrayList` 或创建 `Object[]` 后强制转换。

```java
@SuppressWarnings("unchecked")
T[] array = (T[]) new Object[10];
```

## 泛型与继承

### 泛型类的继承关系

```java
List<String> strings = new ArrayList<>();
List<Object> objects = strings;  // 编译错误！

// 即使 String 是 Object 的子类，List<String> 也不是 List<Object> 的子类
```



### 通配符实现继承

```java
List<String> strings = new ArrayList<>();
List<?> wildcard = strings;           // 正确
List<? extends Object> covariant = strings; // 正确
```

## 完整示例：泛型在集合中的应用

```java
import java.util.*;

public class GenericCollectionDemo {
    public static void main(String[] args) {
        // 1. List 泛型
        List<String> names = new ArrayList<>();
        names.add("Alice");
        names.add("Bob");
        // names.add(123); // 编译错误

        // 2. Set 泛型
        Set<Integer> scores = new HashSet<>();
        scores.add(95);
        scores.add(87);

        // 3. Map 泛型
        Map<String, Integer> studentMap = new HashMap<>();
        studentMap.put("Alice", 95);
        studentMap.put("Bob", 87);

        // 4. 遍历泛型集合
        for (Map.Entry<String, Integer> entry : studentMap.entrySet()) {
            System.out.println(entry.getKey() + " -> " + entry.getValue());
        }
    }
}
```
