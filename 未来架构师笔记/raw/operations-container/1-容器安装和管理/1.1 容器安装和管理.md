一、容器安装和管理

1、容器介绍

1）、Docker 是基于 Go 语言实现的开源容器项目，诞生于 2013 年年初，最初发 起者是 dotCloud 公司。

2）、现在主流的 Linux 操作系统都已经支持 Docker。例如，红帽公司的 RHEL 6.5/CentOS 6.5 往上的操作系统、Ubuntu14.04 往上的操作系统，都已经在软件 源中默认带有 Docker 软件包。

3）、Docker 的构想是要实现“Build，Ship and Run Any App，Anywhere”， 即通过对应用的封装(Packaging)、分发(Distribution)、部署 (Deployment)、运行(Runtime)生命周期进行管理，达到应用组件“一次封装，到处运行”的目的。这里的应用组件，既可以是一个 Web 应用、一个编译环境，也可以是一套数据库平台服务，甚至是一个操作系统或集群。

3、容器、镜像、仓库

1）、仓库(Repository)是集中存放镜像的地方， 仓库可以被认为是一个具体的项目或目录。

2）、注册服务器(Registry)是管理仓库的具体服务器，每个服务器上可以有多个仓库，而每个仓库下面有多个镜像。

3）、例如对于仓库地址 dl.dockerpool.com/ubuntu 来说，dl.dockerpool.com 是注册服务器(Registry)，ubuntu 是仓库(Repository)

​ Docker Hub（公共仓库）登录——docker login 注册成功后，本地用户目录的 .dockercfg 中将保存用户的认证信(Linux 中) 然后之后就能够进行之前学习的一些操作，如拉取镜像等

​ 私有仓库——docker-registrydocker-registry 是官方提供的工具，可以用于构建私有的镜像仓库 有时候，我们并不想把自己的项目公开，只想自己使用。这时我们就需要自己建立自己的 docker hub

4、基本操作

容器服务启动#systemctl start docker.service //新版本不需要服务管理

注意：二进制安装时启动 docker 服务使用 dockerd &

#docker search 镜像名字 //搜索镜像

#docker pull ubuntu //从 docker 官方仓库下载镜像

#docker images //查看当前系统有哪些镜像

开启容器

#docker run -t -i ubuntu /bin/bash //docker run -d -it ubuntu /bin/bash

新建并启动一个容器，可以基于某个镜像开无数个容器

这里的-t 是让 docker 分配一个伪终端，-i 是让容器的标准输入保持打开 也可以加-d 放后台运行

确认系统上有哪些容器

#docker ps -a 如果进入容器后，退出想重新进入原来的容器，可以使用如下步骤和命令来完成

docker start 容器 id

＃docker attach 容器的名字 //也可以使用 docker exec 或者第三方软件 nsenter

docker exec -it 容器名字或容器 id /bin/bash

镜像和容器的导出、导入、删除

#docker save -o ubuntu_14.04.tar ubuntu:14.04 //导出镜像

#docker load < ubuntu_14.04.tar //导入镜像

#docker rmi ubuntu //删除镜像

#docker rm 容器 id //删除容器

#docker export 容器 id 的前 4 个字符 > test_con.tar //导出容器

#cat test_con.tar |docker import - test/ubunut:v1.0 //导入容器

容器的存储－数据卷

#docker run -d -P --name web -v /webapp train/webapp python app.py

-d 后台运行一个容器

-P 允许外部访问容器需要开放的端口

--name web 运行容器时起的名字 web -v /webapp 创建一个数据卷并挂载在容器的/webapp 目录下

train/webapp 该容器创建的时候所基于的镜像名字

python app.py 创建好容器时运行的命令

#docker run -d -P --name web -v /lcoal/dir:/docker/dir:ro train/webapp python app.py

-v /local/dir:/docker/dir:ro /local/dir 是宿主机的目录，/docker/dir 是容器内的目录，ro 是说挂载到容器来的目录只读，未加 ro 的话默认是 rw

#docker run -d -P --name web -v ~/.bash_history:/.bash_history ubuntu /bin/bash

也可以从主机挂载单个文件到容器中做为数据卷 数据卷容器

#docker run -it --name ubuntu_c -v /dbdata docker.io/ubuntu

/dbdata 目录不存在的话，也会自动在容器中创建出来

利用 docker.io/ubuntu 的镜像，建立一个叫 ubuntu_c 的容器，数据卷为/dbdata

#docker run -it --name db1 --volumes-from ubuntu_c docker.io/ubuntu

利用 docker.io/ubuntu 的镜像，建立容器 db1，挂载 ubuntu_c 容器中的数据卷

创建容器并进入容器

#docker run -d -P -it --name ubuntu_test_volume -v /local/dir:/docker/dir ubuntu /bin/bash

#docker exec -it ubuntu_test_volume /bin/bash

1）一个是允许映射容器内应用的服务端口到本地宿主主机。 当使用-P（大写的）标记进，Docker 会随机映射一个端口到内部容器开放的网络端口

docker run -it -P httpd

使用-p 来指定端口映射

docker run -d -p 5000:80 httpd:latest

docker run -d -p 5001:5001 -p 3000:80 httpd

docker run -d -p 127.0.0.1:5000:80 httpd

docker run -it -p 5000:80 docker.io/imagine10255/centos6-lnmp-php56 /bin/bash

docker logs -f 加镜像名字 //确认刚刚做的映射

2）一个是互联机制实现多个容器间通过容器名来快速访问

容器连接（linking）是另一种方式，它会在源和接受的容器之间创建一个隧道，接收的容器可以看到源容器的信息。

备注：容器有自己的内部网络和 IP 地址，使用 docker inspect + 容器 ID 可以获取容器的具体信息
