其他问题：
1、为什么每次提交的时候都让我输用户名和密码呢
有两种办法：
1）ssh 密钥方式

    生成SSH密钥对：在终端中运行ssh-keygen -t rsa -b 4096 -C "your_email@example.com"，按照提示保存密钥，默认生成id_rsa和id_rsa.pub两个文件。
    将公钥添加到远程仓库：登录远程仓库，找到SSH密钥设置页面，添加生成的id_rsa.pub文件中的公钥。
    修改本地Git仓库的远程URL：使用命令git remote set-url origin git@github.com:username/repo.git，将username和repo替换为你的远程仓库用户名和仓库名称。

2）git 凭据存储
git config --global credential.helper store

2、如何清理 git config  
git config --global --unset user.name
git config --global --unset user.email
或者

rm -f ~/.gitconfig

三、其他命令介绍

#git status
这个命令可以查看当前的状态：
untrack files 是指尚未被 git 所管理的文件；changed but not updated 是指文件被 git 管理，并且发生了改变，但改动还没被 git 管理；这两种状态，都可以看成是改动还没被 git 管理的状态，我们这里称非 stage 状态。
changes to be commited 是指进入 stage 状态的文件，stage 是 commit 和未管理之间的一个状态，也有别名叫 index 状态，也就是 git 已经管理了这些改动，但是还没完成提交。
.gitignore 中的文件，不会出现在以上三个状态中
#git rm 操作介绍
#git reset 操作 git reset 会将所有 stage 的文件状态，都改变成非 stage 状
#git diff  
git diff 可以查看当前不在 stage 状态的改动，加参数--cached 可以查看 stage 状态的差异，还可以指定文件名；如 git diff --cached 1.txt 可以查看 stage 状态的 1.txt 的差异
#git log //查看提交的历史,注释写的好，看历史的时候会很清楚
