## 一、我们现在在哪

前面的课程里，你学会了写前端、写后端，项目在**自己的电脑上**能跑起来。这一块要解决的是：**怎么把它放到服务器上，让别人也能访问，并且长期稳定地运行。**

整个路线一共 7 个阶段：

```text
阶段一        阶段二      阶段三          阶段四     阶段五     阶段六      阶段七
Linux 基础 →  Docker  →  Nginx 与      →  K8S   →  CI/CD  →  监控观测 →  云上部署
(你在这里)               并发数据服务
```

> **你现在站在起点：阶段一。** 后面所有的阶段，都是在 Linux 服务器上做的。

## 二、为什么要先学 Linux

- **绝大多数服务器，跑的都是 Linux。** 你写的项目，最终基本都是部署到 Linux 上运行的。
- **后面学的每一样东西，都是在 Linux 里操作的。** Docker、Nginx、K8S、CI/CD、监控，打开就是命令行。这一阶段没学好，后面会处处卡住。
- **服务器没有图形界面。** 它不是靠鼠标点，而是靠命令行远程操作，这是你和服务器沟通的“语言”。

**一句话：Linux 是后面所有内容的地基。**

## 四、命令很多，不用怕

你会看到很多命令和参数。**先说清楚：没有人能把它们全背下来，也不需要。**

真正的做法是：

| 忘了怎么办                  | 怎么做                                                   |
| --------------------------- | -------------------------------------------------------- |
| 忘了某条命令怎么写          | 翻教材里每章末尾的**命令速查**                           |
| 忘了某个参数是什么意思      | `命令 --help`，或者 `man 命令`                           |
| 遇到没见过的报错            | 把报错**原样复制**，搜索，或者**问 AI**                  |
| 想让 AI 帮你写一条命令或脚本 | 可以问，但**要看得懂它给的命令**，再执行                 |

所以，你不需要“记住”，你要掌握的是**三件事**：

1. **知道有这个命令**：遇到问题，脑子里知道“应该用哪一类命令”
2. **看得懂输出**：命令执行完，能判断结果是正常还是有问题
3. **知道危险在哪**：哪些命令会删东西、改配置、影响别人

> **这个阶段真正要练的，是排查问题的思路：** 先看状态，再看日志，再看环境。命令只是工具。

## 五、怎么学

**1. 一定要自己动手敲。** 只看不敲，一周后就忘了。教材里每个小节的“动手练习”，请务必做完。

**2. 学习环境统一：**

| 项目     | 配置                                          |
| -------- | --------------------------------------------- |
| 系统     | Rocky Linux 9（最小安装，没有图形界面）       |
| 虚拟机   | 4 核 CPU，8 GB 内存，40 GB 磁盘               |
| 用户     | 普通用户 `duyi`（可以使用 `sudo`）            |
| 练习目录 | `~/lab`（练坏了，重新生成一遍就好）           |

> 你的电脑内存如果只有 8 GB，虚拟机先给 4 GB，具体见第一章。

**3. 动手之前先“拍快照”。** 虚拟机软件里有“快照”功能，相当于游戏存档。做危险操作之前拍一个，改坏了可以回到原来的样子。

**4. 出错不可怕。** 你练习的是一台**随时可以重装的虚拟机**，大胆试。出错之后看报错、查日志，这本身就是学习。

**5. 有几件事，只在虚拟机里做：** 删除文件（`rm`）、改系统配置、关闭防火墙……**真正的生产服务器上，先想清楚再动手。** 教材里会反复提醒你：**会改什么？能回滚吗？影响多大？**

## 六、学完这个阶段，你应该能

- [ ] 自己装好一台 Rocky Linux 虚拟机，并用 `ssh` 远程登录
- [ ] 在命令行里查看文件和日志，搜索内容，修改配置，并且知道先备份
- [ ] 管理服务（`systemctl`），看服务日志（`journalctl`）
- [ ] 看懂文件权限，遇到 `Permission denied` 知道怎么查
- [ ] 用 `dnf` 安装软件
- [ ] 服务访问不了时，能一层一层排查：服务、端口、防火墙
- [ ] 服务器变慢时，能判断是 CPU、内存、磁盘还是句柄的问题
- [ ] 写简单的 Shell 脚本，看懂别人的脚本
