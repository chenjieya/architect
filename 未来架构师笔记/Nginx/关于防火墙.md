[[Nginx 安装.pdf]]
##### 1. 关闭防火墙

```shell
systemctl stop firewalld.service
```

##### 2. 禁止防火墙开机启动

```shell
systemctl disable firewalld.service
```

##### 3. 放行端口

```shell
firewall-cmd --zone=public --add-port=80/tcp --permanent
```

##### 4. 重载规则

```shell
firewall-cmd --reload
```

##### 5. 重启防火墙

```shell
systemctl restart firewalld
```

##### 6. 查看已配置规则

```shell
firewall-cmd --list-all
```

##### 7. 指定端口和ip访问

```shell
firewall-cmd --permanent --add-rich-rule="rule family="ipv4" source address="192.168.1.19" port protocol="tcp" port="8080" accept"
```

##### 8. 移除规则

```shell
firewall-cmd-permanent --remove-rich-rule="rule family="ipv4" source address="192.168.1.19" port protocol="tcp" port="8080" accept"
```
