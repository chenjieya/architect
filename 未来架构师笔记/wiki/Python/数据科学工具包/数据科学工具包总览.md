## 1. 课程定位

《数据科学工具包》（作者：袁进）面向 **AI Agents 应用开发**，即用这些库去处理数据、展示结果，而不是模型训练/微调/部署/推理。

课程围绕两大块能力：

- **数据处理**：`NumPy` 与 `Pandas`——数据分析和科学计算的基石，是 Agent 处理结构化数据的核心工具。
- **数据可视化**：`Matplotlib` 与 `Seaborn`——把枯燥的数据转化为直观的图表，是 Agent"秀出"分析成果的关键。

## 3. 工程环境

- 课件以 **Jupyter Notebook** 格式编写，用 VS Code 的 Jupyter 插件运行。
- 解释器必须选**当前工程虚拟环境**中的 Python，切勿用其他环境。
- 用 **uv** 管理工程，装依赖统一用 `uv add <package>`。

```shell
# 初始化 uv 工程并安装 jupyter
uv init .
uv add --dev jupyter

# 各章节按需添加依赖
uv add numpy==2.5.1
uv add pandas==3.0.3 openpyxl==3.1.5
uv add matplotlib ipympl
```

交互式绘图（动画、控件）需要先启用 ipympl 后端：`%matplotlib widget`。
