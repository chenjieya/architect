## 1. 概述

本节介绍使用 **`java.nio.file.Files`**、**`BufferedReader`/`BufferedWriter`** 进行文本文件的读写，以及 **`try-with-resources`** 自动关闭资源，避免泄漏与忘记 `close()`。

## 2. 核心概念

| 术语                                 | 说明                                              |
| ------------------------------------ | ------------------------------------------------- |
| `Path`                               | `java.nio.file.Path`，表示文件或目录路径          |
| `Paths.get(...)`                     | 将字符串转为 `Path`                               |
| `Files.readAllLines`                 | 一次性读取文本文件全部行，返回 `List<String>`     |
| `Files.write`                        | 将字节或行写入文件                                |
| `BufferedReader`                     | 带缓冲的字符输入流，适合按行读取大文件            |
| `BufferedWriter`                     | 带缓冲的字符输出流                                |
| `try-with-resources`                 | `try (资源声明) { }` 块结束自动调用 **`close()`** |
| `Charset` / `StandardCharsets.UTF_8` | 指定读写文本编码，避免乱码                        |
| `IOException`                        | 文件读写可能抛出的受检异常，须捕获或 `throws`     |

## 3. 操作步骤

在 IDEA 中完成文件读写：

1. **在项目根或 `src` 旁** 新建目录 `data`，新建空文件 `sample.log`
2. **新建** `FileIODemo.java`，用 **`Files.write`** 写入两行 UTF-8 文本
3. **用** `Files.readAllLines` 读回并打印
4. **新建** `LogFileReader.java`，用 **`BufferedReader`** 按行读取同一文件
5. **全部使用** `try-with-resources`，确认无手动 `close()`
6. **运行** 后检查 `data/sample.log` 内容与控制台一致
7. **故意** 读不存在的路径，观察 `IOException` 信息（捕获后打印友好提示）

## 4. 语法与写法

### 4.1 Path 与 Files 快捷读写

```java
// 文件：FileIODemo.java
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.Arrays;
import java.util.List;

public class FileIODemo {
    public static void main(String[] args) {
        Path path = Paths.get("data", "sample.log");

        try {
            List<String> lines = Arrays.asList(
                    "2026-06-05 INFO 应用启动",
                    "2026-06-05 INFO 加载配置完成"
            );
            Files.write(path, lines, StandardCharsets.UTF_8);

            List<String> read = Files.readAllLines(path, StandardCharsets.UTF_8);
            read.forEach(System.out::println);
        } catch (Exception e) {
            System.err.println("文件操作失败：" + e.getMessage());
        }
    }
}
```

### 4.2 BufferedReader 按行读取

```java
// 文件：LogFileReader.java
import java.io.BufferedReader;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

public class LogFileReader {
    public static void main(String[] args) {
        Path path = Paths.get("data", "sample.log");

        try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (line.contains("ERROR")) {
                    System.out.println("发现错误行：" + line);
                } else {
                    System.out.println(line);
                }
            }
        } catch (Exception e) {
            System.err.println("读取失败：" + e.getMessage());
        }
    }
}
```

### 4.3 try-with-resources 结构

```java
try (BufferedWriter writer = Files.newBufferedWriter(path, StandardCharsets.UTF_8)) {
    writer.write("第一行");
    writer.newLine();
    writer.write("第二行");
}  // 自动 close，即使发生异常也会尝试关闭
```

### 4.4 与旧 File 类（认识）

```java
// 初学优先 Path + Files；java.io.File 仍可见于老代码
Path p = Paths.get("data", "sample.log");
boolean exists = Files.exists(p);
```

## 5. 常见用法

1. **配置文件一行一条**：`Files.readAllLines` 读入再 Stream 处理
2. **追加日志**：`Files.write(path, line, UTF_8, StandardOpenOption.APPEND)`（认识 `APPEND`）
3. **大文件逐行**：`BufferedReader.readLine()` 避免一次性载入内存
4. **导出报表**：`BufferedWriter` 循环写入 CSV 行

## 6. 易错点

- **未指定 UTF-8**：Windows 默认编码可能导致中文乱码
- **忘记关闭流**：不用 try-with-resources 时须在 `finally` 中 `close()`，否则句柄泄漏
- **相对路径工作目录**：IDEA 运行时的「当前目录」通常是**项目根**；路径不对会 `NoSuchFileException`
- **一次性 `readAllLines` 读超大文件**：内存占用高；大文件改 **BufferedReader**
- **写入前未创建父目录**：`data` 不存在时需 `Files.createDirectories(path.getParent())`（了解）

## 7. 本节小结

- 路径用 **`Path` / `Paths.get`**；简单读写用 **`Files`**
- 按行处理大文件用 **`BufferedReader`**
- 一律优先 **`try-with-resources` + `StandardCharsets.UTF_8`**
