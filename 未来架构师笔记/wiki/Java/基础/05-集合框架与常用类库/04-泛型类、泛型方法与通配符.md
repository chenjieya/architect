> 所属：集合框架与泛型 · Java 面向对象与核心类库

## 1. 概述

**泛型（Generics）** 让类、接口、方法在定义时使用**类型参数**（如 `T`），在编译期约束集合元素类型，避免频繁强转与运行期 **`ClassCastException`**。本节覆盖 **泛型类**、**泛型方法** 与 **通配符** 的入门写法。

## 2. 核心概念

| 术语                     | 说明                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| 类型参数                 | 如 `T`、`E`、`K`、`V`，在定义时占位，使用时换成具体类型                                              |
| 泛型类                   | `class Box<T> { ... }`，创建时 `new Box<String>()`                                                   |
| 泛型方法                 | 方法自有类型参数，如 `<T> void print(T item)`                                                        |
| 类型擦除（Type Erasure） | 编译后泛型信息大部分被擦除，运行期主要按 **Object** 或边界类型处理（初学知道「编译期检查为主」即可） |
| 原始类型（Raw Type）     | 不写泛型参数，如 `List list`，失去类型安全                                                           |
| 通配符 `?`               | 表示未知类型，如 `List<?>`                                                                           |
| `? extends T`            | **上界**：只读为主，不能安全 `add`（除 `null`）                                                      |
| `? super T`              | **下界**：可写入 `T` 及其子类，适合「往里放」                                                        |
| PECS 口诀（认识）        | **Producer Extends, Consumer Super**——取多用 extends，放多用 super                                   |

## 3. 操作步骤

在 IDEA 中练习泛型：

1. **新建** `GenericBox.java`，定义 `class GenericBox<T>`，字段 `private T value`
2. **使用**：`GenericBox<String> box = new GenericBox<>();` `set`/`get` 无需强转
3. **对比错误**：若写 `GenericBox raw = new GenericBox();` `get()` 需强转，运行期可能转型失败
4. **新建** `GenericMethodDemo.java`，调用 `printList` 打印 `List<Integer>` 与 `List<String>`
5. **通配符**：编写 `doubleSum(List<? extends Number> list)` 对数字列表求和
6. **运行**确认编译期类型错误（如向 `List<? extends Number>` 误 `add` 字符串）在 IDE 标红

## 4. 语法与写法

### 4.1 泛型类

```java
// 文件：GenericBox.java
public class GenericBox<T> {
    private T value;

    public void set(T value) {
        this.value = value;
    }

    public T get() {
        return value;
    }
}
```

```java
// 文件：GenericBoxDemo.java
public class GenericBoxDemo {
    public static void main(String[] args) {
        GenericBox<String> box = new GenericBox<>();
        box.set("hello");
        String s = box.get();  // 无需 (String) 强转
    }
}
```

### 4.2 泛型方法与集合

```java
// 文件：GenericMethodDemo.java
import java.util.List;

public class GenericMethodDemo {
    public static <T> void printList(List<T> list) {
        for (T item : list) {
            System.out.println(item);
        }
    }

    public static double sumNumbers(List<? extends Number> nums) {
        double total = 0;
        for (Number n : nums) {
            total += n.doubleValue();
        }
        return total;
    }
}
```

### 4.3 通配符示例

```java
// 只读列表：可遍历，不宜 add 非 null 元素
public static void show(List<?> list) {
    for (Object o : list) {
        System.out.println(o);
    }
}

// 可往里放 Integer 及其子类（若有）
public static void addIntegers(List<? super Integer> target) {
    target.add(1);
    target.add(2);
}
```

### 4.4 与集合声明

```java
List<String> names = new ArrayList<>();   // 钻石运算符 <>
Map<String, Integer> map = new HashMap<>();
```

## 5. 常见用法

1. **集合统一加泛型**：`List<Student>`、`Map<String, Course>`
2. **工具类泛型方法**：对任意 `List<T>` 打印、查找
3. **API 参数**：只读用 `List<? extends Number>`，写入用 `List<? super Integer>`

## 6. 易错点

- **泛型数组**：`new T[10]` 非法；集合用 `ArrayList` 代替（进阶）
- **`List<Object>` 不能接收 `List<String>`**：泛型不变性，赋值编译失败
- **混用原始类型与泛型**：`List list = new ArrayList<String>()` 仍可能运行期转型错
- **通配符滥用**：初学业务代码优先 **具体泛型** `List<String>`，通配符多用于库 API 设计

## 7. 本节小结

- **泛型类/方法** 在编译期约束类型，减少强转错误
- 集合声明 **`List<T>` + `new ArrayList<>()`**
- **通配符**：`? extends` 偏读，`? super` 偏写；牢记 **PECS** 便于读 JDK API
