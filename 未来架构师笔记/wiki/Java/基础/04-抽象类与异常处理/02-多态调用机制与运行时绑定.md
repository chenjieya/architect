> 所属：继承、多态与抽象设计 · Java 面向对象与核心类库

## 1. 概述

本节说明 **多态（Polymorphism）**：用**父类类型引用**指向**子类对象**，调用重写方法时由 JVM 在**运行期**决定执行哪一版实现（**运行时绑定**）。

## 2. 核心概念

| 术语                          | 说明                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------- |
| 多态（Polymorphism）          | 同一父类引用，在不同子类对象上表现出不同行为                                  |
| 向上转型（Upcasting）         | 子类对象赋给父类引用，如 `Animal a = new Dog(...)`，**自动、安全**            |
| 运行时绑定（Runtime Binding） | 调用实例方法时，JVM 根据**对象实际类型**选择方法实现                          |
| 编译期类型                    | 引用变量声明的类型，如 `Animal a`                                             |
| 运行期类型                    | 引用指向对象的实际类，如 `new Dog(...)` 的运行期类型是 `Dog`                  |
| `instanceof`                  | 判断引用指向的对象是否为某类（或其子类）的实例                                |
| 向下转型（Downcasting）       | 把父类引用强转为子类，需先 `instanceof` 判断，否则可能 **ClassCastException** |

## 3. 操作步骤

在 IDEA 中演示多态：

1. **沿用** `Animal`、`Dog`、`Cat`（上一节）
2. **新建** `Shape.java`、`Circle.java`、`Rectangle.java`（见下方语法）
3. **编写** `ShapeDemo.java`：`Shape s = new Circle(3.0); s.area();`
4. **数组多态**：`Shape[] shapes = { new Circle(2), new Rectangle(3, 4) };` 循环调用 `area()`
5. **运行**：对比 `Circle` 与 `Rectangle` 不同输出
6. **可选断点**：在 `area()` 内单步，观察实际进入哪个子类方法

## 4. 语法与写法

### 4.1 父类引用指向子类对象

```java
// 文件：Shape.java
public class Shape {
    public double area() {
        return 0;
    }

    public void draw() {
        System.out.println("绘制图形");
    }
}
```

```java
// 文件：Circle.java
public class Circle extends Shape {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public void draw() {
        System.out.println("绘制圆形，半径 " + radius);
    }
}
```

```java
// 文件：Rectangle.java
public class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public void draw() {
        System.out.println("绘制矩形 " + width + "×" + height);
    }
}
```

### 4.2 多态调用

```java
// 文件：ShapeDemo.java
public class ShapeDemo {
    public static void main(String[] args) {
        Shape s1 = new Circle(3.0);       // 向上转型
        Shape s2 = new Rectangle(4, 5);

        System.out.println(s1.area());    // 圆面积 —— 运行期走 Circle.area()
        System.out.println(s2.area());    // 矩形面积 —— 运行期走 Rectangle.area()

        s1.draw();
        s2.draw();
    }
}
```

### 4.3 多态数组 / 统一处理

```java
Shape[] shapes = {
    new Circle(2.0),
    new Rectangle(3, 4),
    new Circle(1.5)
};

for (Shape shape : shapes) {
    System.out.println(shape.area());   // 每个元素按实际类型计算
}
```

### 4.4 `instanceof` 与向下转型

```java
Shape shape = new Circle(5.0);

if (shape instanceof Circle) {
    Circle c = (Circle) shape;   // 向下转型
    System.out.println("半径相关操作：" + c.area());
}
```

### 4.5 多态与 `Animal` 示例

```java
Animal a1 = new Dog("旺财", "柯基");
Animal a2 = new Cat("咪咪");

a1.eat();   // 狗版 eat
a2.eat();   // 猫版 eat
// a1.bark();  // 编译错误：Animal 类型没有 bark 方法
```

## 5. 常见用法

1. **统一集合处理**：`Shape[]` 或后续章节的 `List<Shape>`，循环调用 `area()` 无需 `if-else` 判类型
2. **方法参数用父类**：`void printArea(Shape s) { s.area(); }` 可传入任意子类
3. **扩展新图形**：新增 `Triangle extends Shape` 后，原有循环代码无需修改

## 6. 易错点

- **编译期只看引用类型**：`Animal a = new Dog(...); a.bark();` 编译失败，因 `Animal` 未声明 `bark()`
- **向下转型未检查**：`(Dog) new Cat("x")` 运行期 **ClassCastException**
- **把字段访问当多态**：多态针对**实例方法**；字段没有运行时多态（子类隐藏字段是另一概念，初学以方法为主）
- **混淆重载与重写**：`printArea(Shape s)` 编译期根据参数类型选方法；`s.area()` 运行期看对象类型
- **`static` 方法无多态**：通过类名调用静态方法，不看对象实际类型

## 7. 本节小结

- **多态** = 父类引用 + 子类对象 + 重写方法 → **运行期**绑定实现
- **向上转型**自动安全；**向下转型**需 `instanceof` 再强转
- 统一用父类类型写参数/数组，便于扩展新子类而不改调用代码
