> 所属：继承、多态与抽象设计 · Java 面向对象与核心类库

## 1. 概述

本节说明 **`interface` 接口**：定义能力契约，类通过 **`implements`** 实现；支持**多实现**，是 **面向接口编程** 的基础。

## 2. 核心概念

| 术语              | 说明                                                                        |
| ----------------- | --------------------------------------------------------------------------- |
| 接口（Interface） | 用 `interface` 声明的类型，描述「能做什么」，不含实例字段（本课以方法为主） |
| `implements`      | 类实现接口：`class X implements Payable`                                    |
| 实现类            | 提供接口中全部方法的**具体实现**                                            |
| 多实现            | 一个类可 `implements` **多个**接口，弥补 Java 类单继承限制                  |
| 面向接口编程      | 变量、参数、返回值类型用**接口**声明，具体实现可替换                        |
| `default` 方法    | 接口中带默认实现的方法（JDK 8+），实现类可不重写                            |

## 3. 操作步骤

1. **新建接口** `Payable.java`，声明 `void pay(double amount);`
2. **新建实现类** `AlipayPayment.java`、`WechatPayment.java`，各自 `implements Payable`
3. **编写** `PaymentDemo.java`：`Payable p = new AlipayPayment(); p.pay(99.9);`
4. **切换实现**：把 `new` 改为 `WechatPayment`，`main` 其余代码不变
5. **多实现示例**（可选）：`class OrderService implements Payable, Loggable`（若定义了 `Loggable`）
6. **运行** 观察不同支付渠道输出

## 4. 语法与写法

### 4.1 接口定义

```java
// 文件：Payable.java
public interface Payable {
    void pay(double amount);

    // JDK 8+：带默认实现，实现类可不重写
    default void printReceipt() {
        System.out.println("--- 支付回执 ---");
    }
}
```

### 4.2 实现类

```java
// 文件：AlipayPayment.java
public class AlipayPayment implements Payable {
    @Override
    public void pay(double amount) {
        System.out.println("支付宝支付：" + amount + " 元");
    }
}
```

```java
// 文件：WechatPayment.java
public class WechatPayment implements Payable {
    @Override
    public void pay(double amount) {
        System.out.println("微信支付：" + amount + " 元");
    }
}
```

### 4.3 面向接口调用

```java
// 文件：PaymentDemo.java
public class PaymentDemo {
    public static void main(String[] args) {
        Payable payment = new AlipayPayment();
        payment.pay(99.9);
        payment.printReceipt();

        payment = new WechatPayment();   // 换实现，调用方代码结构不变
        payment.pay(50.0);
    }

    // 参数也用接口类型
    public static void checkout(Payable p, double amount) {
        p.pay(amount);
    }
}
```

### 4.4 接口 vs 抽象类（初学对比）

| 对比项   | 接口                           | 抽象类                       |
| -------- | ------------------------------ | ---------------------------- |
| 关键字   | `interface` / `implements`     | `abstract class` / `extends` |
| 继承数量 | 类可实现**多个**接口           | 类只能 **extends 一个**类    |
| 构造器   | 无                             | 可有                         |
| 典型用途 | 定义**能力**（能支付、能打印） | 定义**is-a 共性** + 模板流程 |
| 本课示例 | `Payable`                      | `AbstractReport`             |

### 4.5 多接口实现（示意）

```java
// 文件：Loggable.java
public interface Loggable {
    void log(String message);
}

// 一个类同时实现两个接口
public class AlipayPayment implements Payable, Loggable {
    @Override
    public void pay(double amount) {
        log("发起支付 " + amount);
        System.out.println("支付宝支付：" + amount + " 元");
    }

    @Override
    public void log(String message) {
        System.out.println("[LOG] " + message);
    }
}
```

## 5. 常见用法

1. **支付、通知、导出等可替换能力**：业务依赖 `Payable`，上线新渠道只加实现类
2. **回调与策略**：把不同算法封装成接口实现，运行时注入
3. **与多态结合**：`Payable[] methods = { new AlipayPayment(), new WechatPayment() };`

## 6. 易错点

- **实现类漏写方法**：接口新增方法后，旧实现类未补全 → 编译错误
- **接口方法默认 public abstract**：实现类方法必须是 `public`（不能更严格）
- **把接口当类 `new`**：`Payable p = new Payable();` 非法（除非匿名内部类，后续章节）
- **混淆 extends 与 implements**：类 extends 类/抽象类；implements 接口；接口 extends 多个接口（本课浅提）
- **过度抽象**：只有单一实现、永不替换时，不必强行加接口

## 7. 本节小结

- **接口**定义能力契约；**`implements`** 实现；类可**多实现**
- **面向接口编程**：用 `Payable` 声明变量/参数，具体 `AlipayPayment` / `WechatPayment` 可替换
- 与抽象类互补：抽象类管 is-a 与模板；接口管能力与解耦
