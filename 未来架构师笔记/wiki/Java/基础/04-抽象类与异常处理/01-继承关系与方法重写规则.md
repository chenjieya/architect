> 所属：继承、多态与抽象设计 · Java 面向对象与核心类库

## 1. 概述

本节说明  **`extends`**  建立父子类关系、子类如何**扩展**父类成员，以及  **`@Override`**  方法重写的语法与约束，为后续多态打基础。

## 2. 核心概念

| 术语                      | 说明                                                                          |
| ------------------------- | ----------------------------------------------------------------------------- |
| 继承（Inheritance）       | 子类通过  `extends`  获得父类的非私有成员，并可新增或改写行为                 |
| 父类 / 超类（Superclass） | 被继承的类，如  `Animal`                                                      |
| 子类 / 派生类（Subclass） | 继承父类的类，如  `Dog extends Animal`                                        |
| `extends`                 | 声明继承：`class 子类 extends 父类`；Java 类**单继承**（只能 extends 一个类） |
| 方法重写（Override）      | 子类提供与父类**同名、同参数列表**的方法，覆盖父类实现                        |
| `@Override`               | 注解，标记重写方法，帮助编译器检查签名是否正确                                |
| 继承链                    | 从子类向上到  `Object`  的层级关系                                            |

## 3. 操作步骤

在 IDEA 中跟做继承示例：

1. **新建父类**：`Animal.java`，含  `protected String name`  与  `public void eat()`
2. **新建子类**：`Dog.java`，写  `public class Dog extends Animal`
3. **扩展字段**：在  `Dog`  中新增  `private String breed`
4. **重写方法**：在  `Dog`  中写  `@Override public void eat()`，打印狗特有的进食描述
5. **新建演示类**：`AnimalDemo.java`，`main`  中  `Dog d = new Dog(); d.eat();`
6. **运行**：观察输出为子类重写后的内容

## 4. 语法与写法

### 4.1 父类与子类基本结构

```java
// 文件：Animal.java
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " 正在吃东西");
    }

    public void sleep() {
        System.out.println(name + " 在睡觉");
    }
}
```

```java
// 文件：Dog.java
public class Dog extends Animal {
    private String breed;

    public Dog(String name, String breed) {
        super(name);           // 调用父类构造器
        this.breed = breed;
    }

    @Override
    public void eat() {
        System.out.println(name + "（" + breed + "）在吃狗粮");
    }

    public void bark() {
        System.out.println(name + " 汪汪叫");
    }
}
```

```java
// 文件：Cat.java
public class Cat extends Animal {
    public Cat(String name) {
        super(name);
    }

    @Override
    public void eat() {
        System.out.println(name + " 在吃鱼");
    }
}
```

### 4.2 子类能继承什么

- **`public` / `protected`  成员**：子类可直接使用
- **`private`  成员**：子类**不能**直接访问，需通过父类  `public`/`protected`  方法间接使用
- **构造器**：子类不继承父类构造器，但可通过  **`super(...)`**  调用（第 1 章已学）

### 4.3 方法重写规则（初学必记）

| 规则                         | 说明                                    |
| ---------------------------- | --------------------------------------- |
| 方法名与参数列表相同         | 仅改方法体不算重载，算重写              |
| 子类访问权限  **不能更严格** | 父类  `public`，子类不能改成  `private` |
| 父类  `final`  方法          | **不能**重写                            |
| 父类  `static`  方法         | 子类同名方法是**隐藏**，不是重写        |
| 建议加  `@Override`          | 拼错方法名时编译器会报错                |

```java
// 文件：AnimalDemo.java
public class AnimalDemo {
    public static void main(String[] args) {
        Dog dog = new Dog("旺财", "柯基");
        dog.eat();    // 狗（柯基）在吃狗粮 —— 走 Dog 的重写版本
        dog.sleep();  // 旺财 在睡觉 —— 继承自 Animal，未重写
        dog.bark();   // 子类自有方法
    }
}
```

## 5. 常见用法

1. **提取公共父类**：`Dog`、`Cat`  都有  `name`  和  `sleep()`，抽到  `Animal`
2. **统一入口、差异化实现**：父类定义  `eat()`，各子类重写具体吃什么
3. **在子类构造器中  `super(参数)`**：先初始化父类字段，再写子类字段

## 6. 易错点

- **把重写当重载**：参数列表不同是**重载**，不是  `@Override`  重写
- **忘记  `@Override`  导致静默错误**：方法名写成  `Eats()`  变成子类新方法，父类逻辑不会被覆盖
- **父类  `private`  方法「重写」**：实际是子类新方法，与父类无关，不能加  `@Override`
- **子类构造器未调  `super`**：父类无无参构造时，子类必须首行  `super(实参)`，否则编译错误
- **认为子类继承构造器**：构造器不能继承，只能显式  `super(...)`  或隐式  `super()`

## 7. 本节小结

- **`extends`**  建立 is-a 关系；子类获得父类非私有成员并可扩展
- **方法重写**：同名同参 + `@Override`；运行时按**实际对象类型**调用（下一节讲多态）
- 子类构造器用  **`super(...)`**  初始化父类部分；`final`/`static`  方法不能按重写理解
