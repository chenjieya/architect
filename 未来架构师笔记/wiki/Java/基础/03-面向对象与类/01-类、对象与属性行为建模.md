> 所属：面向对象编程基础 · Java 面向对象与核心类库

## 1. 概述

本节说明如何用  **类（class）**  描述一类事物的共同特征与行为，并通过  **`new`**  创建  **对象（object）**  在程序中使用，建立「属性 + 方法」的建模习惯。

## 2. 核心概念

| 术语                       | 说明                                                                           |
| -------------------------- | ------------------------------------------------------------------------------ |
| 类（Class）                | 描述一类事物的**模板**，包含成员变量（属性）与方法（行为）                     |
| 对象（Object）             | 类的**具体实例**，在内存中有独立的一份数据                                     |
| 成员变量（Field）          | 定义在类中、描述对象**状态**的变量，如  `name`、`balance`                      |
| 成员方法（Method）         | 定义在类中、描述对象**行为**的函数，如  `deposit()`、`getName()`               |
| 实例化（Instantiation）    | 用  `new 类名()`  在堆上创建对象，并得到**引用**                               |
| 引用类型（Reference Type） | 变量存的是对象的**地址引用**，不是对象本体全部数据                             |
| 点运算符  `.`              | 通过引用访问对象的成员：`对象.方法()`、`对象.字段`（字段常配合封装用方法访问） |

## 3. 操作步骤

在 IDEA 中创建可运行示例：

1. **新建类**：项目  `src`  下右键 → New → Java Class，类名  `Student`（帕斯卡命名）
2. **编写类体**：在大括号内写成员变量与方法（见下方语法）
3. **编写入口**：再建  `StudentDemo.java`，内含  `public static void main`
4. **创建对象**：在  `main`  中写  `Student s1 = new Student();`
5. **调用行为**：`s1.setName("张三");`  与  `s1.study();`（方法名以你定义的为准）
6. **运行**：右键  `StudentDemo` → Run，观察控制台输出

## 4. 语法与写法

### 4.1 类的基本结构

```java
// 文件：Student.java
public class Student {
    // 成员变量（属性）
    String name;
    int score;

    // 成员方法（行为）
    public void study() {
        System.out.println(name + " 正在学习");
    }

    public void setName(String n) {
        name = n;
    }

    public String getName() {
        return name;
    }
}
```

### 4.2 创建对象与使用

```java
// 文件：StudentDemo.java
public class StudentDemo {
    public static void main(String[] args) {
        Student s1 = new Student();   // 实例化：创建第一个学生对象
        Student s2 = new Student();   // 第二个独立对象

        s1.setName("张三");
        s2.setName("李四");

        s1.study();   // 张三 正在学习
        s2.study();   // 李四 正在学习

        System.out.println(s1 == s2);  // false：两个不同对象
    }
}
```

### 4.3 一个类、多个对象

每个  `new Student()`  都会在堆上分配**新对象**；`s1`  与  `s2`  的  `name`、`score` **互不影响**。

```java
Student a = new Student();
Student b = new Student();
a.setName("A");
// b.name 仍为 null 或默认值，与 a 无关
```

## 5. 常见用法

1. **业务实体建模**：用户、订单、商品各定义一个类，用字段存状态、用方法封装操作
2. **工具类雏形**：把相关操作放进同一类的  `static`  方法（本课先以实例成员为主，`static`  在基础课已见过，后续章节会加深）
3. **在  `main`  中组装流程**：创建多个对象，依次调用方法完成小流程（如注册 → 选课 → 打印）

## 6. 易错点

- **只定义类不  `new`**：有  `Student`  类但没有  `new Student()`，就没有可用对象，无法调用实例方法
- **把类名当对象用**：`Student.study();`  若  `study`  不是  `static`  方法会编译错误，应  `new Student()`  后再调用
- **两个引用指向同一对象**：`Student s2 = s1;`  后改  `s2`  的字段，`s1`  看到的也变了——是**同一对象**，不是两次  `new`
- **成员变量未赋值就使用**：引用类型字段默认  `null`，直接  `name.length()`  可能  **NullPointerException**

## 7. 本节小结

- **类**是模板，**对象**是实例；用  **`new 类名()`**  创建对象
- **成员变量**描述状态，**成员方法**描述行为
- 多次  `new`  得到多个**独立**对象；引用赋值  `s2 = s1`  表示共享同一对象
