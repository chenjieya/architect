> 所属：面向对象编程基础 · Java 面向对象与核心类库

## 1. 概述

本节说明 **构造器（Constructor）** 在 `new` 时完成对象初始化、**重载**多个构造版本，以及字段默认值、实例初始化块与构造器之间的**执行顺序**。

## 2. 核心概念

| 术语                   | 说明                                                                           |
| ---------------------- | ------------------------------------------------------------------------------ |
| 构造器（Constructor）  | 与类名相同、**无返回值类型** 的特殊方法，在 `new` 时自动执行                   |
| 默认构造器             | 编译器自动生成的**无参**构造器；一旦手写任意构造器，默认构造器**不再自动提供** |
| 构造器重载（Overload） | 同一类中多个构造器，**参数列表不同**                                           |
| 实例初始化块           | 类体内 `{ ... }` 代码块，每次创建对象时在构造器前执行                          |
| 静态初始化块           | `static { ... }`，类加载时执行一次，本课仅作了解                               |
| 成员变量默认值         | 未显式赋值时：数值型为 `0`/`0.0`，`boolean` 为 `false`，引用类型为 `null`      |

## 3. 语法与写法

### 3.1 无参与有参构造器

```java
// 文件：Book.java
public class Book {
    private String title;
    private double price;

    // 无参构造
    public Book() {
        title = "未命名";
        price = 0.0;
    }

    // 有参构造（重载）
    public Book(String title, double price) {
        this.title = title;
        this.price = price;
    }

    public String getTitle() {
        return title;
    }

    public double getPrice() {
        return price;
    }
}
```

### 3.2 使用不同构造器创建对象

```java
// 文件：BookDemo.java
public class BookDemo {
    public static void main(String[] args) {
        Book b1 = new Book();
        Book b2 = new Book("Java 入门", 59.9);
        System.out.println(b1.getTitle());  // 未命名
        System.out.println(b2.getPrice());  // 59.9
    }
}
```

### 3.3 实例初始化块 + 构造器顺序

```java
public class InitOrderDemo {
    private int x;

    {  // 实例初始化块
        System.out.println("实例块：x=" + x);
    }

    public InitOrderDemo() {
        System.out.println("构造器：x=" + x);
        x = 10;
    }
}
```

**创建对象时典型顺序**（简化记忆）：

1. 分配内存
2. 成员变量赋**默认值**
3. 实例初始化块（若有，按书写顺序）
4. 构造器方法体执行

### 3.4 手写构造器后缺少无参构造

```java
public class User {
    private String name;

    public User(String name) {  // 仅有有参构造
        this.name = name;
    }
}

// 调用处：
// User u = new User();  // 编译错误：没有无参构造器
User u = new User("张三");
```

若仍需无参版本，须**显式写出** `public User() { ... }`。

## 4. 常见用法

1. **必填字段对象**：只提供有参构造，强制创建时传入 `id`、`title`
2. **便利构造**：无参给默认值，有参一次设齐多个字段
3. **构造器内校验**：`if (price < 0) throw new IllegalArgumentException("价格非法");`（异常细节见第 3 章）

## 5. 易错点

- **构造器写了返回值**：`public void Book()` 变成普通方法，不是构造器
- **构造器名称与类名不一致**：编译错误
- **只有有参构造却调用 `new Class()`**：忘记补无参构造或改用有参 `new`
- **在构造器完成前把 `this` 泄露出去**：少见，初学先保证构造器内完成必要赋值
- **误以为局部变量有默认值**：构造器里局部变量仍须赋值后使用；**成员变量**才有默认值

## 6. 本节小结

- 构造器在 **`new`** 时执行，用于初始化对象状态
- 可 **重载** 多个构造器；写了任意构造器后 **默认无参构造不再自动生成**
- 初始化顺序：默认值 → 实例块 → 构造器体
