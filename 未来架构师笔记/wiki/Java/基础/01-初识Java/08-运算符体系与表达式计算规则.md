## 1. 概述

本节汇总 Java 常用**运算符**、**表达式**求值顺序与**优先级**，重点掌握算术、赋值、自增自减、关系、逻辑运算及短路规则。

## 2. 核心概念

| 术语                 | 说明                                                  |
| -------------------- | ----------------------------------------------------- |
| 运算符（Operator）   | 对操作数进行运算的符号，如  `+`、`-`、`==`            |
| 操作数（Operand）    | 参与运算的量，如  `a + b`  中的  `a`、`b`             |
| 表达式（Expression） | 由操作数与运算符组成，可求出一个**值**                |
| 算术运算符           | `+`、`-`、`*`、`/`、`%`（取余）                       |
| 赋值运算符           | `=`、`+=`、`-=`  等复合赋值                           |
| 自增自减             | `++`、`--`（前缀与后缀语义不同）                      |
| 关系运算符           | `==`、`!=`、`>`、`<`、`>=`、`<=`（结果为  `boolean`） |
| 逻辑运算符           | `&&`、`                                               |
| 短路求值             | `&&` / `                                              |
| 运算符优先级         | 先乘除后加减；逻辑非 > 与 > 或；可用  `()`  改变顺序  |

## 3. 语法与写法

### 3.1 算术与取余

```java
int a = 10, b = 3;
System.out.println(a / b);    // 3（整数除法截断小数）
System.out.println(a % b);    // 1
System.out.println(10.0 / 3); // 3.333...
```

### 3.2 自增自减

```java
int i = 5;
int x = i++;   // x=5, i=6（先用后加）
int y = ++i;   // i 先变 7，y=7
```

### 3.3 关系与逻辑

```java
int score = 85;
boolean ok = score >= 60 && score < 90;
boolean fail = score < 60 || score > 100;
```

### 3.4 短路示例

```java
int n = 0;
if (n != 0 && 10 / n > 1) {  // n!=0 为 false，右侧 10/n 不执行，避免除零
    System.out.println("safe");
}
```

### 3.5 字符串拼接

`+`  遇  `String`  时进行**拼接**；`"a" + 1`  得  `"a1"`。

```java
System.out.println("结果:" + (3 + 4));  // 结果:7，括号保证先算数
```

### 3.6 优先级（常用，从高到低摘录）

| 优先级 | 运算符                    |
| ------ | ------------------------- |
| 高     | `()`、一元  `++` `--` `!` |
|        | `*` `/` `%`               |
|        | `+` `-`（二元）           |
|        | 关系  `<` `<=` `>` `>=`   |
|        | 相等  `==` `!=`           |
|        | 逻辑  `&&`                |
|        | 逻辑 `                    |
|        | 赋值  `=`、`+=`  等       |

**建议**：复杂表达式用  `()`  写清意图，不依赖背诵全表。

### 3.7 位运算符（了解）

`&`、`|` 、`^`、`~`、`<<`、`>>`  作用于整数**二进制位**；初学以**逻辑短路**为主，位运算在特定场景（权限标志等）后续再用。

```java
int flags = 1 << 2;  // 了解即可
```

## 4. 常见用法

1. **判断范围**：`age >= 18 && age <= 60`
2. **奇偶**：`n % 2 == 0`
3. **复合赋值**：`sum += value`  等价  `sum = sum + value`
4. **打印调试**：`System.out.println("x=" + x);`

## 5. 易错点

- **整数除法**：`5 / 2`  结果是  `2`  不是  `2.5`；要小数用  `5 / 2.0`  或强转
- **`==`  与  `=`**：`==`  比较相等，`=`  赋值；`if (x = 1)`  在 Java 中非法（条件必须是 boolean）
- **后缀与前缀  `++`**：单独一行  `i++;`  效果相同；参与表达式时结果不同
- **`&`  与  `&&`**：`&&`  短路；`&`  两边都会算，可能触发除零等错误
- **拼接优先级**：`"和:" + a + b`  会把  `a`、`b`  当字符串拼，算术要先括号
