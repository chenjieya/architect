## 1. [面试] if 条件为何必须是 boolean

Java 中  `if (x)`  当  `x`  为  `int`  时编译失败，而 JavaScript 中  `if (0)`  表示 false。请说明  **Java 这样设计的一条理由**（与强类型或常见错误预防相关即可）。

---

## 2. [面试] switch 与 if-else 如何选型

面试官问：「星期几用 switch，成绩分档用 if-else，背后的原则是什么？」请用  **两条对比**  回答（单值离散 vs 区间/复合条件）。

---

## 3. [面试] break 与 continue 区别

请各用  **一句话**  说明  `break`  和  `continue`  在循环中的作用；并举例一种适合用  `continue`  的场景（一句话，如「跳过偶数」）。

---

## 4. [面试·扩展] do-while 与 while

Python 没有  `do-while`  语法。若要在 Java 中实现「**至少展示一次菜单**，再根据用户是否继续决定循环」，为什么  **do-while 比 while 更贴切**？（对比「条件一开始就不满足」时两者执行次数。）

---

## 5. [面试] 传统 switch 的 fall-through

什么是 switch 的  **fall-through**？它是 bug 还是特性？各举  **一种**  情况说明。

---

## 6. [工作] 控制台菜单循环

某控制台程序结构如下：先打印菜单，读入选项；选项  `"0"`  退出，其它选项处理业务。同事用  `while`  且把「打印菜单」写在  `while (条件)` **之后**，导致菜单从未显示。请说明  **应选用哪种循环结构**（for/while/do-while），以及  **菜单打印应放在循环的哪个位置**（先/后），一句话理由。
