## 1. 概述

本节说明 Java 中**标识符**的合法字符与规则、**关键字**的含义，以及变量、方法、类的**命名习惯**，便于写出能通过编译且易读的代码。

## 2. 核心概念

| 术语                     | 说明                                                               |
| ------------------------ | ------------------------------------------------------------------ |
| 标识符（Identifier）     | 程序员为变量、方法、类等起的**名字**                               |
| 关键字（Keyword）        | Java **保留**的单词，不能用作标识符（如 `class`、`int`、`if`）     |
| 字面量（Literal）        | 直接写在代码里的**固定值**（如 `100`、`true`、`"hi"`），本节仅提及 |
| 驼峰命名（camelCase）    | 首单词小写、后续单词首字母大写，如 `studentName`                   |
| 帕斯卡命名（PascalCase） | 每个单词首字母大写，如 `StudentInfo`，用于**公共类名**             |
| 下划线 `_`               | 可作为标识符字符；从 Java 9 起**单独**的 `_` 不能作为标识符        |

## 3. 语法与写法

### 3.1 标识符合法规则

1. 由**字母**、**数字**、**下划线 `_`**、**美元符 `$`** 组成（Unicode 字母也算字母）
2. **不能以数字开头**
3. **不能是关键字**，也不能与关键字仅大小写不同（Java 区分大小写，但 `Class` 与 `class` 不同，`class` 仍是关键字）

```java
// 合法示例
int age;
int _count;
String userName;
int $temp;   // 合法但不推荐

// 非法示例
// int 2name;     // 不能以数字开头
// int class;     // class 是关键字
// int _;         // 单独 _ 非法（Java 9+）
```

### 3.2 常见关键字（本阶段）

| 类别     | 示例                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 类型     | `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`、`void`        |
| 流程     | `if`、`else`、`for`、`while`、`do`、`switch`、`case`、`break`、`continue`、`return` |
| 类与访问 | `class`、`public`、`static`、`final`、`new`                                         |
| 逻辑     | `true`、`false`、`null`                                                             |

完整列表见 JDK 文档；初学先记**本表 + 写代码时 IDE 标红**即可。

### 3.3 命名规范（习惯，非语法强制）

| 对象                 | 习惯            | 示例                               |
| -------------------- | --------------- | ---------------------------------- |
| 类名                 | 帕斯卡，名词    | `HelloWorld`、`Student`            |
| 方法名               | 驼峰，动词开头  | `getName`、`printResult`           |
| 变量名               | 驼峰，有意义    | `totalScore`、`isValid`            |
| 常量（`final` 字段） | 全大写 + 下划线 | `MAX_SIZE`、`PI`                   |
| 包名                 | 全小写，点分隔  | `com.example.demo`（后续章节展开） |

**公共类名必须与文件名一致**（含大小写），例如文件 `Demo.java` 中 `public class Demo`。

```java
public class Demo {
    public static void main(String[] args) {
        int studentCount = 0;
        final int MAX_COUNT = 100;
        System.out.println(studentCount);
    }
}
```

## 4. 常见用法

1. **布尔变量**：用 `is`/`has` 前缀，如 `isEmpty`、`hasNext`
2. **循环计数**：`i`、`j`、`k` 仅用于短循环；业务含义变量用完整名
3. **临时变量**：仍应避免 `a1`、`tmp2` 等无意义名（团队规范可能更严）

## 5. 易错点

- **类名与文件名不一致**：`public class demo` 写在 `Demo.java` → 编译错误
- **把关键字当变量名**：`int class = 1;` → 编译错误
- **数字开头**：`int 1stPlace;` → 编译错误
- **混淆大小写**：`String` 是类名，`string` 不是 Java 类型关键字（但作变量名合法，易与习惯冲突，不推荐）

## 6. 本节小结

- 标识符：字母/数字/`_`/`$` 组成，**不以数字开头**，**不用关键字**
- 类名帕斯卡且与文件名一致；变量/方法驼峰；`final` 常量常全大写
- `true`、`false`、`null` 是字面量关键字，不能当标识符
