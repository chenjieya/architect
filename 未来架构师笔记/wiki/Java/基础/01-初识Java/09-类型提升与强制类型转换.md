## 1. 概述

本节说明表达式中的**自动类型提升**（ widening ）、**强制类型转换**（ narrowing ）的写法与风险，以及  `char`  与整数运算时的规则。

## 2. 核心概念

| 术语                  | 说明                                                             |
| --------------------- | ---------------------------------------------------------------- |
| 类型提升（Promotion） | 较小类型在运算中**自动**变为较大类型，避免丢失范围               |
| widening（拓宽）      | 小类型 → 大类型，**自动**，如  `byte`  参与运算时常提升为  `int` |
| narrowing（收窄）     | 大类型 → 小类型，**可能丢失精度**，须**强制转换** `(类型)`       |
| 强制类型转换          | 语法  `(目标类型) 表达式`，如  `(int) 3.9`                       |
| 字面量默认类型        | 整数字面量默认  `int`，小数默认  `double`                        |

### 2.1 自动提升方向（记忆要点）

```text
byte / short / char  → 参与运算时常先提升为 int
int → long → float → double
```

**boolean 与数值转换绝缘（必记）**：

- **不参与自动提升**：提升链为  `byte → … → double`，**不含  `boolean`**
- **不能强制互转**：`(int) true`、`(boolean) 1`  等均  **编译错误**
- **条件必须是 boolean**：不能写  `if (count)`，应写  `if (count != 0)`  等
- **设计目的（一句话）**：把「逻辑真假」与「数值大小」分开，避免含义模糊和 C 式 0/非 0 判断；详细 Why 见教案

```java
// int n = 1;
// boolean b = (boolean) n;   // 错误
// int x = (int) true;        // 错误
```

## 3. 语法与写法

### 3.1 自动提升

```java
byte b1 = 10, b2 = 20;
// byte result = b1 + b2;   // 错误：b1+b2 结果是 int
int result = b1 + b2;       // 正确

int i = 100;
long L = i;                 // int → long 自动

float f = 3.14f;
double d = f;               // float → double 自动
```

### 3.2 强制转换

```java
double pi = 3.14159;
int approx = (int) pi;      // 3，小数部分截断

long big = 3000000000L;
int small = (int) big;      // 可能溢出，结果不等于原值

byte b = (byte) 128;        // 溢出，结果依赖二进制截断
```

### 3.3 char 与 int

```java
char c = 'A';
int code = c;               // 自动提升为 int，值为 65
char next = (char) (c + 1); // 需强制转回 char

System.out.println(1 + '1');   // 50：'1' 码点 49，按 int 相加，不是 11
System.out.println("1" + '1'); // "11"：有 String 时 + 为拼接
```

**为何是 char→int，而不是 int→String？**  
无  `String`  时  `+`  只做**算术**，`char`  按 Unicode 码点提升为  `int`；只有出现  `String`  时  `+`  才变**拼接**并把另一侧转成字符串。这样  `1+2`  恒为  `3`，不会像 JS 那样在  `+`  上混用加减与拼接。

### 3.4 混合运算

```java
int a = 5;
double b = 2.0;
double c = a + b;           // a 提升为 double 再相加
```

## 4. 常见用法

1. **除法要小数**：`int / int`  先转再除，如  `(double) a / b`  或  `a * 1.0 / b`
2. **读入数字转类型**：`Scanner`  读  `int`  后赋给  `long`  可自动；赋给  `byte`  常需强转（注意范围）
3. **显示整数部分**：`(int) totalPrice`

## 5. 易错点

- **byte/short 相加结果仍是 int**：不能赋给  `byte`  除非强转且注意范围
- **强转只影响紧邻表达式**：`(int) a + b`  与  `(int)(a + b)`  不同
- **double 转 int 截断非四舍五入**：`(int) 3.9`  为  `3`
- **大 long 转 int 溢出**：无编译错误，运行结果错误
- **char 相加得到 int**：要存回  `char`  必须  `(char)(...)`
- **试图把 boolean 与 int 互转**：`(int) true`、`(boolean) 1`  均非法；别用 C 语言「0 为假」习惯
- **以为  `1 + '1'`  得 11**：算术里  `char`  提升为 int（`'1'`→49），结果为  **50**；要  `"11"`  须  `"1" + '1'`

## 6. 本节小结

- 小类型运算常提升为  `int`；向  `long`/`float`/`double`  可自动拓宽
- 缩小类型须  `(类型)`  强转，注意截断与溢出
- `char`  与算术运算按  `int`  处理，赋回  `char`  需强转
- **`boolean`  不参与提升，也不能与数值强转**；`if`  条件须为布尔表达式
