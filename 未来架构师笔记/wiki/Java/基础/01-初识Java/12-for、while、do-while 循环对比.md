## 1. 概述

本节说明三种循环 **for**、**while**、**do-while** 的语法、执行顺序与选用场景，用于重复执行一段代码直到条件不满足。

## 2. 核心概念

| 术语          | 说明                                                               |
| ------------- | ------------------------------------------------------------------ |
| 循环（Loop）  | 在满足条件时**反复执行**同一段代码                                 |
| for 循环      | `for (初始化; 条件; 更新) { ... }`，适合**已知次数**或**计数遍历** |
| while 循环    | `while (条件) { ... }`，先判断条件，**可能一次都不执行**           |
| do-while 循环 | `do { ... } while (条件);`，**先执行一次**再判断，至少执行一轮     |
| 循环变量      | 控制次数或索引的变量，如 `int i = 0`                               |
| 无限循环      | 条件恒为 `true` 时持续执行，须用 `break` 等方式退出（慎用）        |
| 死循环        | 条件无法变假且无法退出，程序挂起（逻辑错误）                       |

## 3. 语法与写法

### 3.1 for 循环

```java
public class LoopDemo {
    public static void main(String[] args) {
        for (int i = 0; i < 5; i++) {
            System.out.println("i = " + i);
        }
    }
}
```

**执行顺序**：① 初始化（仅一次）→ ② 判断条件 → ③ 执行循环体 → ④ 更新 → 回到 ②。

```java
for (int i = 0; i < 3; i++) {
    System.out.print(i + " ");
}
// 输出：0 1 2
```

### 3.2 while 循环

```java
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}
```

**先判断后执行**：若初始条件为 `false`，循环体**零次**执行。

### 3.3 do-while 循环

```java
int n = 0;
do {
    System.out.println(n);
    n++;
} while (n < 5);
```

**注意**：`while (条件)` 后必须有**分号** `;`。

```java
int input = -1;
do {
    // 模拟：至少展示一次菜单
    System.out.println("请重试，当前值无效: " + input);
    input = 0;  // 示例：第二次条件为假
} while (input < 0);
```

### 3.4 三种循环对比示例（累加 1～5）

```java
// for
int sum1 = 0;
for (int i = 1; i <= 5; i++) {
    sum1 += i;
}

// while
int sum2 = 0, j = 1;
while (j <= 5) {
    sum2 += j;
    j++;
}

// do-while
int sum3 = 0, k = 1;
do {
    sum3 += k;
    k++;
} while (k <= 5);
```

三者结果均为 `15`。

### 3.5 循环变量作用域

`for` 括号内声明的变量（如 `int i`）**仅在该 for 循环内**可见：

```java
for (int i = 0; i < 3; i++) { }
// System.out.println(i);  // 编译错误：i 超出作用域
```

## 4. 常见用法

| 场景                                                            | 推荐                            |
| --------------------------------------------------------------- | ------------------------------- |
| 固定次数（打印 10 行、累加 1～n）                               | **for**                         |
| 次数未知，先读条件再执行（如「直到文件读完」——后续 I/O 章展开） | **while**                       |
| **至少执行一次**（菜单、输入校验重试）                          | **do-while**                    |
| 递减计数                                                        | `for (int i = 10; i >= 1; i--)` |

## 5. 易错点

- **死循环**：忘记更新循环变量，如 `while (i < 5) { ... }` 内未 `i++`。
- **do-while 漏分号**：`} while (n < 5)` 写成 `} while (n < 5)` 无分号 → 编译错误。
- **for 三部分写错**：中间是**条件**（boolean），不是赋值；`for (int i = 0; i = 5; i++)` 非法。
- **浮点作循环计数**：`for (double d = 0.0; d != 1.0; d += 0.1)` 可能因精度**永远不等于** 1.0；整数索引更稳妥。
- **分号空体**：`for (int i = 0; i < 5; i++);` 分号使循环体为空，仅执行更新。

## 6. 本节小结

- **for**：初始化、条件、更新集中写在一行，适合计数循环
- **while**：先判后做，可能 0 次
- **do-while**：先做后判，**至少 1 次**；`while` 后要有分号
- 避免**忘记更新**导致死循环；`for` 内声明的变量不出循环体
