## 1. 概述

本节区分**字面量**与**变量**、用 `final` 声明**常量**，并说明变量在**块、方法、类**中的作用域与生命周期。

## 2. 核心概念

| 术语              | 说明                                                                                                  |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| 字面量（Literal） | 源码中直接写出的常量值，如 `42`、`3.14`、`'a'`、`true`、`"ok"`                                        |
| 变量（Variable）  | 有名字、可重新赋值的存储单元（`final` 修饰的除外）                                                    |
| 常量              | 用 `final` 修饰、**只能赋一次值**的变量；类中 `static final` 常作全局常量                             |
| 成员变量          | 类中定义的字段；生命周期与对象或类绑定（本课见 `TypeDemo.count`、`LiterDemo` 的 `MAX_USERS`）         |
| 局部变量          | 方法或块中的变量；**方法参数**也是局部变量                                                            |
| 作用域（Scope）   | 变量**在哪些行代码里可见、可用**                                                                      |
| 生命周期          | 变量从创建到销毁的时间段；**局部变量**随方法/块结束而失效；**成员变量**随对象存在（静态成员随类存在） |
| 块（Block）       | 由 `{ }` 围起来的代码区域                                                                             |

## 3. 语法与写法

### 3.1 常见字面量

| 类型   | 示例                     |
| ------ | ------------------------ |
| 整型   | `0`、`100`、`-5`、`100L` |
| 浮点   | `3.14`、`2.0f`           |
| 字符   | `'Z'`、`'\n'`（转义）    |
| 布尔   | `true`、`false`          |
| 字符串 | `"Hello"`（双引号）      |
| 空引用 | `null`（仅用于引用类型） |

### 3.2 变量声明与赋值

```java
int a = 10;        // 声明并初始化
int b;             // 仅声明（局部变量必须随后赋值才能用）
b = 20;
```

### 3.3 final 常量

```java
final int MAX = 100;
// MAX = 200;   // 编译错误：无法为 final 变量赋值

final double PI = 3.14159;
```

类中常量习惯：

```java
public class LiterDemo {
    static final int MAX_USERS = 50;

    public static void main(String[] args) {
        final String APP_NAME = "学习助手";
        System.out.println(APP_NAME);
    }
}
```

### 3.4 作用域示例

```java
public class ScopeDemo {
    static int classVar = 1;   // 类变量（静态成员）

    public static void main(String[] args) {
        int methodVar = 2;     // 方法内局部变量
        if (methodVar > 0) {
            int blockVar = 3;  // 块内局部变量
            System.out.println(blockVar);
        }
        // System.out.println(blockVar);  // 错误：超出块作用域
    }
}
```

### 3.5 成员变量 vs 局部变量（生命周期对照）

| 变量种类     | 声明示例                           | 何时创建                   | 何时销毁      | 默认值               |
| ------------ | ---------------------------------- | -------------------------- | ------------- | -------------------- |
| 实例成员变量 | `int count;`（类里）               | 创建对象时（后续学 `new`） | 对象被回收时  | 有（`int`→0）        |
| 静态成员变量 | `static final int MAX_USERS = 50;` | 类加载时                   | 程序结束      | 有                   |
| 局部变量     | `int methodVar = 2;`               | 进入方法/块时              | 离开方法/块时 | **无**               |
| 参数         | `main(String[] args)` 的 `args`    | 方法调用时                 | 方法返回时    | **无**（调用方传入） |

**规则摘要**：

- 内层块可使用外层已声明的变量
- 同一作用域内**不能重复声明同名**变量
- 外层不能访问仅在内层块中声明的变量
- **成员变量**与**局部变量**是两套规则：前者有默认值，后者必须赋值

## 4. 常见用法

1. **魔法数字改常量**：`final int PASS_SCORE = 60;` 代替到处写 `60`
2. **方法参数视为局部变量**：在方法体内有效，调用结束即失效
3. **循环变量**：`for (int i = 0; i < 10; i++)` 中 `i` 仅在 `for` 块内（具体见流程控制章）

## 5. 易错点

- **局部变量只声明不赋值就使用**：编译失败
- **对 `final` 二次赋值**：编译失败
- **块外使用块内变量**：如 `if` 里定义的变量在 `if` 外使用 → 编译错误
- **同名遮蔽**：内层 `int x = 1` 与外层 `x` 并存时，内层 `x` 遮盖外层（初学尽量少嵌套同名）

## 6. 本节小结

- 字面量是写死的值；变量有名可改；`final` 只能赋一次
- **成员变量**在类里、有默认值；**局部变量**（含参数）在方法/块里、必须赋值
- 作用域由 `{ }` 与方法、类边界决定；局部变量随块/方法结束而消失
- 常量命名习惯全大写 + 下划线
