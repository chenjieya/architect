## 2. L2 原理与应用

### 2.1

**答**：输出  **5**。  
**推理**：`int`  按值传递，`increment`  的形参  `n`  是  `x`  的拷贝；方法内  `n = n + 10`  只改局部变量，不影响  `main`  的  `x`。

### 2.2

**答**：输出  **3**。  
**推理**：`replace`  里  `arr = new int[10]`  只让形参指向新数组，`main`  的  `data`  仍指向原  `{1,2,3}`。  
**修复**：`replace`  改为  `return new int[10]`（或拷贝旧元素的新数组），`main`  写  `data = replace(data);`。

### 2.3

**答**：输出  **99**。  
**对比**：`arr[0]=value`  通过同一门牌改**堆上数组**；reassign 只改方法内门牌。第 2 题是换门牌不影响外面，本题是改仓库内容，外面可见。

### 2.4

**答**：编译错误（missing return statement / 并非所有路径都有返回值）。  
**修复**：在方法末加  `return 0;`  或增加  `else { return 0; }`  处理  `n == 0`。

### 2.5

**答**：匹配  **`log(String msg, int code)`**（两参数版本）。若只有单参数  `log(String)`，调用  `log("timeout", 504)` **编译失败**——无匹配重载。编译器按实参个数与类型选最匹配版本。

### 2.6

**答**：**StackOverflowError**（无限递归）。原因：`n`  递增，永远达不到终止条件，缺少基准  `if (n <= 0) return 0;`  之类。  
**基准示例**：`if (n <= 0) return 0;`

### 2.7

**答**：**现象**：录入成功提示但列表仍空。**原因**：`appendScore`  返回新数组，未赋给  `scores`，`scores`  仍指向旧数组。**修复**：改为  `scores = appendScore(scores, score);`

### 2.8

**答**：输出  **Hi**。  
**推理**：值传递拷贝门牌；`s = s + "!"`  产生新 String 并让形参指向新对象，调用方  `msg`  不变。  
**改法**：改为  `public static String appendExclaim(String s) { return s + "!"; }`，调用方  `msg = appendExclaim(msg);`

## 3. L3 场景实战

### 3.1

**答**：Java **只有按值传递（pass-by-value）**。基本类型传**数值拷贝**；引用类型传**引用（门牌号）的拷贝**。说「数组是引用传递」易误解为「传引用本身可替换外部变量」——准确是：**引用类型的值按值传递**；改元素可共享堆对象，形参 reassign 不能改调用方变量绑定。

### 3.2

**答**：

1. `arr[0]=100`：**调用方可见**，同一堆数组被修改。
2. `arr=new int[5]`：**调用方不可见**长度/指向变化，仅方法内形参改指向新数组。

### 3.3

**答**：**不合法**。调用  `parse("1")`  无法仅凭返回类型选方法。合法重载须  **方法名相同且参数列表不同**（个数、类型或顺序）。

### 3.4

**答**：**基准情况（终止条件）**  与  **向基准收敛的递归情况**。缺少基准 → 无限递归 → **StackOverflowError**。

### 3.5

**答**：递归版代码贴近数学定义、需理解调用栈；循环版通常更省栈、性能更稳。简单累乘工程上**更常先用 for/while 迭代**；递归用于练拆解思维或问题本身递归定义。

### 3.6

**答**：

- **固定形参**：支持；定义时逐个声明，调用匹配个数与类型（或匹配重载）。
- **可变参数 varargs**：支持；`类型... 参数名`，0 ～多个同类型实参；本课了解，练习以固定参数为主。
- **默认参数值**：**不支持**；无  `int port=8080`。
- **少传参**：用**方法重载**（简版调完整版）。**不定个数同类型**：用 varargs，或本课阶段用数组实参 + 固定参数。

### 3.7

**答**：**不会交换**。`a`、`b`  是实参值的拷贝，交换只发生在形参局部变量。本课范围内可用  **`int[] pair`**  存两个数，方法里交换  `pair[0]`  与  `pair[1]`（改堆上元素），或  **return**  交换后的结果。

### 3.8

**答**：

1. **`nextLine()`  读一整行**再  `Integer.parseInt`  更稳，避免  `nextInt`  换行坑。
2. 至少：**null/空串**、**非数字**（parse 失败）、**超出 0 ～ 100 范围**（可含 trim 后判空）。
3. Java 值传递 + 数组定长：`appendScore` **return 新数组**，必须  **`scores = ...`**  才能让静态字段指向新数组，否则仍用旧引用。
