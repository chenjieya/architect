## 1. 概述

**递归**是方法**直接或间接调用自身**；必须把问题拆成**更小同类子问题**，并设计**终止条件（基准情况）**，否则无法结束或导致栈溢出。

## 2. 核心概念

| 术语                       | 说明                                                              |
| -------------------------- | ----------------------------------------------------------------- |
| 递归（Recursion）          | 方法在执行过程中**再次调用自己**（或间接调用）                    |
| 基准情况（Base Case）      | **不再递归**、直接给出结果的 branch；缺则无限递归                 |
| 递归情况（Recursive Case） | 把问题缩小后**调用自身**；须向基准情况靠近                        |
| 调用栈（Call Stack）       | 每次方法调用占一层栈帧；递归过深可能  **StackOverflowError**      |
| 递归 vs 迭代               | 同一问题往往既可用  **for/while**  也可用递归；本阶段两者都要会写 |

## 3. 语法与写法

### 3.1 阶乘（经典示例）

数学定义：`n! = n × (n-1)!`，且  `0! = 1`。

```java
public class RecursionDemo {
    public static void main(String[] args) {
        System.out.println(factorial(5));   // 120
    }

    public static int factorial(int n) {
        if (n <= 1) {          // 基准情况
            return 1;
        }
        return n * factorial(n - 1);   // 递归情况，n 向 1 靠近
    }
}
```

### 3.2 求 1 ～ n 之和

```java
public static int sumToN(int n) {
    if (n <= 0) {
        return 0;
    }
    return n + sumToN(n - 1);
}
```

### 3.3 数组求和（递归版）

```java
public static int arraySum(int[] arr, int index) {
    if (index >= arr.length) {
        return 0;
    }
    return arr[index] + arraySum(arr, index + 1);
}

// 调用：arraySum(arr, 0)
```

### 3.4 缺少终止条件（错误示范）

```java
// 不要运行：会 StackOverflowError
public static void bad() {
    bad();
}
```

## 4. 设计步骤

1. **定义结果**：最小输入时答案是什么？（基准）
2. **定义递推**：大问题如何变成**更小**的同类问题？
3. **证明收敛**：每次递归参数是否**向基准靠近**？
4. **对比迭代**：能否用循环实现？面试常问两者区别。

### 4.1 迭代版阶乘（对照）

```java
public static int factorialIter(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

## 5. 常见用法

1. **数学定义直接递归**：阶乘、斐波那契（注意重复计算，本课只写清晰版）。
2. **树/目录结构**（后续课程）：先建立递归思维。
3. **分治思想入门**：大问题 = 小问题的组合 + 基准。
4. **用递归写简单遍历**：数组从下标  `index`  起求和。

## 6. 易错点

- **没有基准情况**：无限递归 → `StackOverflowError`。**处理**：先写  `if`  终止分支。
- **基准写错**：如  `factorial(0)`  未处理或  `n==0`  仍递归。**处理**：手算  `n=0,1`  时返回值。
- **递归未向基准靠近**：如  `factorial(n + 1)`  越算越大。**处理**：参数必须**单调逼近**终止条件。
- **斐波那契朴素递归极慢**：`fib(n-1)+fib(n-2)`  重复计算多；本课理解即可，工程用循环或记忆化（后续）。
- **与重载混淆**：递归是**同一方法名同一签名**自调；重载是**不同参数列表**的多个方法。

## 7. 本节小结

- 递归 = **基准情况** + **缩小问题的自调用**
- 缺基准或参数不收敛 → **StackOverflowError**
- 先能写**阶乘、求和**等简单递归，再与  **for 循环**对照
- 实际项目简单累乘/累加优先  **迭代**；递归用于结构清晰或问题本身递归定义
