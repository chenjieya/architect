## 1. 概述

本节用**精简版**菜单项目，把**方法、数组、字符串、循环与边界校验**串起来：`main`  只负责菜单循环与分发，录入、校验、打印拆到独立方法；输入用  **`Scanner`**  的  **`nextLine()`**  读取。

## 2. 核心概念

| 术语     | 说明                                                                        |
| -------- | --------------------------------------------------------------------------- |
| Scanner  | `java.util`  中从**控制台读入一行文本**的工具类                             |
| 菜单循环 | `while (true)` → 打印选项 → 读选择 → `switch`  调对应方法                   |
| 薄 main  | `main`  不写具体业务，只**调度** `printMenu`、`addScore`、`printScores`  等 |
| 模块划分 | **显示 / 录入 / 校验 / 数组扩容**  各用一个方法，改一处不影响其它           |
| 退出分支 | 选  `0`  时  `return`  结束  `main`（或  `break`  跳出循环）                |

## 3. 精简说明（为何这样设计）

| 保留                              | 去掉或合并                       | 原因                                                 |
| --------------------------------- | -------------------------------- | ---------------------------------------------------- |
| 菜单循环 + switch                 | —                                | 练第 3 章流程控制                                    |
| `addScore` + `isValidScoreText`   | —                                | 练方法拆分与第 4 章边界校验                          |
| `appendScore`（return 新数组）    | —                                | 练第 2 节「换对象要 return + 赋值」                  |
| `average`  独立方法               | 不再单独占菜单一项               | 在  **「2 查看」**  里一并输出，少一个分支、代码更短 |
| 3 个菜单项（录入/查看/退出）      | 原 4 项（录入/查看/平均分/退出） | 功能不减，结构更清晰                                 |
| 字段写  `static`，不写  `private` | —                                | 访问修饰符面向对象课再学，本示例避免多余概念         |

**学习顺序建议**：先能 Run 通全文 → 对照注释理解每个方法 → 再试改菜单文案或加「最高分」方法（作业）。

## 4. 操作步骤

1. 在 IDEA 新建类  **`ScoreMenuDemo`**。
2. 顶部写  `import java.util.Scanner;`
3. 粘贴下方完整示例，**Run**。
4. 依次输入：`1` → `85` → `2` → `0`，确认录入、查看、退出正常。

## 5. 语法与写法

### 5.1 Scanner：本课只用 nextLine

```java
Scanner scanner = new Scanner(System.in);
String line = scanner.nextLine().trim();   // 读一整行并去首尾空格
```

菜单选项与分数都走  **`nextLine()`**，再用  `Integer.parseInt`  转数字，避免  `nextInt`  与  `nextLine`  混用时的换行问题。

### 5.2 完整示例：成绩管理（精简版 + 注释）

```java
import java.util.Scanner;

public class ScoreMenuDemo {

    // 全班成绩；static = 整类共享一份（与 main 相同写法，不加 private）
    static int[] scores = new int[0];

    // 控制台输入；各方法共用，不必每个方法都传参
    static Scanner scanner = new Scanner(System.in);

    public static void main(String[] args) {
        // 主循环：反复显示菜单，直到用户选 0 退出
        while (true) {
            printMenu();
            String choice = scanner.nextLine().trim();

            switch (choice) {
                case "1" -> addScore();           // 录入
                case "2" -> printScores();        // 查看列表 + 平均分（合并为一项）
                case "0" -> {                     // 退出
                    System.out.println("再见");
                    scanner.close();
                    return;                       // 结束 main
                }
                default -> System.out.println("无效选项，请重试");
            }
        }
    }

    /** 只负责打印菜单，不读入、不改数据 */
    public static void printMenu() {
        System.out.println("=== 成绩管理 ===");
        System.out.println("1. 录入成绩");
        System.out.println("2. 查看成绩");   // 含列表与平均分
        System.out.println("0. 退出");
        System.out.print("请选择: ");
    }

    /** 读一行分数 → 校验 → 追加到数组 */
    public static void addScore() {
        System.out.print("输入分数(0-100): ");
        String line = scanner.nextLine().trim();

        if (!isValidScoreText(line)) {
            System.out.println("输入无效");
            return;   // 提前结束本方法，不修改 scores
        }

        int score = Integer.parseInt(line);   // 校验通过后再转 int
        scores = appendScore(scores, score);  // 必须接 return 的新数组！
        System.out.println("已录入: " + score);
    }

    /** 校验：非空、能转成整数、且在 0～100 之间 */
    public static boolean isValidScoreText(String text) {
        if (text == null || text.isEmpty()) {
            return false;
        }
        try {
            int v = Integer.parseInt(text);
            return v >= 0 && v <= 100;
        } catch (NumberFormatException e) {
            return false;   // "abc" 等无法转成数字
        }
    }

    /**
     * 在旧数组末尾加一个新分数。
     * 返回新数组（旧数组长度不变）；调用方必须 scores = appendScore(...)
     */
    public static int[] appendScore(int[] old, int score) {
        int[] bigger = new int[old.length + 1];
        for (int i = 0; i < old.length; i++) {
            bigger[i] = old[i];   // 拷贝旧元素
        }
        bigger[old.length] = score;
        return bigger;
    }

    /** 查看：先列全部，再调 average 打印平均分 */
    public static void printScores() {
        if (scores.length == 0) {
            System.out.println("暂无成绩");
            return;
        }
        for (int i = 0; i < scores.length; i++) {
            System.out.println("[" + i + "] " + scores[i]);
        }
        System.out.println("平均分: " + average(scores));
    }

    /** 求平均分；空数组返回 0，避免除零 */
    public static double average(int[] arr) {
        if (arr.length == 0) {
            return 0;
        }
        int sum = 0;
        for (int s : arr) {
            sum += s;
        }
        return (double) sum / arr.length;
    }
}
```

### 5.3 方法分工（对照代码）

| 方法               | 做什么                     | 对应哪章            |
| ------------------ | -------------------------- | ------------------- |
| `main`             | 菜单循环 + switch 分发     | 第 3 章 switch      |
| `printMenu`        | 只打印选项                 | 方法拆分            |
| `addScore`         | 读入 + 调校验 + 调扩容     | 方法调用            |
| `isValidScoreText` | null/空/数字/范围          | 第 4 章边界校验     |
| `appendScore`      | new 大数组 + 拷贝 + return | 第 4 章定长数组扩容 |
| `printScores`      | 遍历打印 + 调 average      | 第 4 章数组遍历     |
| `average`          | 求和再除 length            | 方法返回值          |

## 6. 常见用法

1. **先删菜单，只留 addScore**：测通校验和 append，再加  `while`。
2. **扩展作业**：加  `printMax(scores)`  或在菜单加「3. 最高分」（只加方法，不加新语法）。
3. **非法菜单**：走  `default`  提示即可，不要  `return`  退出整个程序。

## 7. 易错点

- **忘记  `scores = appendScore(...)`**：录入提示成功但查看仍空 → 必须**赋值接 return**。
- **用 nextInt 读菜单又用 nextLine 读分数**：可能读到空行 → 统一  **nextLine**。
- **average 除零**：`length == 0`  时直接返回 0（`printScores`  已先判空，双保险）。
- **不必写 private**：本课只要求  **`public static`  方法**  与  **`static`  字段**；`private`/`public`  字段区别留到面向对象课。
- **对照注释读代码**：方法上方一句职责说明，比裸看代码省时间。

## 8. 本节小结

- 精简菜单：**录入 / 查看（含平均分）/ 退出**  三项即可练全章
- 结构：**Scanner + while 菜单 + switch + 多方法**；`main`  保持薄
- 读入：**nextLine + trim + 校验方法 + parseInt**
- 数组追加：**return 新数组**，并写  **`scores = appendScore(...)`**
