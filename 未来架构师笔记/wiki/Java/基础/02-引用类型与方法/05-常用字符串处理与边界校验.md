## 1. 概述

本节汇总 `String` 的常用方法：**长度、取字符、子串、查找、去空白、判空**，以及编写业务逻辑时的**边界校验**（`null`、空串、下标范围）。

## 2. 核心概念

| 术语                    | 说明                                                                   |
| ----------------------- | ---------------------------------------------------------------------- |
| `length()`              | 返回字符串**字符个数**（方法，带括号）                                 |
| `charAt(int index)`     | 返回下标处的 `char`，下标从 0 开始                                     |
| `substring(begin, end)` | 取 `[begin, end)` **左闭右开**子串；单参数 `substring(begin)` 取到末尾 |
| `indexOf`               | 查找子串或字符**首次**出现下标，未找到返回 **-1**                      |
| `contains`              | 是否包含子串，返回 `boolean`                                           |
| `trim`                  | 去掉首尾**空白字符**（空格、制表等），返回**新** `String`              |
| `isEmpty`               | 长度为 0 为 `true`（`""`）                                             |
| `isBlank`               | JDK 11+，全为空白也为 `true`                                           |
| `split`                 | 按分隔符拆成 `String[]` 数组                                           |
| 边界校验                | 使用前检查 `null`、长度、下标、空串是否符合业务规则                    |

## 3. 语法与写法

```java
public class StringProcessDemo {
    public static void main(String[] args) {
        String s = "  Hello Java  ";

        System.out.println(s.length());           // 15（含空格）
        System.out.println(s.charAt(3));          // 'H'（注意前导空格占下标）
        System.out.println(s.trim());             // "Hello Java"
        System.out.println(s.trim().isEmpty());   // false
        System.out.println("   ".isBlank());      // true

        String path = "user@example.com";
        System.out.println(path.contains("@"));   // true
        System.out.println(path.indexOf("@"));    // 4
        System.out.println(path.substring(0, 4)); // user

        String csv = "a,b,c";
        String[] parts = csv.split(",");
        System.out.println(parts.length);  // 3
        System.out.println(parts[1]);      // b
    }
}
```

### 3.2 边界校验模板

```java
public static boolean isValidUsername(String name) {
    if (name == null) {
        return false;
    }
    String trimmed = name.trim();
    if (trimmed.isEmpty()) {
        return false;
    }
    if (trimmed.length() < 3 || trimmed.length() > 20) {
        return false;
    }
    return true;
}
```

### 3.3 substring 与 indexOf 配合

```java
String email = "a@b.com";
int at = email.indexOf("@");
if (at > 0 && at < email.length() - 1) {
    String user = email.substring(0, at);
    String domain = email.substring(at + 1);
    System.out.println(user + " / " + domain);
}
```

**规则**：`substring` 的 `end` 必须 ≤ `length()`，且 `begin <= end`，否则 `StringIndexOutOfBoundsException`。

### 3.4 split 注意

```java
String line = "a,,b";
String[] arr = line.split(",");
// 可能含空串元素，业务上要过滤 isEmpty
```

## 4. 常见用法

1. **去空格再判断**：`input = input.trim()` 再 `isEmpty()`。
2. **解析简单配置**：`key=value` 用 `indexOf('=')` + `substring` 拆分。
3. **关键词检测**：`text.contains("error")`。
4. **按逗号拆字段**：`split(",")` 后遍历 `String[]`（与数组遍历结合）。

## 5. 易错点

- **charAt 越界**：合法下标 `0`～`length()-1`。
- **substring 右开区间**：`substring(0, 3)` 取的是下标 0、1、2 三个字符。
- **未 trim 就判空**：`" "` 的 `isEmpty()` 为 false，应用 `isBlank()` 或先 `trim`。
- **split 正则特殊字符**：分隔符 `.`、`|` 等在 `split` 里是正则，本阶段先用简单分隔符 `,` `;`。
- **对 null 调方法**：任何 `s.xxx()` 前确认 `s != null`。
- **== 比较字符串内容**：始终用 `equals` / `equalsIgnoreCase`。

## 6. 本节小结

- 常用：`length()`、`charAt`、`substring`、`indexOf`、`contains`、`trim`、`isEmpty`/`isBlank`、`split`
- `substring` 左闭右开；`indexOf` 找不到返回 -1
- 业务入口先校验 **null、trim、长度、下标**；比较内容用 **equals**
