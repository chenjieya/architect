## 1. [面试] 数组满了还要加元素怎么办

已有  `int[] arr`  且槽位已满，业务还要继续存放数据。请说明：

1. 能否通过  `arr.length = 新值`  把**原数组对象**变长？
2. 本课学过的正确做法是什么？（用  **new、拷贝、变量改指向**  等本章词汇描述即可。）

**不要求**答未学过的集合类或框架 API。

---

## 2. [面试] 数组为何设计成定长

为什么 Java 原生数组在  `new`  时就要定好长度、创建后不能改  `length`？请从  **连续存储**  或  **下标访问**  角度答一点（不要求讲底层实现）。

## 3. [面试] String 为何不可变

请说明  **String 不可变**  的含义，并列举  **一条**  好处（如安全、常量池、作哈希键等任一方面即可）。

## 4. [面试] == 与 equals

## 5. [面试] StringBuilder 与 String 不可变

`String`  不可变，那为什么循环拼串还要用  `StringBuilder`？请说明  **Builder 变的是什么、最后怎么得到 String**（不要答「String 变可变了」）。

## 6. [面试] StringBuilder 使用场景

何时用  `StringBuilder`  而不是  `+`？请给  **一种**  典型场景（如循环拼接、数组转逗号分隔串等）。

## 7. [面试·扩展] 字面量与 new String

```java
String a = "hi";
String b = "hi";
String c = new String("hi");
```

说明  `a == b`  与  `a == c`  在本课 Demo 下**一般**分别是什么结果；比较**内容**应如何写（不要求讲 intern 实现细节）。
