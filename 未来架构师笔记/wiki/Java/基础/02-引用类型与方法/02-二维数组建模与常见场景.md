## 1. 概述

本节说明 **二维数组**（可理解为「数组的数组」）的声明、初始化与**双重循环**遍历，以及矩阵、成绩表、棋盘等常见建模方式；并介绍**不规则数组**（各行长度可不同）。

## 2. 核心概念

| 术语                   | 说明                                                                     |
| ---------------------- | ------------------------------------------------------------------------ |
| 二维数组               | 类型写作 `元素类型[][]`，如 `int[][] matrix`，用 `matrix[row][col]` 访问 |
| 行 / 列                | 第一层下标常称**行**，第二层称**列**；`matrix.length` 是**行数**         |
| `matrix[i].length`     | 第 `i` **行**的元素个数（列数）；规则矩阵每行相同，不规则数组各行可不同  |
| 规则矩阵               | 每行列数相同，如 3×4 的 `int[3][4]`                                      |
| 不规则数组（锯齿数组） | 各行 `new` 的长度可以不同，像「每行座位数不一样」                        |
| 嵌套循环遍历           | 外层控制行、内层控制列：`for (i) { for (j) { ... matrix[i][j] } }`       |

## 3. 语法与写法

### 3.1 声明与创建（规则矩阵）

```java
// 3 行 4 列，元素默认 0
int[][] matrix = new int[3][4];

// 同时指定行列
int[][] grid = new int[2][3];

// 字面量：每行一个一维数组
int[][] data = {
    {1, 2, 3},
    {4, 5, 6}
};
// data.length == 2，data[0].length == 3
```

### 3.2 访问元素

```java
int[][] matrix = {{1, 2}, {3, 4}};
System.out.println(matrix[0][1]);  // 2
matrix[1][0] = 10;
```

### 3.3 双重 for 遍历

```java
public class Array2DDemo {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6}
        };
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[i].length; j++) {
                System.out.print(matrix[i][j] + "\t");
            }
            System.out.println();
        }
    }
}
```

**预期**：两行，每行三个数，列对齐后换行。

### 3.4 不规则数组

```java
int[][] jagged = new int[3][];
jagged[0] = new int[2];   // 第 0 行 2 列
jagged[1] = new int[4];   // 第 1 行 4 列
jagged[2] = new int[1];   // 第 2 行 1 列
```

遍历内层应用 `matrix[i].length`，不要假设所有行列数相同。

### 3.5 行求和示例

```java
int[][] scores = {{80, 90}, {70, 85, 60}};
for (int i = 0; i < scores.length; i++) {
    int rowSum = 0;
    for (int j = 0; j < scores[i].length; j++) {
        rowSum += scores[i][j];
    }
    System.out.println("第 " + i + " 行合计: " + rowSum);
}
```

## 4. 常见用法

1. **成绩表**：行=学生，列=科目；`int[][] grades`。
2. **棋盘 / 地图格子**：`char[][] board`，`'X'`、`'O'`、`'.'` 表示状态。
3. **打印图案**：外层行、内层列控制 `*` 或数字（与第 3 章嵌套循环结合）。
4. **矩阵对角线**：`matrix[i][i]` 访问主对角线（需方阵或注意越界）。

## 5. 易错点

- **只 new 了外层**：`int[][] a = new int[3][]` 后未给 `a[i] = new int[...]` 就访问 `a[0][0]` → **NullPointerException**。
- **列数写死**：不规则数组用 `matrix[0].length` 当所有行列数 → 内层越界。**处理**：内层用 `matrix[i].length`。
- **行列颠倒**：`matrix[col][row]` 与数学习惯不一致时易错，团队约定**先行后列**。
- **与一维混淆**：`int[]` 只有一个下标；`int[][]` 必须两个下标。
- **字面量行数不一致**：`{{1,2},{3}}` 合法（不规则）；不要误以为编译器自动补零到同样列数。

## 6. 本节小结

- 二维数组：`类型[][]`，`new[m][n]` 或 `{{...},{...}}`
- `matrix.length` 是行数；`matrix[i].length` 是第 i 行列数
- 遍历：**外层行、内层列**，内层边界用 `matrix[i].length`
- 不规则数组各行长度可不同，须逐行 `new`
