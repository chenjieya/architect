## 1. 概述

本节说明如何声明、创建与初始化**一维数组**，用下标访问元素，并用 **for** 或 **增强 for（for-each）** 遍历；数组是**引用类型**，长度由 `length` 属性得到。

## 2. 核心概念

| 术语                 | 说明                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| 数组（Array）        | **同一类型**多个元素按**连续下标**存放的结构，下标从 **0** 开始                        |
| 一维数组             | 只有一层下标的数组，如 `int[] scores`                                                  |
| 元素（Element）      | 数组中某一个位置的值，用 `arr[i]` 访问                                                 |
| 下标（Index）        | 从 0 到 `length - 1` 的整数；越界会触发运行期异常                                      |
| `length`             | 数组**元素个数**（只读），不是方法，写法为 `arr.length`                                |
| 引用类型             | 数组变量存的是**堆中数组对象的引用**，不是把整个数组「拷进变量」                       |
| 默认值               | 用 `new` 创建且未逐个赋值时，元素为类型默认值（`int`→0，`boolean`→false，引用→`null`） |
| 增强 for（for-each） | `for (元素类型 item : 数组)`，按顺序访问每个元素，**不能改下标**                       |

## 3. 语法与写法

### 3.1 声明与创建

```java
// 方式一：类型[] 名（推荐）
int[] scores;

// 方式二：类型 名[]（合法，不推荐）
int scores2[];

// 指定长度，元素为默认值
scores = new int[5];   // {0,0,0,0,0}

// 声明并创建
double[] prices = new double[3];
```

### 3.2 字面量初始化

```java
int[] nums = {10, 20, 30};           // 完整写法
int[] nums2 = new int[]{1, 2, 3};    // 匿名数组，常用于传参
```

**注意**：`int[] arr = new int[3]{1,2,3};` 非法——**不能**同时写 `new int[n]` 和花括号列表。

### 3.3 访问与修改

```java
int[] arr = {5, 8, 12};
System.out.println(arr[0]);  // 5
arr[1] = 99;
System.out.println(arr.length);  // 3
```

### 3.4 用 for 遍历（带下标）

```java
public class Array1DDemo {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30};
        for (int i = 0; i < arr.length; i++) {
            System.out.println("arr[" + i + "] = " + arr[i]);
        }
    }
}
```

**习惯**：循环条件写 `i < arr.length`，不要写 `i <= arr.length`（会越界）。

### 3.5 增强 for 遍历

```java
for (int value : arr) {
    System.out.println(value);
}
```

适合**只读每个元素**；若要修改指定下标或需要下标，用普通 `for`。

### 3.6 求和示例

```java
int[] arr = {1, 2, 3, 4, 5};
int sum = 0;
for (int n : arr) {
    sum += n;
}
System.out.println(sum);  // 15
```

## 4. 定长说明与需要更多元素时

| 要点           | 说明                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 为何定长       | `new int[n]` 时在堆上划出**连续**的 n 格，`length` 写入对象后**不可改**；保证按下标访问稳定、实现简单 |
| 能否拉长原数组 | **不能**；没有 `arr.length = 新值` 或「原地加一格」                                                   |
| 元素不够怎么办 | **`new` 更大的新数组 → 拷贝旧元素 → 变量指向新数组**（旧数组由 GC 回收）                              |
| 业务里常用做法 | 需要频繁增减元素时，后续课程用 **ArrayList**（内部自动换更大的数组并拷贝）                            |

```java
int[] arr = {1, 2, 3};
int[] bigger = new int[arr.length + 2];
for (int i = 0; i < arr.length; i++) {
    bigger[i] = arr[i];
}
bigger[3] = 4;
bigger[4] = 5;
arr = bigger;
```

## 5. 常见用法

1. **成绩列表**：`int[] scores = new int[30];` 按下标存第 i 个学生分数。
2. **查找最大值**：`for` 遍历，用变量 `max` 与 `arr[i]` 比较更新。
3. **复制引用**：`int[] b = a;` 两个变量指向**同一数组**，改 `b[0]` 会影响 `a[0]`。
4. **空数组**：`new int[0]` 合法，`length` 为 0，循环体不执行。

## 6. 易错点

- **下标越界**：访问 `arr[arr.length]` 或 `arr[-1]` → `ArrayIndexOutOfBoundsException`。**处理**：合法下标为 `0`～`length-1`。
- **length 不是方法**：应写 `arr.length`，不要写 `arr.length()`（那是 `String` 的方法）。
- **未初始化就使用**：只声明 `int[] a;` 未 `new` 或赋值就 `a[0]=1` → 编译错误或空指针。**处理**：先 `new` 或字面量初始化。
- **数组长度固定**：创建后**不能**改 `length`；要更多元素见上文「定长说明与需要更多元素时」的 **new + 拷贝** 写法。
- **增强 for 不能替换下标赋值**：若需 `arr[i] = arr[i] * 2` 且要用下标，用普通 `for`。

## 7. 本节小结

- 一维数组：`类型[] 名`，`new 类型[n]` 或 `{ ... }` 初始化
- 下标从 **0** 开始，合法范围 `0`～`length-1`
- 遍历：**普通 for**（要下标）或 **增强 for**（只读元素）
- 数组是**引用类型**，`length` 是属性不是方法；**定长**；变长靠新数组拷贝或后续 **ArrayList**
