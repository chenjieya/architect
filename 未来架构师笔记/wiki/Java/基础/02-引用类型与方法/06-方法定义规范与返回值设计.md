## 1. 概述

本节说明如何在类中**定义与调用方法**，理解**返回类型**、**参数列表**与  **`return`**  的写法，让  `main`  只负责入口，具体逻辑拆到独立方法里。

## 2. 核心概念

| 术语                     | 说明                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| 方法（Method）           | 完成**一段可复用逻辑**的命名代码块，通过**方法名 + 参数**调用                                |
| 方法签名                 | 由**方法名 + 参数类型列表**唯一标识；不含返回类型                                            |
| 返回类型（Return Type）  | 方法执行后**交给调用方**的数据类型；无返回值写  **`void`**                                   |
| 形参（Formal Parameter） | 方法定义括号里的变量，接收调用时传入的值                                                     |
| 实参（Actual Argument）  | 调用方法时传入的**具体值或表达式**                                                           |
| `return`                 | 结束当前方法；非  `void`  方法必须  **`return`  与返回类型匹配的值**                         |
| 固定参数列表             | 定义时**逐个声明**形参类型与名字；调用时实参**个数与类型**须匹配（或用重载提供多个固定列表） |
| 调用（Invocation）       | `方法名(实参列表)`；有返回值时可赋给变量或参与表达式                                         |

## 3. 语法与写法

### 3.1 基本结构

```java
返回类型 方法名(参数类型 参数名, ...) {
    // 方法体
    return 值;   // void 可省略 return，或写 return;
}
```

**`public static`  写法约定（不重复讲修饰符）**：与第 1 章  `main`  相同——示例里出现的  `public static` **照抄即可**。`public`、`static`  各表示什么已在  **第 1 章「Java 程序入口」**  讲过；本章重点在**返回类型、参数、return**。面向对象课再系统学访问修饰符与实例方法。

```java
public class MethodDefineDemo {
    public static void main(String[] args) {
        greet("Java");
        int sum = add(10, 20);
        System.out.println("sum = " + sum);
    }

    public static void greet(String name) {
        System.out.println("Hello, " + name);
    }

    public static int add(int a, int b) {
        return a + b;
    }
}
```

**预期输出**：

```text
Hello, Java
sum = 30
```

### 3.2 void 与有返回值

| 返回类型            | 含义                             | return                          |
| ------------------- | -------------------------------- | ------------------------------- |
| `void`              | 只执行动作，**不**向调用方交数据 | 可省略；提前结束可写  `return;` |
| `int`、`String`  等 | 必须把结果**交回**调用处         | 必须  `return`  匹配类型的值    |

```java
public static boolean isPositive(int n) {
    if (n > 0) {
        return true;
    }
    return false;
}
```

### 3.3 命名与参数

- 方法名：**小驼峰**（camelCase），动词或动词短语，如  `calcAverage`、`printMenu`。
- 参数：多个时用逗号分隔；调用时**类型、个数、顺序**须与定义一致（重载见第 3 节）。
- 一个方法只做**一件事**，便于阅读和复用。

### 3.4 参数列表：固定、可变、默认（本课边界）

| 方式                    | Java 是否支持 | 本课要求       | 说明                                                                                                                                               |
| ----------------------- | ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **固定参数列表**        | ✅            | **主修**       | `add(int a, int b)` —— 定义几个形参，调用就传几个实参（或匹配某一重载）                                                                            |
| **可变参数（varargs）** | ✅            | **了解**       | 语法  `类型... 参数名`，如  `sum(int... nums)`；调用时可传  **0 个或多个**  同类型实参；方法内当作数组用。**本课练习以固定参数为主**，知道存在即可 |
| **默认参数值**          | ❌            | 用**重载**代替 | 无 Python `def f(x, y=0)`；少参版方法内部调多参版（见第 3 节）                                                                                     |

可变参数示例（阅读即可，不要求默写）：

```java
public static int sum(int... nums) {
    int total = 0;
    for (int n : nums) {
        total += n;
    }
    return total;
}
// 调用：sum()、sum(1)、sum(1, 2, 3) 均可
```

**易混**：「动态参数」在 Java 里通常指  **varargs（可变参数）**，不是默认参数；**没有**「形参自带默认值」语法。

### 3.5 main 瘦身示例

```java
public static void main(String[] args) {
    int[] scores = {80, 90, 75};
    printScores(scores);
    System.out.println("平均分: " + average(scores));
}

public static void printScores(int[] arr) {
    for (int s : arr) {
        System.out.println(s);
    }
}

public static double average(int[] arr) {
    int sum = 0;
    for (int s : arr) {
        sum += s;
    }
    return (double) sum / arr.length;
}
```

## 4. 常见用法

1. **计算并返回**：`return max(a, b);`  供  `main`  打印或继续判断。
2. **校验封装**：`isValidUsername(String name)`  返回  `boolean`，`main`  里  `if (!isValid...)`.
3. **打印菜单**：`void printMenu()`，只负责输出，不返回值。
4. **数组处理**：传入  `int[]`，在方法内遍历或求和，返回统计结果。

## 5. 易错点

- **非 void 方法漏写 return**：编译错误「missing return statement」。**处理**：所有分支都要能到达  `return`，或最后统一  `return`。
- **return 类型不匹配**：`int`  方法里  `return "ok";`  编译失败。**处理**：`return`  表达式类型与声明返回类型一致（或可自动转换）。
- **调用时参数个数/类型不对**：`add(1, 2, 3)`  而定义只有两个固定形参 → 编译错误。**处理**：对照方法定义传实参，或改用匹配的重载 /（了解）可变参数版本。
- **把 Python 默认参数搬进 Java**：写  `void f(int x, int y=0)` **非法**。**处理**：写两个重载方法。
- **在 static 方法里直接调非 static 方法**：实例方法面向对象课再学；本课示例  **`public static`  照抄 main**  即可。若去掉  `static`  从  `main`  调用会编译失败——原因见第 1 章  `main`  为何必须  `static`。
- **void 方法写  `return 值`**：非法。**处理**：void 只能  `return;`  或不写。

## 6. 本节小结

- 方法 = **返回类型 + 名 + 参数 + 体**；无返回值用  **`void`**
- 参数列表本课主修  **固定形参**；Java 另有  **可变参数  `类型...`**（了解）；**无默认参数值**
- **`return`**  把结果交回调用方；非 void **每条路径**都要有合适  `return`
- **`public static`  照抄 main**（修饰符含义见第 1 章）；重点学拆分方法与传参
