机器学习"让机器自己找规律"，但具体用什么算法来找，历史上走出了一条不断升级的路线。这篇文章把这条路线串起来，帮你在脑子里建一张"算法地图"，需要的时候能对上号。

## 1. 一句话理解

**机器学习算法不是并列的，而是一条"从浅到深"的升级谱系**：

> [[线性回归]] → [[决策树]] → [[支持向量机]] 是"浅层"方法，靠明确的数学规则或可解释的判断；
> [[神经网络]] → [[深度学习]] 是可以处理复杂问题的"降维打击"，靠海量数据和算力自动提取特征。

这条谱系的源头是人工智能"连接主义"流派，详细背景见 [[【基础】AI的分类：三大流派与机器学习入门]]。

## 2. 五类算法一览

| 算法           | 核心思想                     | 擅长任务     | 一句话记忆                    |
| -------------- | ---------------------------- | ------------ | ----------------------------- |
| [[线性回归]]   | 画一条最贴合数据的直线       | 预测数值     | 拟合直线，预测房价            |
| [[决策树]]     | 一连串 if-else 组成树状判断  | 分类/回归    | 像走流程分支，规则可解释      |
| [[支持向量机]] | 找一条"最大间隔"分界线切数据 | 分类         | 分得开、还留足安全距离        |
| [[神经网络]]   | 模拟大脑神经元连接           | 图像/文本等  | 用大量神经元"长"出智能        |
| [[深度学习]]   | 把神经网络做得更深更大       | 复杂高维任务 | 深 + 大 + 海量数据 = 能力质变 |

## 3. 为什么是"升级"而不是"并列"

从浅层到深层，本质是**人工设计 → 自动学习**的转变：

1. **线性回归**：规则最简单，一条直线概括数据趋势，但只能拟合线性关系。
2. **决策树**：引入"判断分支"处理非线性，规则透明可解释，但容易过拟合。
3. **支持向量机**：用"最大间隔 + 核技巧"优雅地切开复杂数据，曾经是分类任务的王者。
4. **神经网络**：换了一条路线——不再人工设计规则，而是堆大量神经元让数据自己"训练"出规律。
5. **深度学习**：神经网络的极致形态，层数加深、参数量暴增，配合海量数据和 GPU 算力，能力发生质变——**今天的大模型全部属于这一层**。

> 一句话串起来：**前三个是"人把规则想清楚"，后两个是"让机器自己长出规则"**。

## 4. 怎么选算法

- **要预测一个连续数值**（房价、销量、温度）→ 先试 [[线性回归]]，简单可解释。
- **要分类、且想看懂为什么**（贷款审核、风控规则）→ [[决策树]]，规则透明。
- **要分类、数据边界复杂但样本不算海量**（垃圾邮件、小样本图像分类）→ [[支持向量机]]。
- **处理图像、语音、文本等高维复杂数据** → [[神经网络]] / [[深度学习]]，让模型自动学特征。
- **没有海量数据和算力时**，别硬上深度学习，浅层方法往往更省事、更可解释。

## 5. 与大模型的关系

大模型（GPT 这类）本质上是 **深度学习 + 海量数据 + 超强算力** 的集大成者，它的发展脉络可参考 [[【LLM】发展历史]]；神经网络的具体结构如何一步步变深、变强，见 [[深度学习]]。而这套"让机器自己学"的底层数学工具（拟合、优化、概率），在 [[线性回归]] 的"梯度下降"和 [[支持向量机]] 的"间隔最大化"里都有体现，属于同一套数学思想的不同应用。
