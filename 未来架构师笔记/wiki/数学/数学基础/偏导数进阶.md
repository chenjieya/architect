[[导数与梯度]] 里求的偏导都是 $f(x,y)=3x+2y$ 这种"每项只有一个变量"的简单货色。但真实机器学习里的函数长这样：MSE 损失 $(wx+b-y)^2$、Sigmoid 函数 $\frac{1}{1+e^{-x}}$——里面有**乘积**、有**分式**、有**套娃（复合）**。这篇就讲怎么拆这些"复杂一点"的偏导，三个新工具：乘积法则、除法法则、链式法则。

## 1. 一句话理解

- **乘积法则**：两项相乘，变化率 = "前项不动×后项的变化 + 前项的变化×后项不动"。
- **除法法则**：分式的导数，分子是"交叉相减"（顺序不能反），分母平方。
- **链式法则**：套娃函数的变化率 = 外层导数 × 内层导数，**层层相乘**。

> 不变的总口诀还是那一句：**对谁求偏导，其他变量一律当常数**。三个法则只是"单项内部怎么拆"的工具。

## 2. 热身：带混合项的多项式

先升级一个基础工具——**幂法则**（基础篇证过 $x^2 \to 2x$，同理可证一般形式）：

$$x^n \;\xrightarrow{\text{求导}}\; n \cdot x^{n-1}$$

大白话：**指数掉下来当系数，指数减一**。比如 $x^3 \to 3x^2$，$y^4 \to 4y^3$。

**例子**：$f(x,y) = 5x^3y^2 + 2xy - 7y^4$。注意 $x^3y^2$ 这种"混合项"——对 $x$ 求偏导时，$y^2$ 整个就是常数系数。

对 $x$ 求偏导（$y$ 当常数）：

| 项         | 当作               | 求导过程              | 结果         |
| --------- | ---------------- | ----------------- | ---------- |
| $5x^3y^2$ | $5y^2 \cdot x^3$ | $5y^2 \cdot 3x^2$ | $15x^2y^2$ |
| $2xy$     | $2y \cdot x$     | $2y \cdot 1$      | $2y$       |
| $-7y^4$   | 常数               | 常数导数为 0           | $0$        |

$$\frac{\partial f}{\partial x} = 15x^2y^2 + 2y$$

对 $y$ 求偏导（$x$ 当常数）：

| 项        | 当作             | 求导过程        | 结果     |
| --------- | ---------------- | --------------- | -------- |
| $5x^3y^2$ | $5x^3 \cdot y^2$ | $5x^3 \cdot 2y$ | $10x^3y$ |
| $2xy$     | $2x \cdot y$     | $2x \cdot 1$    | $2x$     |
| $-7y^4$   | $-7 \cdot y^4$   | $-7 \cdot 4y^3$ | $-28y^3$ |

$$\frac{\partial f}{\partial y} = 10x^3y + 2x - 28y^3$$

> 混合项不可怕：对谁求导，另一个变量的幂就"冻"成系数。

## 3. 乘积法则：两项相乘怎么求

热身例子的项都"天然分得开"。但如果两个**都含 $x$ 的式子**相乘，就不能只冻一边了，需要乘积法则：

$$(uv)' = u'v + uv'$$

| 符号     | 含义                                     |
| -------- | ---------------------------------------- |
| $u$、$v$ | 两个相乘的函数（比如 $u=x^2$，$v=\sin$） |
| $u'v$    | "$u$ 的变化 × $v$ 不动"那一笔账          |
| $uv'$    | "$u$ 不动 × $v$ 的变化"那一笔账          |

### 3.1 求证：乘积法则为什么成立

从导数定义 $\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$ 出发，看乘积 $f(x)g(x)$ 的变化量：

1. **写差值**：$f(x+h)g(x+h) - f(x)g(x)$。
2. **加一项减一项**（证明的核心技巧）：在中间插入 $f(x+h)g(x)$，值不变：
   $$f(x+h)g(x+h) - f(x+h)g(x) + f(x+h)g(x) - f(x)g(x)$$
3. **分两组取极限**：前一组提出 $f(x+h)$，后一组提出 $g(x)$：
   $$= \lim_{h\to0} f(x+h)\cdot\frac{g(x+h)-g(x)}{h} + \lim_{h\to0}\frac{f(x+h)-f(x)}{h}\cdot g(x)$$
4. **各自认出导数**：第一个极限 $= f(x)g'(x)$，第二个 $= f'(x)g(x)$。

于是证明了 $(fg)' = fg' + f'g$。**大白话**：两项相乘的变化，等于"第二项变化贡献 + 第一项变化贡献"两笔账分开记，再相加——就像两个合伙做生意，总增量 = 各自贡献之和。

### 3.2 偏导版：能偷懒就偷懒

对 $x$ 求偏导时，若某一边完全不含 $x$（是"冻住"的常数），乘积法则自动退化成"常数提出来"：

- **能偷懒**：$f = x^2y^3$ 对 $x$：$y^3$ 整个是常数，直接幂法则 $\Rightarrow \frac{\partial f}{\partial x} = 2xy^3$。
- **必须用法则**：两边都含 $x$。比如 $f(x,y) = (3x + y^2)(x^2y)$，对 $x$ 求偏导（$u = 3x+y^2$，$v = x^2y$）：

$$\frac{\partial f}{\partial x} = \underbrace{3 \cdot x^2y}_{u'v} + \underbrace{(3x+y^2)\cdot 2xy}_{uv'} = 3x^2y + 6x^2y + 2xy^3 = 9x^2y + 2xy^3$$

**验证**（两种做法必须一致）：先把原式展开 $(3x+y^2)(x^2y) = 3x^3y + x^2y^3$，再逐项求导也得 $9x^2y + 2xy^3$。✓

## 4. 链式法则：套娃函数的变化率层层相乘（最重要）

**链式法则是三个法则里最重要的**——[[神经网络]] 反向传播的本质就是它。

### 4.1 单变量版

若 $y = f(u)$，而 $u = g(x)$（$y$ 套着 $u$，$u$ 套着 $x$），则：

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

| 符号            | 含义                                |
| --------------- | ----------------------------------- |
| $\frac{dy}{du}$ | **外层**函数的导数（把 $u$ 当整体） |
| $\frac{du}{dx}$ | **内层**函数的导数                  |
| 相乘            | 变化率**层层传递、逐层相乘**        |

**直观推导**：一小步的变化量可以拆账——$\frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u}\cdot\frac{\Delta u}{\Delta x}$（分子分母约掉 $\Delta u$），让 $\Delta x \to 0$ 就得到法则。

**大白话**：自行车变速——脚蹬一圈带轮盘转几圈（第一个传动比），轮盘带后轮又转几圈（第二个传动比），"脚 → 后轮"的总速比就是两个传动比**相乘**。函数套娃也一样：$x$ 动一点引起 $u$ 动多少，$u$ 动一点又引起 $y$ 动多少，连乘起来。

### 4.2 多元版（偏导真正用到的形式）

若 $z = f(u)$，而中间变量 $u = u(x, y)$ 同时依赖两个自变量：

$$\frac{\partial z}{\partial x} = f'(u)\cdot\frac{\partial u}{\partial x}, \qquad \frac{\partial z}{\partial y} = f'(u)\cdot\frac{\partial u}{\partial y}$$

套路固定三步：**认外层 → 认内层 → 外层导数 × 内层偏导**。

### 4.3 例 1：$z = e^{x^2+y^2}$

| 步骤   | 内容                                                    |
| ------ | ------------------------------------------------------- |
| 认外层 | $f(u) = e^u$，而 $e^u$ 的导数还是 $e^u$（自己求导不变） |
| 认内层 | $u = x^2+y^2$，得 $\frac{\partial u}{\partial x}=2x$    |
| 相乘   | $\frac{\partial z}{\partial x} = e^{u}\cdot 2x$         |

$$\frac{\partial z}{\partial x} = 2x\,e^{x^2+y^2}, \qquad \frac{\partial z}{\partial y} = 2y\,e^{x^2+y^2}$$

### 4.4 例 2：$z = \ln(3x^2+2y)$

| 步骤   | 内容                                |
| ------ | ----------------------------------- |
| 认外层 | $f(u)=\ln u$，导数 $\frac{1}{u}$    |
| 认内层 | $u = 3x^2+2y$，对 $x$ 的偏导是 $6x$ |
| 相乘   | $\frac{1}{3x^2+2y}\cdot 6x$         |

$$\frac{\partial z}{\partial x} = \frac{6x}{3x^2+2y}, \qquad \frac{\partial z}{\partial y} = \frac{2}{3x^2+2y}$$

> 常用的三个"外层"导数先背熟：$u^n \to nu^{n-1}$、$e^u \to e^u$、$\ln u \to \frac{1}{u}$。

## 5. 除法法则：分式怎么求

$$(u/v)' = \frac{u'v - uv'}{v^2}$$

| 符号        | 含义                                     |
| ----------- | ---------------------------------------- |
| $u$         | 分子                                     |
| $v$         | 分母                                     |
| $u'v - uv'$ | **交叉相减**：谁求导谁站前面，顺序不能反 |
| $v^2$       | 分母整体平方                             |

### 5.1 求证：除法法则为什么成立

不用死记，它可以从乘积法则 + 链式法则**推出来**。把除法改写成乘法：$\frac{u}{v} = u\cdot v^{-1}$（除以 $v$ = 乘 $v$ 的 $-1$ 次方）。

1. **套乘积法则**：$(u\cdot v^{-1})' = u'\cdot v^{-1} + u\cdot(v^{-1})'$。
2. **用链式法则求 $(v^{-1})'$**：外层是幂函数 $w^{-1}$，导数 $-w^{-2}$；内层是 $v$，导数 $v'$。相乘：$(v^{-1})' = -v^{-2}\cdot v'$。
3. **代回去**：$= \dfrac{u'}{v} - \dfrac{uv'}{v^2}$，通分合并：

$$\frac{u'v - uv'}{v^2}$$

### 5.2 例子：$f(x,y) = \dfrac{x^3}{y+1}$

- 对 $x$（分母 $y+1$ 冻住，能偷懒）：$\dfrac{\partial f}{\partial x} = \dfrac{3x^2}{y+1}$。
- 对 $y$（分子分母都含 $y$，用除法法则）：$u=x^3$ 的 $\frac{\partial u}{\partial y}=0$；$v=y+1$ 的 $\frac{\partial v}{\partial y}=1$：

$$\frac{\partial f}{\partial y} = \frac{0\cdot(y+1) - x^3\cdot 1}{(y+1)^2} = \frac{-x^3}{(y+1)^2}$$

> 大白话记忆：**分子不动、分母动，就出负号**——分母变大，整个分式的值自然变小。

## 6. 实战一：Sigmoid 函数的导数（神经网络激活函数）

[[神经网络]] 里把任意实数压到 $(0,1)$ 的激活函数（除法 + 复合，两大法则同时上场）：

$$\sigma(x) = \frac{1}{1+e^{-x}}$$

**第 1 步：先求分母里的 $e^{-x}$**（链式法则：外层 $e^u$ 导数不变，内层 $-x$ 导数 $-1$）：

$$(e^{-x})' = e^{-x}\cdot(-1) = -e^{-x}$$

**第 2 步：整个分式用除法法则**（$u=1$ 导数为 $0$，$v=1+e^{-x}$ 导数 $-e^{-x}$）：

$$\sigma'(x) = \frac{0\cdot(1+e^{-x}) - 1\cdot(-e^{-x})}{(1+e^{-x})^2} = \frac{e^{-x}}{(1+e^{-x})^2}$$

**第 3 步：变形为著名的紧凑形式**。把分子分母同拆成两个因子：

$$\frac{e^{-x}}{(1+e^{-x})^2} = \underbrace{\frac{1}{1+e^{-x}}}_{\sigma(x)} \cdot \underbrace{\frac{e^{-x}}{1+e^{-x}}}_{1-\sigma(x)}$$

（第二个因子为什么是 $1-\sigma$？因为 $1 - \frac{1}{1+e^{-x}} = \frac{e^{-x}}{1+e^{-x}}$，通分即得。）于是：

$$\boxed{\sigma'(x) = \sigma(x)\bigl(1-\sigma(x)\bigr)}$$

**顺手验证**：$x=0$ 时 $\sigma=0.5$，$\sigma' = 0.5\times0.5 = 0.25$ 是最大值——对应 Sigmoid 曲线"中间最陡、两头变平"的形状。✓

**偏导版**（对权重求导，反向传播的真实形态）：设 $a = \sigma(z)$，$z = wx+b$，则再套一层链式（内层 $\frac{\partial z}{\partial w} = x$）：

$$\frac{\partial a}{\partial w} = \sigma'(z)\cdot x = \sigma(z)\bigl(1-\sigma(z)\bigr)\cdot x$$

## 7. 实战二：线性回归 MSE 损失的偏导（梯度下降的燃料）

[[线性回归]] 用 $\hat{y} = wx+b$ 做预测，用 [[梯度下降]] 找最优的 $w$、$b$——而梯度下降每一步都需要"损失对 $w$、$b$ 的偏导"。现在我们有能力亲手算它了。

**先算单样本**（只有一组数据 $x, y$），损失 $L = (wx+b-y)^2$（预测偏差的平方）。设误差 $u = wx+b-y$，则 $L = u^2$，套链式法则：

| 步骤 | 对 $w$ 求偏导                                     | 对 $b$ 求偏导                       |
| ---- | ------------------------------------------------- | ----------------------------------- |
| 外层 | $u^2 \to 2u$                                      | $u^2 \to 2u$                        |
| 内层 | $\frac{\partial u}{\partial w} = x$（$w$ 的系数） | $\frac{\partial u}{\partial b} = 1$ |
| 相乘 | $2u\cdot x$                                       | $2u\cdot 1$                         |

$$\frac{\partial L}{\partial w} = 2(wx+b-y)\cdot x, \qquad \frac{\partial L}{\partial b} = 2(wx+b-y)$$

**扩展到 $n$ 个样本**（真实 MSE，对每个样本的偏差平方取平均）：

$$\frac{\partial L}{\partial w} = \frac{2}{n}\sum_{i=1}^{n}\bigl(wx_i+b-y_i\bigr)\cdot x_i, \qquad \frac{\partial L}{\partial b} = \frac{2}{n}\sum_{i=1}^{n}\bigl(wx_i+b-y_i\bigr)$$

逐符号拆解：

| 符号                      | 含义                                                                       |
| ------------------------- | -------------------------------------------------------------------------- |
| $x_i,\ y_i$               | 第 $i$ 个样本的特征值和真实值（数据，是死的常数）                          |
| $wx_i+b$                  | 模型对第 $i$ 个样本的预测值 $\hat{y}_i$                                    |
| $wx_i+b-y_i$              | 第 $i$ 个样本的**预测误差**（预测偏高为正、偏低为负）                      |
| $\sum_{i=1}^{n}$          | 把 $n$ 个样本的贡献逐个加起来（求和号）                                    |
| $\frac{2}{n}$             | 两个来源：平方求导掉下来的 $2$ + 取平均的 $\frac{1}{n}$                    |
| 末尾的 $x_i$（仅 $w$ 式） | 链式法则的内层导数：$w$ 的"杠杆"是 $x_i$，误差越大且杠杆越长，$w$ 越该多调 |

这两个公式填进 [[梯度下降]] 的更新式 $w \leftarrow w - \eta\frac{\partial L}{\partial w}$，就是线性回归训练的全部数学。

## 8. 高阶偏导：求完一次再求一次

对偏导数再求一次偏导，就是**二阶偏导**，记号 $\frac{\partial^2 f}{\partial x \partial y}$ 表示"先对 $x$ 再对 $y$"。

以 $f = x^3y^2$ 为例，先求一阶：$\frac{\partial f}{\partial x} = 3x^2y^2$。然后：

- **再对 $x$**：$\dfrac{\partial^2 f}{\partial x^2} = 6xy^2$（对同一变量求两次）。
- **换成对 $y$**：$\dfrac{\partial^2 f}{\partial y\,\partial x} = 6x^2y$（先 $x$ 后 $y$，混合偏导）。

> 两个实用的结论：① 混合偏导**先 $x$ 后 $y$ 和先 $y$ 后 $x$ 结果相同**，不必纠结顺序；② 二阶偏导为正 ≈ "下凸"（碗底），机器学习里用它判断一个点是不是损失函数的最小值点。

## 9. 总结：四步套路与常见坑

**拿到任何复杂偏导，固定四步**：

1. 认变量：对谁求偏导，其余变量全部冻成常数。
2. 拆结构：逐项看是和差（拆开）、乘积（乘积法则）、分式（除法法则）还是套娃（链式法则）。
3. 套法则：外层导数 × 内层导数，逐层往里剥。
4. 合并化简：展开、约分，能偷懒（某侧全为常数）就偷懒。

**四个常见坑**：

- 链式法则**忘乘内层导数**——最常见，$(e^{-x})'$ 写成 $e^{-x}$ 就错了（少了 $-1$）。
- 除法法则分子**顺序写反**——记住"谁求导谁在前"，$u'v - uv'$ 不是 $uv' - u'v$。
- 对 $x$ 求偏导时**把 $x$ 当了常数**——变量搞混，全盘皆错。
- 基础三外层没背熟：$u^n \to nu^{n-1}$、$e^u \to e^u$、$\ln u \to \frac{1}{u}$。

**这条链完整了**：基础求导（[[导数与梯度]]）→ 本篇三大法则 → 损失函数偏导（MSE、Sigmoid）→ [[梯度下降]] 更新参数 → [[线性回归]]、[[神经网络]] 训练全流程。
