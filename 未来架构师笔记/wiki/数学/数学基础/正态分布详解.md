## 1. 一句话理解

正态分布（也叫高斯分布）是统计学里最"常见"的数据分布：**大多数数据往中间靠，越往两边越稀少，形状像一口倒扣的钟。**

- 全班同学的身高，高矮两头的都是少数，多数堆在中间那几个身高。
- 一批零件的直径测量值，贴着标准值的最多，偏离很远的极少。
- 双色球开奖和值，长期统计下来接近 80~122 之间那团"钟形"最密集，极低极高都罕见。

> 注意：它叫"正态"不是"正太"，是 Normal Distribution 的翻译，"正常/常规形态"的意思——因为它出现在太多自然现象里，被当作"最常态"的分布。

## 2. 两个参数决定一切

正态分布只用**两个数字**就能完整描述，不需要别的东西：

| 参数               | 名字     | 作用             | 直观感受       |
| ------------------ | -------- | ---------------- | -------------- |
| $\mu$（均值）      | 中心位置 | 决定钟形顶点在哪 | 数据"平均"在哪 |
| $\sigma$（标准差） | 离散程度 | 决定钟形胖瘦     | 数据"散不散"   |

> 其中 $\mu$ 就是概率里的**期望**、$\sigma$ 就是**标准差**（方差的平方根），想先搞懂这两个基础概念，见 [[概率基础]]。

- **$\mu$ 相同、$\sigma$ 不同**：钟形顶点在同一位置，但 $\sigma$ 小的又高又瘦（数据很集中），$\sigma$ 大的又矮又胖（数据很分散）。
- **$\sigma$ 相同、$\mu$ 不同**：形状完全一样，只是整体平移了一个位置。

### 2.1 公式长什么样

$$f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

不用背——只需要先认识里面出现的两个"固定常数"（它们不是变量，是写死的数）：

- **$\pi$（圆周率）≈ 3.14159**：圆的周长除以直径，早就认识的老朋友。
- **$e$（自然常数）≈ 2.71828**：一个和"连续增长/衰减"有关的特殊数，$e^x$ 是最"自然"的指数函数，专门用来描述"随距离平滑衰减"这类变化。这里 $e$ 的指数上挂着一个负数平方，就形成了中间高、两边低的钟形。

再看两个信号：

1. 分母有 $\sigma$：参数越大，$\frac{1}{\sigma\sqrt{2\pi}}$ 越小，曲线整体越矮（数据分散了自然就不集中）。
2. 指数部分 $-\frac{(x-\mu)^2}{2\sigma^2}$：离 $\mu$ 越远，$(x-\mu)^2$ 越大，负号让 $e$ 的指数越小，值就越低。**平方**保证了 $\mu$ 左右两侧完全对称。

### 2.2 $\mu$ 和 $\sigma$ 从哪来

用一组数据就能估计出来，这正是 [[标准差公式详解]] 里做的那件事：

```python
import numpy as np
data = np.array([...])
mu = data.mean()     # 中心位置
sigma = data.std()   # 离散程度（默认总体标准差 ddof=0）
```

均值告诉你"在哪"，标准差告诉你"靠不靠谱"，两个一起才是完整画像。

## 3. 最重要的数字：68-95-99.7

正态分布有个超级好用的经验法则，只要知道 $\mu$ 和 $\sigma$，就能立刻回答"数据大概落在哪"：

| 区间              | 覆盖的数据比例 |
| ----------------- | -------------- |
| $\mu \pm 1\sigma$ | 约 **68%**     |
| $\mu \pm 2\sigma$ | 约 **95%**     |
| $\mu \pm 3\sigma$ | 约 **99.7%**   |

把这些区间画到钟形曲线上，就是下面这张图——由浅到深的三块蓝色区域，分别对应 68%、95%、99.7% 的覆盖面积：

![](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786864929646_正态分布钟形曲线.png)

**举个例子**：某班考试成绩均值 70 分，标准差 10 分，且近似正态：

- 大约 68%（三分之二左右）的人考在 **60~80 分**（70±10）。
- 大约 95% 的人考在 **50~90 分**（70±20）。
- 超过 **40~100**（70±30）之外的，几乎是极端情况（满分 100 时 100 就到顶了，这正好说明成绩分布并不完美正态，只有近似）。

> 反过来用（异常检测）：99.7% 都在 $\mu\pm3\sigma$ 内，那么落在外面的点大概率是**异常值/脏数据**。这就是 [[标准差公式详解]] 里 3σ 法则、异常值过滤的来历。

## 4. 套到任何分布的"换算尺子"：Z-score

不同分布的大小、单位都不一样，怎么比较？把每个点换算成"距 μ 有几个 σ"，得到无量纲的 **Z-score**：

$$
z = \frac{x - \mu}{\sigma}
$$

- $z=0$：恰好落在均值，最"普通"。
- $z=1.5$：比平均高 1.5 倍标准差，偏上，但不极端。
- $z=-2$：比平均低 2 个标准差，进入"约 95%"的边缘区。

**对比的威力**：身高 175cm 和薪资 20k 看起来不是一个量纲，但各自减去均值、除标准差后，就能比较"175 在身高里的位置"和"20k 在薪资里的位置"谁的相对水平更高。这也是机器学习做特征标准化的原理（`StandardScaler`）。

## 5. 不要踩的坑

**坑 1：正态 ≠ ∀ 数据都服从的"常数"，先验**。很多现实分布是偏度（skewed）的，比如房价（少数天价拉出长尾）、收入（少数富豪拖出长尾）。先看分布（直方图、QQ 图）再谈正态，别默认。

**坑 2：μ±1σ 覆盖 68% 的前提是近似正态**。数据很不正态时，68-95-99.7 不成立，直接用会高估区间覆盖。

**坑 3：统计分析不必正态得十全十美**。许多统计检验（如 t 检验）只要求样本均值近似正态，靠大样本（中心极限定理）就能成立，不要求原始数据严格正态。

**坑 4：别迷信"正态即最好"。**正态便于计算，但真实世界长尾分布（幂律）到处都是，数据处理时按分布形态对症下药。

## 6. 在数据科学工具包里怎么用

正态分布在 [[NumPy数据操作]]、[[Pandas数据类型]]、[[Seaborn可视化]] 里的实际用法：

### 6.1 生成正态随机数

```python
import numpy as np
arr = np.random.normal(loc=170, scale=6, size=1000)   # 均值170 标准差6 的1000个身高
```

- `np.random.normal(μ, σ, 样本数)`：直接生成服从 N(μ,σ²) 的数组。
- 再配 `arr.mean()` / `arr.std()` 就能验证数据确实近似 ddof 里的 μ 和 σ。

### 6.2 判断一批数据正不正态

```python
import numpy as np
mean, std = arr.mean(), arr.std()
within_1 = np.mean((arr > mean - 1*std) & (arr < mean + 1*std))   # 期望 ≈ 0.68
within_2 = np.mean((arr > mean - 2*std) & (arr < mean + 2*std))   # 期望 ≈ 0.95
```

### 6.3 可视化确认

```python
import seaborn as sns
sns.histplot(arr, kde=True)     # 直方图 + 核密度曲线，正态应是对称钟形
sns.kdeplot(arr, fill=True)     # 只画密度曲线
```

用 [[Seaborn可视化]] 里学的直方图/核密度图一眼确认是钟还是长尾，比盲目套公式靠谱。

## 7. 总结

- 正态分布 = 两个参数（μ 中心、σ 胖瘦）决定的对称钟形。
- 最常用结论：**68-95-99.7**，一套 σ 就能推算出约 68%/95%/99.7% 的数据区间。
- 想比较不同分布/量纲，用 Z-score 换算成"距均值几个标准差"。
- 想识别异常、标准化特征、验证分布，先可视化再按公式，别硬套。
