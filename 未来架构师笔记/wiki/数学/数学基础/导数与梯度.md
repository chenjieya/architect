导数、偏导数、梯度是机器学习的"地基中的地基"——[[线性回归]] 的梯度下降、[[神经网络]] 的反向传播，全靠它们。这篇文章从最简单的"斜率"讲起，一步步推到"梯度"，让你彻底搞懂这些词到底在说什么。

## 1. 一句话理解

- **导数**：曲线在某一点的"瞬时斜率"——它正往上爬还是往下掉，爬得多快。
- **偏导数**：一个多变量函数，只盯着其中一个变量求导（其余变量当常数）。
- **梯度**：把所有偏导数打包成一个向量，指向函数值"上升最快"的方向。

> 记住一句话就够了：**梯度告诉我们"往哪个方向走，函数值涨得最快"；反过来（负梯度），就是跌得最快**——这正是 [[梯度下降]] 的全部依据。

## 2. 先从斜率说起：直线有多陡

一条直线，我们用一个数就能描述它多陡——**斜率**：

$$\text{斜率} = \frac{\text{竖直方向的变化}}{\text{水平方向的变化}} = \frac{\Delta y}{\Delta x}$$

- $\Delta$（Delta）读作"变化量"，$\Delta y$ 就是"y 变了多少"，$\Delta x$ 就是"x 变了多少"。
- 斜率 = 2，意思是"x 每前进 1，y 就上升 2"。
- 斜率是负数，表示"往下走"。

**举例**：直线 $y=2x+1$，斜率就是 2。你走一步（x+1），它就爬高 2。

> 但直线是"从头到尾一样陡"。现实里的曲线（比如 $y=x^2$）每一处的陡峭程度都不一样——这时候就需要**导数**。

## 3. 导数：曲线在某一点的"瞬时斜率"

曲线不是直的，那怎么衡量"某一点的陡峭程度"？办法是：**在这一点画一条"刚好贴着曲线"的切线，切线的斜率就是这点的导数**。

![](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786869567688_导数切线图.png)

如图所示，曲线 $y=x^2$ 在每一点的切线斜率都不同（越往右越陡）。这个"切线斜率"就是导数，记作 $f'(x)$ 或 $\frac{dy}{dx}$。

### 3.1 导数的定义（公式逐符号拆解）

$$f'(x) = \lim_{h \to 0}\frac{f(x+h) - f(x)}{h}$$

| 符号                        | 含义                                                        |
| --------------------------- | ----------------------------------------------------------- |
| $f(x+h)-f(x)$               | 让 x 前进一小步 $h$ 后，函数值变了多少（也就是 $\Delta y$） |
| $h$                         | 水平方向那一小步（也就是 $\Delta x$）                       |
| $\frac{\Delta y}{\Delta x}$ | 这一小段的"平均斜率"                                        |
| $\lim_{h\to 0}$             | 让这一小步 $h$ 无限缩小到 0，取极限——就得到"瞬间"的斜率     |

**大白话**：先算一小段"平均坡度"，再让这一小段缩到无限小，剩下的就是"这一点瞬间的坡度"——这就是导数。

### 3.2 求证：$f(x)=x^2$ 的导数为什么是 $2x$

光知道定义还不够，我们亲手算一遍，看看"证明"是怎么做的：

1. **先写差值**：$f(x+h) - f(x) = (x+h)^2 - x^2$。
2. **展开平方**：$(x+h)^2 = x^2 + 2xh + h^2$，所以差值 $= x^2 + 2xh + h^2 - x^2 = 2xh + h^2$。
3. **除以 $h$**：$\frac{2xh + h^2}{h} = 2x + h$。
4. **让 $h$ 趋近 0**：$\lim_{h\to 0}(2x + h) = 2x$。

于是我们**证明了**：$f'(x) = 2x$。也就是说，$y=x^2$ 在 $x=3$ 处，切线斜率就是 $2\times3=6$（意味着这附近"x 每前进 1，y 约上升 6"）。

> 这就是"求证公式"的意义：不是背"$x^2$ 求导等于 $2x$"，而是**从定义一步步推出 $2x$**，理解它为什么成立。

## 4. 偏导数：多个变量时，只盯着一个求导

现实中的函数往往有多个输入。比如房价可能同时取决于"面积 $x$"和"房龄 $y$"：

$$z = f(x, y)$$

**偏导数**就是：把其他变量当成常数，只对其中一个变量求导，记作 $\frac{\partial f}{\partial x}$。

- $\frac{\partial f}{\partial x}$（对 x 的偏导）：问"只改面积、房龄不变时，房价怎么变"。
- $\frac{\partial f}{\partial y}$（对 y 的偏导）：问"只改房龄、面积不变时，房价怎么变"。

**举例**：$f(x,y)=3x + 2y$。

- 对 $x$ 求偏导：把 $2y$ 当常数，$3x$ 的导数是 $3$，所以 $\frac{\partial f}{\partial x}=3$。
- 对 $y$ 求偏导：把 $3x$ 当常数，$2y$ 的导数是 $2$，所以 $\frac{\partial f}{\partial y}=2$。

> 求偏导的方法和求普通导数一模一样，只是"别的变量当空气"。

遇到乘积、分式、复合函数（比如 $(wx+b-y)^2$、$\frac{1}{1+e^{-x}}$）这种"复杂一点"的偏导，需要乘积、除法、链式三大法则，见 [[偏导数进阶]]。

## 5. 梯度：把所有偏导数打包，指向最陡方向

把函数所有变量的偏导数拼在一起，就得到一个向量，叫**梯度**，记作 $\nabla f$（倒三角，读作 nabla）：

$$\nabla f = \left(\frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y}\right)$$

比如 $f(x,y)=3x+2y$ 的梯度就是 $(3, 2)$。

**梯度最重要的性质：它指向函数值上升最快的方向，大小等于上升的速率。**

![](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786869567691_梯度方向图.png)

图中一圈圈的是"等高线"（同一高度连成的线），箭头就是各点的梯度方向——它们总是**垂直于等高线、指向高度上升最快的方向**（就像爬山时，最陡的上山路总是垂直于等高线）。

### 5.1 求证：为什么梯度方向是"上升最快"的方向

站在某一点，四面八方都可以走，问"沿哪个方向走，函数值涨得最快"？

- 沿任意方向走，上升速率 = **梯度的大小 $\times$ cos(这个方向与梯度方向的夹角)**。
- cos 的最大值是 1，出现在"夹角为 0°"时——也就是**正好沿梯度方向走**。
- 所以沿梯度方向走，上升最快；沿反方向（负梯度）走，下降最快。

> 用大白话记：cos 表示"两个方向的贴合程度"，夹角越小越贴合，上升越快；完全贴合（夹角 0°）时最快。这条性质就是 [[梯度下降]] 里"每次都朝负梯度方向挪一步"的根本原因。

## 6. 为什么必须懂这些

- [[线性回归]] 的 MSE 损失函数要找最小值 → 靠 [[梯度下降]]。
- [[梯度下降]] 要判断"往哪走损失下降最快" → 靠梯度（负梯度方向）。
- [[神经网络]] 的反向传播要更新每个权重 → 靠偏导数（对每个权重求偏导）。

所以这三者是一条链：**导数/偏导数 → 梯度 → 梯度下降**。

## 7. 总结

- **导数** = 曲线某点的切线斜率（瞬时变化率），从定义 $\lim\frac{f(x+h)-f(x)}{h}$ 一步步能推出 $x^2$ 的导数是 $2x$。
- **偏导数** = 多变量函数里"只盯着一个变量"求导。
- **梯度** = 所有偏导数组成的向量，**指向上升最快方向**（证明：上升速率 = 梯度大小 × cos 夹角，夹角 0° 时最大）。
