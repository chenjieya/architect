线性回归是机器学习里最简单、也最经典的一个算法，常常是入门的第一站。别小看它——很多复杂模型的思想都能在它身上找到影子。

## 1. 一句话理解

**画一条"最贴合数据"的直线，用它来预测数值。**

比如知道一堆房子的"面积"和"成交价"，画出一条直线后，就能拿一个新面积去"套"出一个大概的价格。

> 它属于[[【基础】AI的分类：三大流派与机器学习入门]]里的**监督学习**（数据带答案），处理的是"预测一个连续数字"的回归问题。

## 2. 核心思想：找到那条"最好"的直线

一条直线可以写成：

$$y = w \cdot x + b$$

- $x$：输入（自变量），比如房子面积。
- $y$：输出（预测值），比如预测的房价。
- $w$：斜率，也叫**权重**，决定这条线多"陡"。
- $b$：截距，也叫**偏置**，决定这条线在竖轴上的位置。

把 $w$ 和 $b$ 套进房价例子里，感受一下它们"管什么"：

- **斜率 $w$**：每多 1 平米，房价涨多少。若 $w=2$，就是"面积每增加 1 平米，价格大约涨 2 万"——$w$ 越大，线越陡，涨得越猛。
- **截距 $b$**：当面积为 0 时，直线在价格轴上的"起步位置"。它让整条线整体往上抬或往下压。

"学"线性回归，本质就是**从数据里找到最合适的 $w$ 和 $b$**。

### 2.1 什么叫"最贴合"

让直线尽量"穿过"所有点的中间——也就是让**预测值和真实值之间的差距最小**。这个差距用"损失函数"来度量，最常用的是均方误差（MSE）：

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

这个式子看着吓人，拆成"零件"就懂了：

| 符号              | 读法 / 含义                                                  |
| ----------------- | ------------------------------------------------------------ |
| $\sum$            | 大写希腊字母 Sigma，意思是"**求和**"——把后面的东西全部加起来 |
| $\sum_{i=1}^{n}$  | 让 $i$ 依次取 1、2、3……直到 $n$，逐个累加                    |
| $n$               | 数据的个数（一共有多少套房子）                               |
| $y_i$             | 第 $i$ 个数据的**真实值**（真实成交价）                      |
| $\hat{y}_i$       | 第 $i$ 个数据的**预测值**（直线算出来的价）                  |
| $(y_i-\hat{y}_i)$ | 真实值减预测值，就是"**这个点差了多少**"，可正可负           |

再看整体 $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ 一步步做了什么：

1. **先求差**：每个点都算一遍"真实价 − 预测价"。
2. **再平方**：把负数变成正数，同时"离得特别远的点"被放大，惩罚更狠。
3. **再求和**：把所有点的差距平方累加起来，得到"总的误差"。
4. **最后除以 $n$**：取平均，得到"平均每个点差多少"——这就是 MSE。

> 为什么要平方而不是直接求和？因为差距有正有负，直接加会互相抵消（+3 和 −3 相加得 0，看起来像没误差）。平方保证所有误差都往"正"里贡献。这套"偏差 → 平方 → 平均"的思路，和 [[标准差公式详解]] 里的做法一模一样。

目标就是**不断调整 $w$、$b$，让 MSE 越小越好**。

### 2.2 怎么调：梯度下降

怎么知道该把 $w$、$b$ 往哪个方向调？答案是**梯度下降**——一种"沿最陡下坡方向一步步走"的优化方法：

1. 站在当前 $w$、$b$ 的位置，算一下损失函数的"坡度"（梯度）。
2. 朝坡度最陡的下坡方向迈一小步，损失就会变小一点。
3. 反复走，直到走不动（损失几乎不再下降）为止，就找到了"谷底"。

这个"谷底"对应的 $w$、$b$，就是我们要的那条直线。

## 3. 一个例子：预测房价

假设我们收集了 3 套房子的数据：

| 面积（平方米） | 成交价（万元） |
| -------------- | -------------- |
| 60             | 150            |
| 90             | 210            |
| 120            | 270            |

把这 3 个点画到坐标系里，再用一条直线"兜住"它们，就是这个样子：

![](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786864919454_线性回归拟合图.png)

这条直线是 $y=2x+30$（也就是 $w=2$、$b=30$）：**每多 1 平米，价格大约多 2 万**。于是对一个 100 平米的新房，代入 $y=2\times100+30$，可以预测约 **230 万**左右。图中那些**灰色虚线**，就是每个真实点和直线之间的"差距"——MSE 衡量的正是这些差距的平均大小。

**关键点**：它假设"面积和价格之间是直线关系"。如果真实关系是弯曲的（比如面积特别大时单价反而下降），这条直线就不准了——这是线性回归最大的局限。

## 4. 适用场景与局限

**适用**：

- 预测连续数值：房价、销量、气温、广告投入与收益。
- 数据量不大、关系近似线性、需要快速得到可解释结果。

**局限**：

- **只能表达线性关系**，遇到曲线规律无能为力（可以引入多项式特征补救）。
- **对异常值敏感**：一个离群点就可能把整条直线"带歪"。
- **假设各特征相互独立**，特征之间强相关时效果打折。

## 5. 在数据科学工具包里怎么用

用 NumPy 可以快速做一次最简单的线性拟合；scikit-learn 的 `LinearRegression` 是最常用的现成实现。更多数组与统计操作见 [[NumPy数据操作]]、[[标准差公式详解]]。

## 6. 总结

- 线性回归 = **一条直线 + 最小二乘（或梯度下降）找参数**。
- 核心是"让预测值和真实值的差距（MSE）最小"。
- 简单、可解释、适合预测数值，但只能拟合线性关系。
