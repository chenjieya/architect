## 2. 推荐学习顺序（从何学起）

### 2.1 第一站：统计基础（先看懂"数据长什么样"）

1. [[概率基础]]：概率、条件概率、期望、方差——后面所有 $\mu$、$\sigma$ 的来源。
2. [[标准差公式详解]]：标准差公式逐项拆解，搞懂"数据有多散"怎么量化。
3. [[正态分布详解]]：最常用的分布，68-95-99.7 法则。

> 这一站解决"怎么描述一组数据"，是数据分析和特征工程的根。

### 2.2 第二站：微积分与优化（再看懂"模型是怎么学会的"）

4. [[导数与梯度]]：斜率 → 导数 → 偏导数 → 梯度，理解"往哪个方向走涨得最快"。
5. [[梯度下降]]：沿负梯度一步步找最小值，这是几乎所有模型"训练"的共同内核。
6. [[偏导数进阶]]：乘积、除法、链式三大法则，亲手算出 Sigmoid 与 MSE 的偏导。

> 这一站解决"模型凭什么能自己变好"，是理解神经网络、深度学习训练的前提。

### 2.3 第三站：线性代数（看懂"神经元其实是一张表格"）

7. [[矩阵与线性代数]]：矩阵相加、乘法（行×列）、转置、向量方向。神经网络每一层本质就是矩阵运算，这一步是看懂"神经网络"和"深度学习"代码的钥匙。
8. [[矩阵求导与梯度矩阵]]：损失对权重矩阵的梯度（$\frac{\partial L}{\partial W}=\delta\cdot a^\top$），是反向传播、梯度下降矩阵化的最后一块拼图。

> 这一站解决"神经网络那堆神经元到底在算什么"——答案是一次矩阵乘法；以及"训练时矩阵怎么更新"——答案是梯度矩阵。看完你会明白：所谓"神经元"只是"权重矩阵的一行"。

### 2.4 插曲：高频工具函数（学注意力/分类前先认识它）

- [[Softmax详解]]：把任意一串分数变成"非负、和为 1"的概率权重。注意力机制、分类层、大模型预测下一个词全都靠它，属于"地基之外的通用工具"。

> 想看懂注意力机制（[[【基础】注意力机制]]）里"softmax 把分数变权重"那一步，或分类/生成模型的输出层，先花十分钟认识它。

### 2.5 第四站：机器学习算法（把地基用到算法上）

9. [[机器学习算法谱系]]：先看总览，建立"浅层 → 深层"的地图。
10. [[线性回归]] → [[决策树]] → [[支持向量机]]：三个浅层方法，由易到难。
11. [[神经网络]] → [[深度学习]]：把前面的导数、梯度、概率、矩阵全用上。

> 这一站是"主角"，但建议先走完前三站再进来。

## 3. 哪些文章是"公式推导/证明"页

有些文章除了讲"是什么、怎么用"，还专门花了篇幅**证明"公式为什么成立"**。如果你想深挖原理，重点看这几篇：

| 文章               | 证明了什么公式 / 结论                                                     |
| ------------------ | ------------------------------------------------------------------------- |
| [[概率基础]]       | 期望线性性 $E(aX+b)=aE(X)+b$；方差公式 $Var=E(X^2)-\mu^2$                 |
| [[标准差公式详解]] | 样本标准差为什么除以 $n-1$（无偏估计）                                    |
| [[导数与梯度]]     | $f(x)=x^2$ 的导数是 $2x$；梯度是上升最快方向                              |
| [[梯度下降]]       | 沿负梯度方向走，函数值必然下降                                            |
| [[偏导数进阶]]     | 乘积/除法/链式法则；$\sigma'=\sigma(1-\sigma)$；MSE 偏导                  |
| [[Softmax详解]]    | 二分类时 Softmax 退化为 Sigmoid：$\dfrac{e^x}{e^x+1}=\dfrac{1}{1+e^{-x}}$ |

> 只想"会用公式"的话，证明部分可以跳过；但如果你想搞懂"它凭什么对"，就点进上面这几篇看推导。
