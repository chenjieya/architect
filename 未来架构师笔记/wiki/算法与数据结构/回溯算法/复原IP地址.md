## 1. 复原IP地址

每段必须用 1 到 3 个数字，数值在 0 到 255，除单独的 0 外不能以 0 开头。递归状态同时记录已消耗字符数和已确定的段数。

### 1.1 思路与过程

1. 从当前位置尝试取 1、2、3 个字符作为下一段，排除超过 255 或含多位前导零的候选。选中一段后继续处理剩余字符，返回时撤销。

2. 还剩 r 段时，未用字符至少需要 r 个、至多 3r 个；超出范围可立即剪枝。第 4 段完成后，只有同时用完所有字符才是答案。

3. 25525511135 可以分成 255.255.11.135 与 255.255.111.35；0000 只有 0.0.0.0。这里是在处理十进制文本分段，不能用允许不同前缀或自动忽略非法后缀的宽松数值解析代替规则检查。

### 1.2 适用条件与容易出错的地方

输入必须全是 ASCII 数字，长度只能为 4 到 12。恰好四段且恰好用完输入才收集结果。固定 IPv4 限制使分支树有常数上界；不能把它泛称为随任意长度增长的指数算法。
