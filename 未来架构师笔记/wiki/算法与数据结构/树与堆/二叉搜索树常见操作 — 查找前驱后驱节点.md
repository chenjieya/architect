## 1. 二叉搜索树常见操作 — 查找前驱后驱节点

删除有两个孩子的节点时，取右子树最小值覆盖当前值，再在右子树删掉那一个值，避免重复。递归返回的是新的子树根，父节点和外部调用者都要接住。

### 1.1 本页关注

这里讨论严格小于目标的最大值与严格大于目标的最小值。目标不必存在；若找不到候选应返回无结果，不能用固定数值 0 代替，因为 0 也可能是合法键。

### 1.2 思路与过程

1. 删除叶子用空位置替换；只有一个孩子时用该孩子替换；两个孩子时取右子树最小节点的值覆盖当前值，再递归删除右子树中的那一个节点。后一步必须调用删除函数，不能写成 JavaScript 的 delete 运算。

2. 每层递归返回新子树根，父节点要把它接到原来的左或右位置。删除整棵树的根时，外部也要保存返回值，否则仍可能拿着已失效的旧根。

3. 查严格前驱时，当前值小于目标便可作为候选并尝试右侧寻找更大者；否则向左。后继完全对称。这个版本即使目标不在树中也有意义；如果要求“存在节点的中序前驱”，需要另做存在性检查。

### 1.3 适用条件与容易出错的地方

用 root=deleteNode(root,target) 保存结果。前驱函数返回最大的小于 target 的值，后继返回最小的大于 target 的值，即使 target 不存在也可按此边界查询解释。单次复杂度 O(h+1)。
