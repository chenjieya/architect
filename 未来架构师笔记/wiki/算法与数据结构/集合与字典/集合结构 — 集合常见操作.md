## 1. 集合结构 — 集合常见操作

数学集合不依赖顺序；JavaScript Set 为遍历规定插入顺序。内置 Set 可区分数字 1 和字符串 1，对象按引用区分，NaN 按 SameValueZero 规则视为同一个值。

### 1.1 本页关注

并集先收集一边再补另一边未出现的值；交集检查成员资格；差集只保留左边独有的值；子集关系要求左边每一项都在右边。任何一种都不能简单用数组长度关系代替。

### 1.2 思路与过程

1. 集合回答某个值是否存在，不为重复添加同一值增加第二份记录。并集包含任一集合中的值，交集只保留两边都有的值，差集保留左边有而右边没有的值。

2. JavaScript Set 使用 SameValueZero 判断值相等：NaN 与 NaN 算同一值，正零与负零算同一值，对象则按引用区分。它还规定插入顺序，但数学集合运算本身不依赖排列。

3. 用普通对象模拟集合时，数字键与同形字符串可能合并，原型属性也会干扰存在性判断。限定字符串并使用无原型对象可减少这些问题，但仍不等价于通用 Set。SQL 的 JOIN 连接记录，不能直接当作集合交集的同义词。

### 1.3 适用条件与容易出错的地方

对象模拟版本应限定字符串键，并使用无原型对象避免特殊属性名影响；它不是通用 Set 的替代。自制 size()/values() 常需扫描元素；内置 size 是属性，values() 返回迭代器。

### 1.4 规范核对

键值集合的相等规则与遍历顺序应以语言规范为准。参见 [ECMAScript 键值集合规范](https://tc39.es/ecma262/multipage/keyed-collections.html)。
