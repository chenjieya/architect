> 前言： docker 启动挂载 nginx[[docker_nginx]]

## 1. 基础配置讲解

```nginx
worker_processes  1;  # 启动多少个子进程

# 事件驱动模块
events {
    worker_connections  1024; # 每个worker子进程可以创建多少连接
}

http {
    include       mime.types;  # 将其他文件引入到当前文件（mime.types文件记录的是什么类型的文件Content-Type）
    default_type  application/octet-stream; # 默认类型，如果不包含在mime.types中，则以当前类型告诉浏览器让浏览器解析

    sendfile        on;  # 数据0拷贝 1

    keepalive_timeout  65;


    # 虚拟主机-每个主机互相不干扰
    server {
        listen       8090;  # 监听服务的端口号
        server_name  localhost;  # 域名、主机名 最后会解析成ip地址
        location / {
            root   html;
            index  index.html index.htm;
            try_files $uri $uri/ /index.html;
        }

        location /api/ {
            rewrite ^/api(/.*)$ $1 break;
            proxy_pass https://httpbin.org;
        }
        error_page   500 502 503 504  /50x.html;   # 服务端错误的时候错误码 转到内部的地址 /50x.html
        location = /50x.html {  # 匹配到这个路径
            root   html;    # 去html下面找50x.html
        }
    }
}
```

## 2. 一个 ip 端口，对应多个网站

通过设置域名，`server_name`监听域名,_如果域名可以解析，但是没有匹配上 nginx 配置，会默认走第一个配置_

```nginx
server {
	listen	80; # 监听80端口
	server_name	www.cj.com;  # 监听域名

	location / {
		root /usr/share/nginx/html/www; # 访问www下的网站
		index index.html index.html;
	}
	error_page   500 502 503 504  /50x.html;
	location = /50x.html {
		root   /usr/share/nginx/html;
	}
}
server {
	listen	80; # 监听80端口
	server_name	vod.cj.com; # 监听域名

	location / {
		root /usr/share/nginx/html/vod; # 访问vod下的网站
		index index.html index.html;
	}
	error_page   500 502 503 504  /50x.html;
	location = /50x.html {
		root   /usr/share/nginx/html;
	}
}
```

## 4. 负载均衡

> 现在有三台机器： `192.168.1.19本机` `192.168.1.21windowserver` `192.168.1.25debian`

以 192.168.1.25debian 为主机

`weight`权重比例

`down`不参加负载均衡

`backup`备用机器，正确情况下是不参加负载均衡得

```nginx
upstream httpds {
	server 192.168.1.19:8090 weight=10; # 这个服务好一点
	server 192.168.1.21:8090 weight=2 down backup;  # 这个服务垃圾
}

server {
	listen	80;
	server_name	vm1.alvis.org.cn;
	location / {
		proxy_pass http://httpds;
		#root /usr/share/nginx/html/www;
		#index index.html index.html;
	}
	error_page   500 502 503 504  /50x.html;
        location = /50x.html {
        	root   /usr/share/nginx/html;
    	}
    }
# 刷新页面，一次指向`192.168.1.19:8090`站点、一次指向`192.168.1.21:8090`站点（轮询，不加权重）
# 加了权重之后，则会按照权重比例出现
```

## 5. URLRewrite 伪静态配置

1. rewrite 语法格式及参数语法：

```nginx
#rewrite是实现URL重写的关键指令，根据regex (正则表达式)部分内容，
#重定向到replacement，结尾是flag标记。

rewrite    <regex>    <replacement>    [flag];
#关键字      正则       替代内容          flag标记

# 关键字：其中关键字error_log不能改变
#正则：perl兼容正则表达式语句进行规则匹配
#替代内容：将正则匹配的内容替换成replacement
#flag标记：rewrite支持的flag标记

#rewrite参数的标签段位置： server,location,if

#flag标记说明：
last #本条规则匹配完成后，继续向下匹配新的location URI规则
break #本条规则匹配完成即终止，不再匹配后面的任何规则
redirect #返回302临时重定向，浏览器地址会显示跳转后的URL地址
permanent #返回301永久重定向，浏览器地址栏会显示跳转后的URL地址
```

实例

```nginx
rewite ^/([0-9]+).html$    /index.jsp?pageNum=$1    break;
```

## 7. 防盗链

`valid_referers none | blocked | server_names | strings ....;`

- none， 检测 Referer 头域不存在的情况。** (单独在浏览器打开图片，没有 referer)**
- blocked，检测 Referer 头域的值被防火墙或者代理服务器删除或伪装的情况。这种情况该头域的值不以 “http://” 或 “https://” 开头。
- server_names ，设置一个或多个 URL ，检测 Referer 头域的值是否是这些 URL 中的某一个。

```nginx
# 只有通过vm1.alvis.org.cn才能访问到图片，其他站点，或者在浏览器单独打开访问不到。甚至是vm1.alvis.org.cn解析得ip都访问不到图片。
location /img/ {
	valid_referers vm1.alvis.org.cn;
		if ($invalid_referer) {
		return 403;
	}

	alias /usr/share/nginx/html/img/;
}
```

```nginx
# Referer不存在得情况下可以访问，例如：浏览器单独访问图片
location /img/ {
	valid_referers none vm1.alvis.org.cn;
		if ($invalid_referer) {
		return 403;
	}

	alias /usr/share/nginx/html/img/;
}
```
