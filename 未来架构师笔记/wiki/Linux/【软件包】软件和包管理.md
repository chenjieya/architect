## 1. RPM 包管理

> 发行版与包管理机制的横向关系见 [[虚拟机基础事项]]。

### 1.1 RPM 简介

RPM（Red Hat Package Manager）是 Red Hat 系列 Linux 发行版的标准包管理工具，用于软件的安装、升级、查询和卸载。

### 1.2 RPM 常用命令

#### 1.2.1 安装软件包

```bash
# 安装软件包（i=install, v=verbose, h=hash显示进度条）
rpm -ivh package-name.rpm

# 示例
rpm -ivh nginx-1.18.0.rpm
```

#### 1.2.2 卸载软件包

```bash
# 卸载软件包
rpm -e package-name

# 示例
rpm -e nginx
```

#### 1.2.3 查询软件包

```bash
# 查询文件属于哪个软件包
rpm -qf /path/to/file

# 示例：查询ls命令属于哪个包
which ls          # 输出：/bin/ls
rpm -qf /bin/ls   # 输出：coreutils-8.4-13.el6.i686

# 查询已安装的所有软件包
rpm -qa

# 查询特定软件包是否安装
rpm -qa package-name

# 示例：查询syslinux相关包
rpm -qa | grep syslinux
```

#### 1.2.4 查询软件包详细信息

```bash
# 查询软件包头信息
rpm -qi package-name

# 示例
rpm -qi obexd-0.19-2.el6.i686

# 查询软件包包含的文件列表
rpm -ql package-name

# 示例
rpm -ql obexd-0.19-2.el6.i686
```

#### 1.2.5 升级软件包

```bash
# 升级软件包
rpm -Uvh package-name.rpm

# 示例
rpm -Uvh nginx-1.20.0.rpm
```

### 1.3 RPM 命令总结表

| 命令       | 功能             | 示例                     |
| ---------- | ---------------- | ------------------------ |
| `rpm -ivh` | 安装软件包       | `rpm -ivh nginx.rpm`     |
| `rpm -e`   | 卸载软件包       | `rpm -e nginx`           |
| `rpm -qf`  | 查询文件所属包   | `rpm -qf /bin/ls`        |
| `rpm -qa`  | 查询所有已安装包 | `rpm -qa \| grep python` |
| `rpm -qi`  | 查询包信息       | `rpm -qi nginx`          |
| `rpm -ql`  | 查询包文件列表   | `rpm -ql nginx`          |
| `rpm -Uvh` | 升级软件包       | `rpm -Uvh nginx-new.rpm` |

## 2. YUM 包管理

### 2.1 YUM 简介

YUM（Yellowdog Updater Modified）是基于 RPM 的包管理器，能够自动解决依赖关系，从仓库中下载并安装软件包。

### 2.2 YUM 仓库配置

#### 2.2.1 服务端设置方式

1. **本地目录共享** - 仅供本机使用
2. **局域网服务** - FTP/HTTP 服务，供局域网使用
3. **公网仓库** - 阿里云、CentOS 官方仓库等

#### 2.2.2 客户端配置

配置文件位置：`/etc/yum.repos.d/` 目录下的 `.repo` 文件

##### 2.2.2.1 A. 本地目录共享配置

```bash
# 首先挂载ISO镜像
mount /dev/sr0 /mnt

# 创建仓库配置文件
vi /etc/yum.repos.d/local.repo
```

**local.repo 内容：**

```ini
[base]
name=base8
baseurl=file:///mnt/BaseOS
enable=1
gpgcheck=0

[app]
name=app8
baseurl=file:///mnt/AppStream
enable=1
gpgcheck=0
```

##### 2.2.2.2 B. 局域网服务配置

```ini
[lan-repo]
name=LAN Repository
baseurl=ftp://192.168.1.9/pub/centos84
enable=1
gpgcheck=0
```

##### 2.2.2.3 C. 公网仓库配置（以阿里云为例）

```ini
[aliyun-base]
name=Aliyun Base
baseurl=https://mirrors.aliyun.com/centos/$releasever/BaseOS/$basearch/
enable=1
gpgcheck=1
gpgkey=https://mirrors.aliyun.com/centos/RPM-GPG-KEY-CentOS-Official
```

### 2.3 配置文件参数说明

- `[repository-id]`：仓库唯一标识
- `name`：仓库描述名称
- `baseurl`：仓库地址
- `enabled`：是否启用（1 启用，0 禁用）
- `gpgcheck`：是否检查 GPG 签名（1 检查，0 不检查）
- `gpgkey`：GPG 密钥地址

### 2.4 YUM 常用命令

```bash
# 安装软件包
yum install package-name

# 卸载软件包
yum remove package-name

# 更新软件包
yum update package-name

# 搜索软件包
yum search keyword

# 列出所有可用软件包
yum list available

# 列出已安装软件包
yum list installed

# 查看软件包信息
yum info package-name

# 清理缓存
yum clean all

# 重新建立缓存
yum makecache
```

## 3. 源代码编译安装

### 3.1 源代码安装准备

在编译安装前，务必阅读以下文件：

- **README**：软件介绍和使用说明
- **INSTALL**：详细的安装指南

### 3.2 编译安装三部曲

#### 3.2.1 第一步：配置（Configure）

```bash
./configure --prefix=/usr/local/software-name
```

**常用参数：**

- `--prefix`：指定安装目录
- `--help`：查看所有可用参数

#### 3.2.2 第二步：编译（Make）

```bash
make
```

#### 3.2.3 第三步：安装（Make Install）

```bash
make install
```

### 3.3 源代码安装示例：htop

```bash
# 进入源代码目录
cd /usr/local/src

# 下载htop源代码
wget http://sourceforge.net/projects/htop/files/htop/1.0.2/htop-1.0.2.tar.gz

# 解压源代码包
tar -zxvpf htop-1.0.2.tar.gz

# 进入解压后的目录
cd htop-1.0.2

# 配置编译选项
./configure --prefix=/usr/local/htop

# 编译源代码
make

# 安装软件
make install

# 添加到PATH环境变量（可选）
echo 'export PATH=/usr/local/htop/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### 3.4 源代码安装注意事项

1. **依赖检查**：确保系统已安装编译所需的开发工具和库
2. **权限管理**：安装到系统目录可能需要 root 权限
3. **环境变量**：安装到自定义目录后需要设置 PATH 环境变量
4. **文档阅读**：仔细阅读 README 和 INSTALL 文件

## 5. 管理工具对比

| 特性     | RPM      | YUM      | 源代码安装 |
| -------- | -------- | -------- | ---------- |
| 依赖处理 | 手动     | 自动     | 手动       |
| 安装速度 | 快       | 快       | 慢         |
| 灵活性   | 低       | 低       | 高         |
| 版本控制 | 好       | 好       | 灵活       |
| 适用场景 | 单包安装 | 日常管理 | 定制安装   |

## 6. 最佳实践建议

1. **优先使用 YUM**：日常软件管理首选 YUM，自动处理依赖
2. **谨慎使用 RPM**：RPM 安装时注意依赖关系，可能导致问题
3. **源代码安装适用场景**：
   - 需要特定版本功能
   - 进行软件定制化编译
   - 学习软件编译过程
4. **仓库管理**：合理配置仓库源，确保软件来源安全可靠

通过掌握这三种软件管理方式，可以根据不同需求灵活选择最适合的软件安装和管理方法。
