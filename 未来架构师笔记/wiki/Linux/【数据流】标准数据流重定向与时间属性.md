## 1. 标准数据流

Linux 程序运行时有三个"默认通道"，称为**标准数据流**：

| 数据流   | 名称   | 代码 | 默认去向 | 重定向符号          |
| -------- | ------ | ---- | -------- | ------------------- |
| 标准输入 | stdin  | 0    | 键盘     | `<`                 |
| 标准输出 | stdout | 1    | 屏幕     | `>` `>>` `1>` `1>>` |
| 标准错误 | stderr | 2    | 屏幕     | `2>` `2>>`          |

- `>` 就等同于 `1>`
- `>>` 追加（不覆盖），`>` 覆盖

## 2. 重定向示例

### 2.1 标准输出重定向

```bash
ls -l > /tmp/123     # 正常输出写入文件（覆盖）
ls -l >> /tmp/123    # 追加到文件末尾
```

### 2.2 标准错误重定向

```bash
ls /不存在的目录 2> /tmp/err.txt   # 错误信息写入文件
```

### 2.3 合并输出和错误

```bash
# 把标准输出和错误都写入同一个文件（最常见写法）
ls -l > /tmp/123 2>&1

# 输出和错误分别写两个文件
ls -l > /tmp/123 2> /tmp/list

# 错误信息丢弃（写进 /dev/null 黑洞，日常大量使用）
ls -l > /tmp/123 2>/dev/null
```

> `2>&1` 含义：把**错误输出（2）重定向到标准输出（1）当前所在的位置**。`2>/dev/null` 表示把错误信息直接丢弃。

### 2.4 标准输入重定向

```bash
# 把 install.log 的内容作为输入喂给 cat，再重定向到文件 2
cat > 2 < /root/install.log

# 交互输入：从键盘输入内容，Ctrl+D 结束，写入文件 123
cat > 123

# 用 EOF 标记结束输入（脚本里非常常用）
cat > 123 <<eof
第一行
第二行
eof
```

> `<<eof` 称为 here-doc：把下面直到 `eof` 为止的内容作为命令的输入，适合在脚本里批量生成配置文件。

### 2.5 脚本日志实践

```bash
# 运行脚本，把正常和错误输出都记录到日志（排错必备）
./shell.sh > shell.log 2>&1
```

## 3. 双向重定向 tee

`tee` 让数据**同时**流向文件和下一个命令：

```bash
# last 的输出：既保存到 last.list，又继续传给 cut 处理
last | tee last.list | cut -d " " -f1

# -a 追加到文件（不加 -a 是覆盖）
ls -l / | tee -a ~/files | more
```

## 4. 文件时间属性

文件有三个时间属性：

| 属性  | 名称     | 更新时机                     |
| ----- | -------- | ---------------------------- |
| atime | 访问时间 | 读取文件内容时更新           |
| mtime | 修改时间 | **文件内容**改变时更新       |
| ctime | 状态时间 | 文件**权限、属主**改变时更新 |

> 当文件内容改变时，三个时间都会变；但仅修改权限/属主时，只更新 ctime。

### 4.1 查看时间属性

```bash
stat 文件              # 查看完整状态（含三个时间）
ls -l                 # 默认显示 mtime
ls -l --time=atime    # 显示 atime
ls -l --time=ctime    # 显示 ctime
```

### 4.2 时间属性应用

```bash
# 手动修改文件的 mtime（常用技巧：让文件时间"回到过去"）
touch -t 1005170230 文件   # 格式：月日时分年（MMDDhhmmYY）

# 按修改时间查找：两天内修改过的文件
find ./ -mtime -2

# inotify 文件监控工具，依赖 mtime/ctime 变化来触发事件
```
