## 1. 虚拟机资源分配

虚拟机装 Linux，需要分配 CPU、内存、存储。

- 除了玩 K8s，其他基础学习**只用一个 CPU** 就够了
- 内存建议 2G，存储建议 20G（Linux 对硬件要求不高）

## 2. 分区概念

安装系统时通常做如下分区规划：

- `/` 根分区：系统文件都挂在这里
- `swap` 分区：物理内存（是内存，不是存储）不够用时，把临时不活跃的数据从物理内存"踢"出来，放到 swap 分区。大小一般是**物理内存的 2 倍**（看情况而定）
- `/boot` 引导分区：存放系统启动引导文件（可选，默认分区方案会自动创建）

> swap 只是"应急"空间，并不是越大越好。现代服务器内存充足时，swap 甚至可以小一些或关闭。

## 3. Linux 版本分类

### 3.1 常见发行版

RedHat、CentOS、RedFlag、Debian、Ubuntu、OpenSUSE、Fedora、Gentoo 等。

### 3.2 按包管理机制分类

> 发行版与包管理的深入内容见 [[【软件包】软件和包管理]]。

| 包管理机制 | 包格式 | 代表发行版             |
| ---------- | ------ | ---------------------- |
| yum / dnf  | rpm    | RedHat、CentOS、Fedora |
| apt-get    | deb    | Debian、Ubuntu         |
| Yast       | rpm    | OpenSUSE               |

### 3.3 主流版本关系

- **RHEL（Red Hat Enterprise Linux）**：红帽企业版，商业授权，稳定性要求高的服务器常用
- **CentOS**：基于 RHEL 源码编译的社区版，免费，是学习/生产的热门选择
- **Fedora**：RHEL 的"试验田"，新特性最先在这里测试
- **Ubuntu**：基于 Debian，桌面体验好，开发环境常用

## 4. Linux 安装方式

1. **U 盘引导**：最常用，把 ISO 镜像写入 U 盘启动安装
2. **网络安装**：通过 NFS/FTP/HTTP 提供镜像，配合 DNS+DHCP+TFTP 实现无人值守批量部署
3. **光盘安装**：用系统 ISO 镜像文件（如 CentOS 8.4 镜像约 8-9G）

**安装过程注意点：**

- 分区规划：基本是 `/`（根分区）、`swap`、`/boot`，可选自动分区或手动分区
- swap 一般取物理内存的 2~2.5 倍（学习环境可按实际调整）
- 软件选择：学习建议**最小化安装**，避免 GUI 占用资源；生产按需选择

## 5. 安装后初始化配置

> 系统开关机、systemctl 服务管理等见 [[【进程】系统状态和进程管理]]。

### 5.1 SELinux 管理

SELinux（安全增强 Linux）默认开启，常因权限过严导致服务访问异常，学习环境常关闭：

```bash
# 临时关闭（当前生效，重启失效）
setenforce 0

# 永久关闭：修改配置文件，重启后生效
# 编辑 /etc/sysconfig/selinux，确保：
SELINUX=permissive
```

`SELINUX` 的三个值：`enforcing`（强制）、`permissive`（只记录不拦截）、`disabled`（禁用）。

### 5.2 防火墙管理

> 防火墙区域、服务放行的完整讲解见 [[【服务】防火墙 firewalld 区域管理]]。

```bash
# 关闭防火墙服务
systemctl stop firewalld.service

# 禁止开机自启（永久关闭）
systemctl disable firewalld.service

# 查看状态
systemctl status firewalld.service
```

### 5.3 系统开关机命令

```bash
# 关机
poweroff
init 0
halt
shutdown -h now          # 立即关机
shutdown -h +20          # 20 分钟后关机

# 重启
reboot
init 6
shutdown -r now          # 立即重启
shutdown -r +20          # 20 分钟后重启
```

## 6. 网络配置

### 6.1 虚拟机网卡三种类型

1. **NAT 网卡**：宿主机能上网，虚拟机就能上网；但**局域网内其他电脑访问不到**虚拟机（宿主机把虚拟机"藏"起来了）
2. **桥接网卡**：桥接到宿主机上网的那张网卡（一般设自动）。宿主机能上网，虚拟机也能上网，**局域网内其他电脑也能访问**虚拟机
3. **仅主机网卡（hostonly）**：**不能连公网**，宿主机和所有虚拟机组成一个独立局域网

### 6.2 直接修改配置文件

```bash
# eth0 网卡的配置文件
/etc/sysconfig/network-scripts/ifcfg-eth0

# 图形界面用 gedit/kwrite 编辑，文本终端用 vim 编辑
# 修改完成后重启指定网卡
ifdown eth0 && ifup eth0
```

### 6.3 nmcli 命令行配置（推荐）

```bash
# 查看当前网络连接
nmcli c show

# 修改 IP（手动模式）
nmcli c mod ens160 ipv4.method manual ipv4.addr "192.168.1.2/24" gw4 192.168.1.1

# 重启网卡使配置生效
nmcli c down ens160 && nmcli c up ens160

# 如果连接不存在，新增一个：
nmcli c add type ethernet con-name ens160 ifname ens160 \
  ipv4.method manual ipv4.address "192.168.1.2/24" gw4 192.168.1.1
```
