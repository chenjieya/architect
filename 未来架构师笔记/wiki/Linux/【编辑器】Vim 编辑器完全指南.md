## 1. 文本编辑器概述

Linux 下编辑文件有很多工具，最常用的是这三种：

| 编辑器   | 特点                 | 适用场景                  |
| -------- | -------------------- | ------------------------- |
| `gedit`  | 图形界面，像记事本   | 桌面环境改配置文件        |
| `kwrite` | 图形界面（KDE 系）   | 桌面环境                  |
| `vim`    | 终端下运行，功能强大 | **服务端/命令行环境首选** |

在终端里编辑指定文件（图形界面下）：

```bash
gedit /a/b.txt   # 用图形编辑器打开
vim  /a/b.txt    # 用 vim 打开
```

> **提示**：在终端输入命令或文件名时，按 **Tab 键**可以自动补齐（补命令名、文件名、目录名），非常高效。

## 2. Linux 路径与目录结构

Linux 中一个文件的**路径**，指的就是该文件存放的位置。所有文件（目录）都被组织成以根目录 `/` 开始的**倒置的树状结构**：

![Linux目录路径树状图](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1785670031246_Linux目录路径树状图.png)

- 绝对路径：从根 `/` 开始写，如 `/etc/nginx/nginx.conf`
- 相对路径：从当前目录开始写，如 `./nginx.conf`、`../conf/`

## 3. vi 和 vim 的区别

- **vi**：最早的经典编辑器，功能单一
- **vim**：vi 的增强版，**有颜色显示，支持程序语法高亮**（写代码、看配置更舒服）

> 现在的 Linux 发行版，`vi` 通常就是指向 `vim` 的别名。

### 3.1 vim 配置文件

```bash
/etc/vimrc        # 全局配置（对所有用户生效）
~/.vimrc          # 当前用户配置（优先于全局）
```

常用配置示例（写入 `~/.vimrc`）：

```vim
set nu            " 显示行号
set ts=4          " Tab 占 4 个空格
syntax on         " 开启语法高亮
```

### 3.2 交换文件 .swp（崩溃恢复）

用 vim 编辑文件时，会生成一个隐藏的交换文件 `.filename.swp`：

- 编辑过程中的**修改临时存放在 .swp 文件里**
- 如果系统死机且**未保存**，下次打开该文件时 vim 会提示：
  - 按 `R`（Recover）**恢复到修改过程中的样子**（而不是回到源文件）
- 正常 `:wq` 退出后，.swp 文件会自动删除

## 4. vim 的四种模式

vim 难在"模式"，先记住四种模式及切换方式：

| 模式                     | 作用                 | 进入方式                    |
| ------------------------ | -------------------- | --------------------------- |
| **一般模式**（浏览模式） | 移动光标、删除、复制 | 刚打开 vim 时默认处于此模式 |
| **编辑模式**             | 输入文字             | `i` / `I` / `a` / `o` / `R` |
| **命令行模式**           | 保存、退出、查找替换 | `:` / `/` / `?`             |
| **可视化模式**           | 批量选择文本         | `v` / `V` / `Ctrl+v`        |

**模式切换：**

```text
打开vim ──► 一般模式 ──(i/a/o/R)──► 编辑模式
    ▲              │
    └──(Esc)───────┘
    │
    ├──(: / ?)──► 命令行模式 ──(Esc)──► 一般模式
    │
    └──(v/V/Ctrl+v)──► 可视化模式 ──(Esc)──► 一般模式
```

进入编辑模式的按键区别：

- `i`：在**光标前**插入
- `I`：在**行首**插入
- `a`：在**光标后**插入
- `o`：在**下一行**新建一行
- `R`：**覆盖**模式（替换后面的字符）

## 5. 光标移动（一般模式下）

```text
0     跳到光标所在行的行首
$     跳到光标所在行的行尾
G     跳到文件最后一行
nG    跳到文件第 n 行（如 5G 跳到第 5 行）
gg    跳到文件第一行
n回车  光标向下移动 n 行
```

## 6. 查找与替换

```bash
/word    # 向下查找 word 字符串
?word    # 向上查找 word 字符串
n        # 重复上一次搜索（继续向下）
N        # 反向重复上一次搜索（向上）
```

**替换**（命令行模式）：

```bash
:n1,n2s/word/new/g     # 将第 n1 到 n2 行之间的 word 替换成 new
:1,$s/word/new/g       # 全文替换
:1,$s/word/new/gc      # 全文替换，但每次询问确认（c=confirm）
```

> `g` 表示一行中所有匹配都替换；不加 `g` 只替换每行第一个匹配。

## 7. 删除（一般模式）

```bash
x        # 向后删除一个字符
X        # 向前删除一个字符
dd       # 删除光标所在整行
ndd      # 从光标开始删除 n 行（如 2dd 删除 2 行）
d1G      # 从第一行删除到光标所在行（含光标行）
dG       # 从光标行删除到文件末尾
d5G      # 删除到第 5 行（不含光标行？等价"删到第5行"）
d$       # 删除光标位置到行尾
```

## 8. 复制与粘贴（一般模式）

```bash
yy       # 复制光标所在整行
y5y      # 复制 5 行（也写作 5yy）
y5G      # 复制光标行到第 5 行
yG       # 复制光标行到文件末尾
y$       # 复制光标位置到行尾
P        # 粘贴到光标行的上一行
p        # 粘贴到光标行的下一行
```

## 9. 保存与退出（命令行模式）

```bash
:w        # 保存
:q        # 退出（未保存会提示）
:wq       # 保存并退出
:wq!      # 强制保存并退出（涉及只读权限时用）
:q!       # 不保存强制退出
:w[文件名] # 另存为指定文件名
:r[文件名] # 把另一个文件的内容读入光标行之后
```

## 10. 撤销与重复

```bash
u        # 撤销上一步操作
Ctrl+r   # 重做（取消撤销）
.        # 重复上一步操作
```

## 11. 实用技巧

```bash
:set nu        # 显示行号
:set nonu      # 取消行号
:set paste     # 粘贴模式（避免粘贴时自动缩进错乱）
:n             # 跳到第 n 行
```

## 12. 练习巩固

1. 用 vim 新建 `/tmp/test.txt`，输入三行内容，练习 `i` 进入编辑、`Esc` 返回
2. 练习光标移动：`gg` 回开头、`G` 到结尾、`5G` 到第 5 行
3. 用 `yy`、`p` 复制粘贴行，用 `dd` 删除行
4. 把文件中的单词 `hello` 全文替换为 `world`
5. 用 `:wq` 保存退出，重新打开确认修改已生效
