前向传播是 Agent 底层逻辑里"算结果"的那一步：把数据从输入层一路算到输出层。上一节我们认识了单个 [[【基础】神经元]]，这一节看它们"串成网络"后，数据是怎么一层层流动、算出最终结果的。它是训练（反向传播）和预测（推理）的共同基础，涉及到的纯数学概念（求和符号、向量）见 [[导数与梯度]]。

## 1. 一句话理解

**前向传播 = 数据从输入层出发，一层层"加权求和 + 激活"，最后流到输出层，得到预测结果。**

就像工厂流水线：原料（输入）进第一道工序，加工后交给第二道工序，最后产出成品（输出）。

## 2. 回顾：单个神经元的前向计算

先看一个神经元怎么做（详见 [[【基础】神经元]]）：

$$y = \sigma\!\left(\sum_{i=1}^n w_i x_i + b\right) = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$$

- 输入 $[x_1,\dots,x_n]$：一个**向量**（多维信息）。
- 输出 $y$：一个**标量**（单个数字）。
- 权重 $[w_1,\dots,w_n]$：每个输入有多重要。
- 偏置 $b$：基础偏移。
- $\sigma$：激活函数（如 ReLU）。

**记住这个"向量进、标量出"的视角**——这是理解前向传播的钥匙。

## 3. 一层的前向计算：矩阵形式

一层里有多个神经元，每个都做上面那套"加权求和 + 激活"。把它们**打包**，就得到矩阵形式：

$$\mathbf{a}^{(l)} = \sigma\!\left(\mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}\right)$$

逐符号拆解（上标 $(l)$ 表示"第 $l$ 层"）：

| 符号                 | 含义                                            | 形状        |
| -------------------- | ----------------------------------------------- | ----------- |
| $\mathbf{a}^{(l-1)}$ | 第 $l-1$ 层的输出，也是第 $l$ 层的**输入**      | $m\times1$  |
| $\mathbf{W}^{(l)}$   | 第 $l$ 层的**权重矩阵**（每个神经元一行的权重） | $n\times m$ |
| $\mathbf{b}^{(l)}$   | 第 $l$ 层的**偏置向量**（每个神经元一个偏置）   | $n\times1$  |
| $\sigma(\cdot)$      | 激活函数，对向量**逐元素**作用                  | —           |
| $\mathbf{a}^{(l)}$   | 第 $l$ 层的**输出向量**                         | $n\times1$  |

### 3.1 矩阵乘法到底在算什么

别被"矩阵"吓到，它就是把一堆"加权求和"打包成一次乘法。假设第 $l-1$ 层有 3 个神经元、第 $l$ 层有 2 个神经元：

$$
\begin{bmatrix} a_1^{(l)} \\ a_2^{(l)} \end{bmatrix}
= \sigma\!\left(
\begin{bmatrix} w_{11} & w_{12} & w_{13} \\ w_{21} & w_{22} & w_{23} \end{bmatrix}
\begin{bmatrix} a_1^{(l-1)} \\ a_2^{(l-1)} \\ a_3^{(l-1)} \end{bmatrix}
+ \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}
\right)
$$

把矩阵乘法展开，其实就是两个神经元**各自**在做加权求和：

$$a_1^{(l)} = \sigma(w_{11}a_1^{(l-1)} + w_{12}a_2^{(l-1)} + w_{13}a_3^{(l-1)} + b_1)$$
$$a_2^{(l)} = \sigma(w_{21}a_1^{(l-1)} + w_{22}a_2^{(l-1)} + w_{23}a_3^{(l-1)} + b_2)$$

- 权重矩阵第 1 行 $[w_{11},w_{12},w_{13}]$ 就是第 1 个神经元的三个权重。
- 第 2 行 $[w_{21},w_{22},w_{23}]$ 就是第 2 个神经元的三个权重。
- 矩阵乘向量，本质是"每一行和输入向量做点乘"，得到每个神经元的加权和。

> 大白话：**矩阵形式 = 把一层里所有神经元的"加权求和"写成一个式子**，实际干的还是每个神经元那一套，只是写法更紧凑、更适合计算机批量计算。

## 4. 为什么用矩阵：向量化加速

手动写每个神经元的公式，层多了、神经元多了会写到手软；而且计算机里，矩阵乘法有高度优化的库（GPU 特别擅长），一次矩阵乘法能瞬间算完成千上万个神经元。所以实际代码里，前向传播就是几行矩阵运算。

## 5. 总参数量：一个网络到底有多少参数

"大模型动辄几十亿参数"，这个数字怎么来的？公式：

$$\text{总参数量} = \sum_{l=1}^{L}\left(n_l \times n_{l-1} + n_l\right)$$

- $n_l$：第 $l$ 层的神经元数；$n_{l-1}$：前一层的神经元数。
- $n_l \times n_{l-1}$：两层之间的**连接数**（每个"前层神经元 → 后层神经元"的连线都要一个权重）。
- $+\,n_l$：第 $l$ 层的**偏置数**（每个神经元一个偏置）。
- $\sum_{l=1}^{L}$：把所有层加起来。

**例子**：一个网络 输入 3 → 隐藏 4 → 输出 2（两层有权重，即 $l=1$ 隐藏层、$l=2$ 输出层）：

- 隐藏层：$n_1\times n_0 + n_1 = 4\times3 + 4 = 16$ 个参数。
- 输出层：$n_2\times n_1 + n_2 = 2\times4 + 2 = 10$ 个参数。
- **总参数 = 16 + 10 = 26**。

## 6. 一个完整的小例子

用上面这个 3→4→2 网络，输入 $\mathbf{a}^{(0)}=[1,2,3]$，走一遍前向传播（假设 $\sigma=\text{ReLU}$，即负数取 0）：

1. **第一层**（隐藏层，4 个神经元）：$\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{a}^{(0)} + \mathbf{b}^{(1)}$，再 $\mathbf{a}^{(1)} = \text{ReLU}(\mathbf{z}^{(1)})$。
2. **第二层**（输出层，2 个神经元）：$\mathbf{z}^{(2)} = \mathbf{W}^{(2)}\mathbf{a}^{(1)} + \mathbf{b}^{(2)}$，再 $\mathbf{a}^{(2)} = \sigma(\mathbf{z}^{(2)})$。

最后的 $\mathbf{a}^{(2)}$ 就是网络的输出（比如"猫/狗"两个类别的分数）。整个过程没有任何"魔法"，就是**加权求和 + 激活，重复两层**。

## 7. 前向传播和反向传播的关系

- **前向传播**：算结果（预测值），方向从输入到输出。
- **反向传播**：算误差（梯度），方向从输出倒着传回输入，具体怎么"逐层传"见 [[【基础】反向传播]]。

训练时两者交替：先前向算出预测，再用预测和真实答案的误差反向传播、更新权重（[[梯度下降]]）。所以**前向传播是反向传播的地基**——没有前向算出结果，就无从谈起误差。

## 8. 总结

- 前向传播 = **数据逐层"加权求和 + 激活"**，从输入流到输出。
- 单神经元是"向量进、标量出"；一层打包成矩阵形式 $\mathbf{a}^{(l)}=\sigma(\mathbf{W}^{(l)}\mathbf{a}^{(l-1)}+\mathbf{b}^{(l)})$。
- 矩阵形式只是"把所有神经元的加权求和写成一次乘法"，本质不变。
- 总参数量 $=\sum_l(n_l\times n_{l-1}+n_l)$：连接权重数 + 偏置数。
