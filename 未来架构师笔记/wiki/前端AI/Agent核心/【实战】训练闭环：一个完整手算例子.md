前几讲把每个环节单独讲清了：[[【基础】前向传播]] 算结果、[[【基础】反向传播]] 算梯度、[[【基础】梯度下降]] 改参数。但**光知道每个零件，还没看过它们怎么合起来转一整圈**。这篇就用一个具体的神经网络，**手把手算一遍完整训练**，把五个步骤串成你能亲手复现的例子。

## 1. 准备：一个最小神经网络

为了让手算友好，我们选一个很小的网络，激活函数用**线性函数** $\sigma(z)=z$（就是"原样输出"，斜率恒为 1，手算最省事；真实网络用 Sigmoid/ReLU，道理一样，只是 $\sigma'$ 换成对应斜率）。

**网络结构**：2 个输入 → 1 个隐藏神经元 → 1 个输出神经元。

```
输入 x₁=1, x₂=2  →  隐藏神经元 h  →  输出 o
                  ↑                ↑
              w₁=2, w₂=1, b₁=0   w₃=3, b₂=0
```

**已知条件**：

- 输入：$x_1=1,\ x_2=2$
- 真实答案：$y=1$（我们希望网络最终输出 1）
- 隐藏层权重：$w_1=2,\ w_2=1$，偏置 $b_1=0$
- 输出层权重：$w_3=3$，偏置 $b_2=0$

## 2. 第一步：前向传播（算一个结果）

按 [[【基础】前向传播]]，逐层"加权求和 + 激活"：

**隐藏层**：把两个输入加权求和：

$$z_1 = w_1x_1 + w_2x_2 + b_1 = 2\times1 + 1\times2 + 0 = 4$$

激活（线性，原样输出）：

$$a_1 = \sigma(z_1) = z_1 = 4$$

**输出层**：把隐藏层输出继续加权求和：

$$z_2 = w_3a_1 + b_2 = 3\times4 + 0 = 12$$

$$a_2 = \sigma(z_2) = z_2 = 12$$

> 网络预测出了 **12**，但真实答案是 **1**——差得离谱。

## 3. 第二步：算损失（看错多少）

用平方误差（[[【基础】梯度下降]] 里的 MSE 单样本版）：

$$L = (a_2 - y)^2 = (12 - 1)^2 = 121$$

损失 **121**，很大，说明网络错得很厉害，需要狠狠改。

## 4. 第三步：反向传播（算出每个权重该改多少）

这是 [[【基础】反向传播]] 的主角。核心是**从输出层往回，一层层算每个神经元的"责任" δ，再算出每个权重的梯度**。

### 4.1 输出层的责任 δ₂

$$\delta_2 = \frac{\partial L}{\partial z_2} = 2(a_2 - y)\cdot\sigma'(z_2) = 2\times(12-1)\times1 = 22$$

（$\sigma'=1$ 是因为线性激活斜率恒为 1。）

### 4.2 隐藏层的责任 δ₁

责任沿连接线往回传，乘权重、再乘本层激活斜率：

$$\delta_1 = \delta_2 \cdot w_3 \cdot \sigma'(z_1) = 22 \times 3 \times 1 = 66$$

### 4.3 每个权重的梯度 = 责任 × 输入

| 权重  | 梯度公式             | 计算        | 结果    |
| ----- | -------------------- | ----------- | ------- |
| $w_3$ | $\delta_2 \cdot a_1$ | $22\times4$ | **88**  |
| $w_1$ | $\delta_1 \cdot x_1$ | $66\times1$ | **66**  |
| $w_2$ | $\delta_1 \cdot x_2$ | $66\times2$ | **132** |
| $b_1$ | $\delta_1$           | $66$        | **66**  |
| $b_2$ | $\delta_2$           | $22$        | **22**  |

> 观察：$w_2$ 的梯度（132）比 $w_1$（66）大，因为 $w_2$ 接的输入 $x_2=2$ 更大——"输入越大，这个权重越该多改"，正是 [[【基础】反向传播]] 里讲的规则。

## 5. 第四步：梯度下降更新（真的改）

按 [[【基础】梯度下降]] 的更新公式 $w \leftarrow w - \alpha \cdot \text{梯度}$，取学习率 $\alpha=0.01$：

| 参数  | 更新计算            | 新值  |
| ----- | ------------------- | ----- |
| $w_3$ | $3 - 0.01\times88$  | 2.12  |
| $w_1$ | $2 - 0.01\times66$  | 1.34  |
| $w_2$ | $1 - 0.01\times132$ | −0.32 |
| $b_1$ | $0 - 0.01\times66$  | −0.66 |
| $b_2$ | $0 - 0.01\times22$  | −0.22 |

## 6. 第五步：循环，看损失下降

用更新后的参数再跑一遍前向传播：

$$z_1 = 1.34\times1 + (-0.32)\times2 + (-0.66) = -0.04$$
$$a_1 = -0.04$$
$$a_2 = 2.12\times(-0.04) + (-0.22) = -0.3048$$

新损失：

$$L = (-0.3048 - 1)^2 \approx 1.70$$

**损失从 121 骤降到 1.70**，下降了几十倍。这就是"训练"的威力——只要方向对（负梯度）、步子合适，每轮损失都会往下掉。

> 大白话：完整训练就是反复跑这五步——**算一遍 → 看错多少 → 责任往回传 → 按责任改权重 → 再算**。跑几千几万轮，损失会一直降到接近 0，权重就被"磨"到最佳位置。

## 7. 一句话串起全流程

| 步骤        | 在干什么              | 关键公式                                                | 对应文章             |
| ----------- | --------------------- | ------------------------------------------------------- | -------------------- |
| 1. 前向传播 | 从输入算到输出        | $a=\sigma(Wa+b)$                                        | [[【基础】前向传播]] |
| 2. 算损失   | 量出错多少            | $L=(a_2-y)^2$                                           | [[【基础】梯度下降]] |
| 3. 反向传播 | 责任往回传、算梯度    | $\frac{\partial L}{\partial w}=\delta\times\text{输入}$ | [[【基础】反向传播]] |
| 4. 梯度下降 | 按梯度更新权重        | $w\leftarrow w-\alpha\frac{\partial L}{\partial w}$     | [[【基础】梯度下降]] |
| 5. 循环     | 反复 1~4 直到损失最小 | —                                                       | —                    |

## 8. 补充说明

- **为什么用线性激活**：手算最省事。真实网络用 Sigmoid/ReLU，区别只在 $\sigma'$ 换成对应斜率（Sigmoid 是 $\sigma(1-\sigma)$，ReLU 是 0 或 1），流程完全一样。
- **为什么是标量**：为了让每个数字都能看懂。真实网络权重是矩阵，标量的"责任×输入"会升级成矩阵的"δ 外积输入"，见 [[矩阵求导与梯度矩阵]]。
