上一讲 [[【基础】前向传播]] 讲的是"数据怎么在神经网络里算出一个结果"，但只算了结果还不够——算出来的是对是错、错了怎么改，才是让模型"变聪明"的关键。这一讲就回答这个问题：**模型是怎么一步步学会的**，答案就是"梯度下降"。

## 1. 一句话理解

**梯度下降 = 让模型"试一次、看错多少、朝最陡的下坡方向改一点"，反复做，直到错得最少。**

先记住三个词，这是理解"训练"的全部钥匙：

- **损失函数**：衡量"模型错得有多离谱"的尺子。
- **梯度下降**：这把尺子的读数下降最快的方向（也就是"怎么改"）。
- **学习率**：每次改动的"步子大小"。

## 2. 损失函数：先给"错"打分

模型算出一个结果后，总得知道它和正确答案差多少。用来量这个"差"的公式，就是**损失函数**。机器学习里最常用的一种叫**均方误差（MSE）**：

$$L = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{y}_i\bigr)^2$$

逐符号拆解：

| 符号                          | 含义                                                                  |
| ----------------------------- | --------------------------------------------------------------------- |
| $y_i$                         | 第 $i$ 个数据的**真实值**（正确答案）                                 |
| $\hat{y}_i$                   | 模型算出的**预测值**                                                  |
| $y_i - \hat{y}_i$             | 这一个数据"差了多少"，可正可负                                        |
| $\bigl(y_i-\hat{y}_i\bigr)^2$ | 平方：把负号消掉（差 3 和差 −3 平方后都是 9），同时"差得远"的惩罚更重 |
| $\sum_{i=1}^{n}$              | 把 $n$ 个数据的差距平方全部加起来                                     |
| $\frac{1}{n}$                 | 除以个数，取平均                                                      |

**大白话**：损失 $L$ 就是"平均每个数据点错多少"。预测完全正确时 $L=0$；错得越离谱，$L$ 越大。

> 为什么要平方、而不是直接相加？因为差距有正有负，直接加会互相抵消（+3 和 −3 相加得 0，看起来像"没错"）。平方让所有误差都朝"正"里贡献。这套"偏差 → 平方 → 平均"的思路，和 [[标准差公式详解]] 一模一样，也和 [[线性回归]] 的 MSE 是同一个公式。

## 3. 梯度下降：往"最陡的下坡"改

有了损失 $L$，下一步问题变成：**参数该往哪个方向调，$L$ 才降得最快？**

想象你被扔在一座山的山坡上，四周漆黑、看不到谷底。最聪明的走法是：**用脚试探哪边最陡，朝最陡的下坡方向走一小步**，再试探、再走，直到脚下变平（到谷底）。

梯度下降就是把这个"试探—迈步"交给数学自动做：

- "哪边最陡" → 靠**梯度**（[[导数与梯度]] 里讲过，梯度指向函数值上升最快的方向，反过来就是下降最快）。
- "走一小步" → 朝负梯度方向挪一点，损失就会降一点。

一句话：**沿负梯度方向走，损失下降最快。**

## 4. 学习率：步子该迈多大

每次改动的大小，由**学习率**（记作 $\alpha$）决定：

- **$\alpha$ 太小**：每次只挪一点点，收敛慢，训练要等很久。
- **$\alpha$ 太大**：一步迈太远，可能从谷底这头冲到另一头山坡上，来回震荡，甚至越走越高。
- **$\alpha$ 合适**：既快又稳地逼近谷底。

这就是"学习率"这个词的意思——**每一次根据梯度调整参数的幅度**。

## 5. 学习 / 训练：把上面几步串起来

理解了损失函数、梯度下降、学习率，就能给"学习/训练"下一个准确的定义：

> **学习（训练）是一个过程：反复用梯度下降的手段，让神经网络的参数一步步调整到让损失最小的"最佳状态"。**

流程就是：

1. 前向传播算一次结果（[[【基础】前向传播]]）。
2. 用损失函数量出"错多少"。
3. 反向传播把损失一层层传回，算出每个权重的梯度（[[【基础】反向传播]]）。
4. 朝负梯度方向、按学习率的大小，把参数调一点。
5. 回到第 1 步，反复循环，直到损失几乎不再下降。

**大白话**：训练就是"算一遍 → 看错多少 → 改一点 → 再算"，几千几万次循环后，参数就被"磨"到了接近最佳的位置。

> 想把这五步用**一个具体神经网络 + 具体数字**亲手算一遍，见 [[【实战】训练闭环：一个完整手算例子]]。

> 上面的流程还没回答一个问题：每次该拿**几个样本**去算梯度？这就是"训练模式"（SGD / 全批量 / 小批量），见 [[【基础】训练模式与框架]]。

## 6. 想看数学细节，去这里

这一讲只把"梯度下降"这个概念串起来。想看它的完整推导——更新公式 $\theta_{\text{new}} = \theta_{\text{old}} - \alpha\nabla L$ 逐符号拆解、以及"为什么沿负梯度走函数值一定下降"的证明，见 [[梯度下降]]。想先搞懂"梯度"本身是什么，见 [[导数与梯度]]。想了解真实训练里权重是矩阵时、梯度怎么升级成矩阵形式（$\frac{\partial L}{\partial W}=\delta\cdot a^\top$），见 [[矩阵求导与梯度矩阵]]。

## 7. 总结

- **损失函数**：量"模型错多少"的尺子，MSE 是最常用的一种。
- **梯度下降**：朝最陡的下坡（负梯度）方向调整参数。
- **学习率**：每次调整的幅度（步长）。
- **学习/训练**：反复"算 → 量错 → 改一点"，用梯度下降把参数调到损失最小。
