神经网络是目前机器学习里最常见、最重要的实现智能的手段，而理解神经网络，一切都要从一个最小的零件——**神经元**——开始。这也是 Agent 底层逻辑的第一块积木。

## 1. 一句话理解

**神经元是神经网络的"最小计算单元"：它接受一个向量（多个输入），输出一个标量（一个数字）。**

![](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786884749393_202607081415781.png)

> 一句话记牢：**向量进、标量出**。

## 2. 神经元的来历

1943 年，神经科学家 Warren McCulloch 和逻辑学家 Walter Pitts 给生物神经元建立了第一个数学模型。经过几十年发展，最终每个神经元的数学模型定型成了下面这个样子：

$$y = \sigma\!\left(\sum_{i=1}^n w_i x_i + b\right) = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$$

这个公式看着吓人，其实是"加权求和 + 激活"两步。下面把每个符号拆开。

## 3. 公式里每个符号是什么意思

| 符号              | 名字           | 大白话                                         |
| ----------------- | -------------- | ---------------------------------------------- |
| $[x_1,\dots,x_n]$ | 输入值（向量） | 喂给神经元的多个信息，每个分量是某一维度的信息 |
| $[w_1,\dots,w_n]$ | 权重（向量）   | 每个输入有多"重要"，权重越大越受重视           |
| $b$               | 偏置           | 改变神经元"被激活的阈值"（门槛）               |
| $\sigma$          | 激活函数       | 决定是否输出有效值                             |
| $y$               | 输出值/激活值  | 神经元算出来的结果，一个标量                   |

**两个要点**：

- **输入是向量，输出是标量**：一堆信息进去，一个数字出来。
- **参数 = 权重 + 偏置**：它们统称"参数"，是整个神经网络唯一"可学习"的东西。训练的本质，就是不断调整这些参数，让神经元的输出变得正确。

## 4. 激活函数：决定"要不要输出"

激活函数 $\sigma$ 决定了神经元"是否输出有效值"。最经典的是 **ReLU**：

$$\text{ReLU}(z) = \max(0, z)$$

- 如果加权求和的结果 $z$ 是正数，就原样输出；如果是负数，就输出 0。
- 大白话：**ReLU 像一个"水龙头"——信号是正的就放行，是负的（没意义）就关掉**。

激活函数是**固定**的（不是学习出来的），真正被训练改变的是权重和偏置。

## 5. 总结

单个神经元的核心理解：

- **接受一个向量，输出一个标量**。
- **激活函数是固定的**（如 ReLU）。
- **参数（权重和偏置）唯一决定了这个神经元的输出是否正确**。
