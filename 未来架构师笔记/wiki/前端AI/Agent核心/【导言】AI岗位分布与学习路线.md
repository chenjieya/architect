这篇文章是整个 Agent 开发系列的开篇。我们会先弄明白：**学了这些内容能去做什么岗位、值多少钱**，再看清楚**整个系列怎么一步步把你带到那个岗位**。看完之后，你会对"从哪里来、到哪里去"有一个清晰的地图。

## 1. AI 岗位分布：这条路通向你想要的工作

AI 行业目前主要有三大类岗位。你可以把它们想象成一座大厦的三层：**最底下是做应用（人多活好上手），中间是搞部署（把模型跑得又快又省），顶上是研究模型（门槛最高）**。

| 岗位类型 | 岗位名称                                                      | 岗位需求 | 学习难度 | 薪资水平 | 核心知识                                                                                                         |
| -------- | ------------------------------------------------------------- | -------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| 应用开发 | AI 应用开发工程师、Agent 应用开发工程师、大模型应用开发工程师 | ★★★★★    | ★★★☆☆    | ★★★☆☆    | 编程思维、AI 认知、应用框架、业务经验                                                                            |
| 推理部署 | 大模型部署工程师、LLM 推理优化工程师                          | ★★☆☆☆    | ★★★★★    | ★★★★★    | CUDA 内核、GPU 架构、算子融合、分布式推理、推理引擎、模型量化、显存优化                                          |
| 模型研发 | 大模型算法工程师、LLM 微调工程师、大模型训练工程师            | ★★☆☆☆    | ★★★★★    | ★★★★★    | 深度学习理论、算法创新、模型架构、分布式训练、数据处理、强化学习、论文复现、高等数学、线性代数、概率论、优化理论 |

### 1.1 应用开发：需求量最大，最适合作为入行方向

- **岗位名称**：AI 应用开发工程师、Agent 应用开发工程师、大模型应用开发工程师。
- **需求 ★★★★★**：AI 要真正落地到业务，靠的就是大量会写对应用的人。岗位最多，公司最缺。
- **难度 ★★★☆☆**：不要求你自己训模型，重点是会**调用现成的大模型 API、编排复杂的业务逻辑**——这正是本系列接下来要掌握的核心内容。
- **薪资 ★★★☆☆**：天花板一般，但胜在门槛友好、机会多，是大多数开发者的主战场。
- **核心知识**：编程思维（会写代码）、AI 认知（了解模型能干什么不能干什么）、应用框架（用 LangChain 这类工具快速搭建）、业务经验（把 AI 能力塞进真实业务流程）。

### 1.2 推理部署：让模型跑得又快又便宜

- **岗位名称**：大模型部署工程师、LLM 推理优化工程师。
- **需求 ★★☆☆☆、难度 ★★★★★、薪资 ★★★★★**：岗位少，但要求能力极硬——要懂 **CUDA 内核、GPU 架构、算子融合**（把多个计算步骤合并减少浪费）、**分布式推理**（多张卡分摊）、**模型量化**（把模型"压缩"以加速）、**显存优化**（省显存）。研究这两方面的工程师非常稀缺，所以薪资是最高的。
- **一句话理解**：模型研发把模型"造"出来，部署工程师负责让它在生产环境里"跑得动、跑得快、跑得起"。

### 1.3 模型研发：造模型的人

- **岗位名称**：大模型算法工程师、LLM 微调工程师、大模型训练工程师。
- **需求 ★★☆☆☆、难度 ★★★★★、薪资 ★★★★★**：需要扎实的**深度学习理论、模型架构、分布式训练、数据处理、强化学习**，能读论文、能复现论文。底层数学（高等数学、线性代数、概率论、优化理论）是硬门槛。
- **一句话理解**：应用开发是"用模型"，模型研发是"造/改模型"。

> 三条路怎么选？**本系列走的是第一类——应用开发（Agent 方向）**，因为它的需求最大、入行难度相对友好，且同样能拿到不错的薪资。部署与研发作为背景知识了解即可。

## 2. 学习路线：六段式，带你从零到企业级 Agent 开发者

下面是完整的学习路线图：

![学习路线图](https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1786862191822_202607141602641.png)

整个系列分为六大部分，环环相扣——**先懂原理，再造应用，再上企业，再用工具提效，最后找工作**。

### 2.1 第一阶段：Agents 底层逻辑（地基）

这一阶段回答"Agent 到底是怎么工作的"。你会从最底层开始，把大模型和 Agent 的每一个零件都拆开看明白：

- **AI 的本质**：从神经元、前向传播、梯度下降，到训练模式与框架（对应第 1～6 讲；其中神经元与前向传播见 [[神经网络]]，梯度下降见 [[线性回归]]）。
- **语言模型是怎么理解文字的**：词元（Token）、词嵌入、注意力机制、Transformer 的完整训练流程（第 7～12 讲）。
- **模型怎么"思考"**：推理机制、训练阶段（第 13～14 讲）。
- **模型怎么部署与对话**：用 Ollama 跑本地模型、系统提示词、会话管理（第 15～17 讲）。
- **Agent 核心机制**：tools（工具）、封装 tools、ReAct 思维循环、Agent 本体、Agent 接搜索引擎（第 18～22 讲）。
- **Agent 的"外挂"**：Skill（技能）、MCP 协议、MCP Client、Agent 接入 MCP、自己实现 MCP 服务器、Skill VS MCP（第 23～28 讲）。
- **进阶玩法**：子代理、Prompt / Context / Harness / Loop / Graph 五大工程（第 29～34 讲）。

这一阶段学完，你对 "大模型 → Agent" 的整条链路会有全局认识，而不是只会调接口。

### 2.2 第二阶段：Agents 应用框架（工欲善其事）

把第一阶段学会的底层能力，用成熟的 Agent 框架落地成可维护的应用。这一部分解决"从会到熟"的问题：不用每次都从零手写循环、工具调度、记忆管理，框架已经帮你封装好。

### 2.3 第三阶段：Agents 企业应用（真实战场）

把 Agent 放进真实的业务场景：企业知识库问答、客服自动化、复杂流程编排等。这部分强调**业务经验**——知道在什么场景用什么方案、如何评估效果、如何上线运维。

### 2.4 第四阶段：其他知识（补齐短板）

Agent 工程落地还需要周边配套知识，比如工程链路、平台能力、周边技术栈等，把这些补上才能在真实项目里独当一面。

### 2.5 第五阶段：AI 效能工具（武装自己）

学会用 AI 工具提升自己的开发效率（AI 编程、AI 工作流），做一个"会使用 AI 的开发工程师"，这也是当下职场里最实际的竞争力。

### 2.6 第六阶段：就业（临门一脚）

简历怎么写、怎么准备面试、怎么选择岗位方向，把前面学会的东西兑现成一份工作。

> 简单总结这条路线：**先搞懂 Agent 背后的原理 → 再用框架把它做成产品 → 然后放进企业场景里创造价值 → 同时用 AI 工具给自己提效 → 最后拿下工作**。

在进入第一部分「Agents 底层逻辑」之前，我们先打好地基——弄清 AI 到底是什么、有哪些分类，详见 [[【基础】AI的分类：三大流派与机器学习入门]]。
