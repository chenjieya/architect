DeepSeek Harness 里有两个特别重要的词：轮次和步骤。

小白可以先这样理解：

- **轮次**：从用户发起一次工作，到这次工作彻底结束。
- **步骤**：轮次里的一次模型请求，加上这次模型请求触发的工具执行。

一次轮次里可能只有一个步骤，也可能有多个步骤。

## 1. 为什么一个轮次里会有多个步骤

因为 Agent 不只是回答一句话。它可能需要先问模型，模型说“我要调用工具”；工具执行后，模型还要再看工具结果，然后继续回答。

例如：

```text
用户：帮我看看项目里有哪些测试
步骤 1：
  模型判断需要查文件
  模型调用文件搜索工具
  工具返回测试文件列表
步骤 2：
  模型读取工具结果
  整理答案
轮次结束
```

从用户角度看，这是一次请求；从系统角度看，中间发生了两次模型请求，所以是一个轮次、两个步骤。

## 2. 官方流程翻译成人话

DeepSeek Harness 的主流程可以简化成：

```text
turn/start
  领取用户输入
  运行 agent/pre-step
  step/start
    写入 user/message
    组装系统提示词和工具 schema
    发起 agent/request
    通过 llm/stream 接收模型流式输出
    写入 assistant/chunk 和 assistant/message
    如果模型要求工具调用：
      写入 tool/call
      执行工具流水线
      写入 tool/result
  step/end
  如果还欠一次模型请求，就进入下一个 step
turn/end
```

这里每个名字都不是随便取的。`turn/*`、`step/*`、`user/message`、`assistant/*`、`tool/*` 会进入持久会话日志。`agent/*`、`llm/*`、`tools/*` 更多是实时控制点。

## 3. agent/pre-step 在干什么

`agent/pre-step` 是模型请求前的重要入口。

它能决定：

- 用户输入是否允许进入模型。
- 输入内容是否需要改写。
- 是否注入额外上下文。
- 是否直接拒绝本步骤。

比如一个安全插件可以在这里检查“这段输入是否应该发给模型”；一个上下文插件可以在这里补充项目说明。

这也是 [[插件化架构与 Cordis]] 中 waterfall 事件的典型用法：监听器可以委托给下游，也可以短路。

## 4. 为什么要区分实时事件和持久事件

有些信息必须永久保存，比如用户消息、模型消息、工具调用和工具结果。因为恢复会话、回放界面、重新推导模型历史都要依赖它们。

有些信息只在运行时有用，比如当前 Agent 正在运行还是空闲、某条 inbox 消息被领取了没有。这些属于实时协调信息，不一定写成模型历史。

这就是 DeepSeek Harness 的分层：

| 类型            | 例子                                               | 用途                     |
| --------------- | -------------------------------------------------- | ------------------------ |
| 持久会话事件    | `user/message`、`assistant/message`、`tool/result` | 回放、恢复、派生模型历史 |
| 实时 Agent 事件 | `agent/status`、`agent/pre-step`、`agent/request`  | 控制运行中的 Agent       |
| 能力事件        | `tools/pre-execute`、`fs/*`                        | 给某类能力加策略和扩展   |

## 5. 模型调用和工具调用如何接在一起

模型输出可能包含工具调用块。Agent 循环会把这些工具调用交给 [[工具调用与执行流水线]]。

工具执行完后，结果不是直接丢给模型，而是先作为 `tool/result` 写入会话日志。下一次模型请求再从日志派生历史，把工具结果作为上下文交给模型。

这样做有两个好处：

1. 工具结果不会在内存里丢失。
2. 以后重放会话时，能还原当时模型看到了什么。

## 6. 记住这张简图

```text
轮次 turn
├── 步骤 step
│   ├── 用户消息
│   ├── 模型请求
│   ├── 模型响应
│   └── 工具调用与结果
├── 可能还有下一个步骤
└── 轮次结束
```

如果一句话概括：**轮次是用户视角的一次工作，步骤是系统视角的一次模型调用。**
