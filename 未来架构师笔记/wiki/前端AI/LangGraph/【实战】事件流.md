Agent 一次运行可能持续几十秒，中间有思考、工具调用、子代理输出。如果等全部结束再返回，前端只能一直转圈。**事件流（Streaming）**把过程按块推给调用方，实现"边想边显示"。

## 1. 一个最小的流式调用

```python
stream = client.runs.stream(
    thread_id=thread_id,
    assistant_id=assistant_id,
    input={"messages": [{"role": "user", "content": "写一首夏天的诗"}]},
    stream_mode=["values", "checkpoints", "updates", "messages-tuple"],
    stream_subgraphs=True,
    version="v1",
)

async for chunk in stream:
    print(chunk.event, chunk.data)
```

关键参数：

| 参数               | 作用                       |
| ------------------ | -------------------------- |
| `stream_mode`      | 要订阅哪些事件类型，可多选 |
| `stream_subgraphs` | 是否同时输出子图内部的事件 |
| `version`          | 事件格式版本，当前用 `v1`  |

## 2. stream_mode 都有什么

| 模式             | 内容                              | 典型用途                     |
| ---------------- | --------------------------------- | ---------------------------- |
| `values`         | 每个超步后的完整图状态            | 保存最终结果、渲染整体状态   |
| `updates`        | 节点返回的增量更新                | 显示"哪个节点产出了什么"     |
| `messages-tuple` | 模型消息块（`(chunk, metadata)`） | 逐字输出、展示思考与工具调用 |
| `checkpoints`    | 检查点事件                        | 进度条、审计、调试           |

实际项目通常同时订阅多种，用事件名分流。

## 3. 事件长什么样

流式块里最重要的字段是 `event` 和 `data`。`event` 可能是 `values`、`updates`、`messages` 等；子图事件会带命名空间，格式形如：

```text
messages|child:graph
```

前半段是事件类型，后半段是子图命名空间。没有命名空间就是根图。

`messages-tuple` 的 `data` 是二元组：第一个元素是消息块，第二个是元数据，里面能找到 `langgraph_node`（哪个节点产生的）。

## 4. 从消息块里分离思考、正文与工具调用

一个实用的打印器：只在 `model` 节点产生消息时处理，按内容块类型切换标题，并把子图输出单独标出来。

```python
msg_type_map = {"thinking": "思考：", "text": "回复：", "tool_use": "调用工具："}

def print_message(chunk):
    event_type, _, namespace = chunk.event.partition("|")
    if event_type != "messages":
        return
    if chunk.data[1]["langgraph_node"] != "model":
        return

    source = namespace or "root"
    for block in chunk.data[0]["content"]:
        kind = block["type"]
        if kind in msg_type_map:
            title = msg_type_map[kind]
            if kind == "tool_use":
                title += block["name"]
            if namespace and namespace not in announced:
                announced.add(namespace)
                print(f"\n子代理：{title}")
            else:
                print(f"\n{title}")
        if kind == "text":
            print(block["text"], end="", flush=True)
```

要点：

- `thinking` 是推理内容，`text` 是给用户看的正文，二者要分开渲染；
- `tool_use` 只需要显示工具名，不必把参数直接展示给用户；
- 用 `flush=True` 才能逐字刷新；
- 同时收集中间块，方便最后拼成完整结果。

消息块的结构与来源见 [[【基础】模型接入与消息体系]]。

## 5. 中断之后继续流式

流式接口同样支持恢复中断：把 `input` 换成 `command` 即可。

```python
from langgraph_sdk.schema import Command as SDKCommand

stream = client.runs.stream(
    thread_id=thread_id,
    assistant_id=assistant_id,
    command=SDKCommand(resume={"interrupt_id": "清新淡雅"}),
    stream_mode=["values", "updates", "messages-tuple"],
    stream_subgraphs=True,
    version="v1",
)
```

中断与恢复的完整流程见 [[【实战】Command、中断与人在回路]]。运行本身的创建与查询见 [[【实战】Run API]]。
