### 1.2 更新 state

`state.py`

```py
video_jobs: NotRequired[list[dict]]
video_results: Annotated[dict[str, dict], operator.or_]
video_error: NotRequired[str]
final_video_path: NotRequired[str]
```

**video_jobs**

`video_jobs` 是本轮要生成的镜头任务单，由 `prepare_videos` 在用户确认开拍、并且本机有 FFmpeg 之后一次性写入。

每一项大致是：

```py
{
  "shot_id": "shot_01",
  "order": 1,
  "folder": "a1b2c3...",          # 本批视频的目录名
  "prompt": shot.video_prompt,    # 交给视频模型的镜头提示词
  "duration": 4,                  # shot.duration_seconds
  "ratio": "9:16",                # 任务上的画幅
  "frames": [                     # 已批准的首帧、尾帧，顺序固定
      {"local_path": "outputs/images/...png", "content_sha256": "..."},
      {"local_path": "outputs/images/...png", "content_sha256": "..."},
  ],
}
```

**video_results**

`video_results` 是各镜头子图跑完后合并回来的结果。键是 `shot_id`，值固定三个字段：

```py
{
  "shot_01": {
      "task_id": "方舟返回的任务 ID，提交失败时为 null",
      "path": "outputs/videos/{folder}/shot_01.mp4",  # 相对项目根目录；失败时为 null
      "error": null,
    	# 失败时是「提交失败：…」「查询失败：…」「查询结果：…」「达到查询次数上限…」「下载失败：…」
  }
}
```

该字段使用 `operator.or_` 做归并：多个镜头并行返回各自的单键字典，按键合并进父状态。

1. 成功看 `path` 有没有值；
2. 单镜头失败写在这里的 `error`，不会单独写到 `video_error`。

**video_error**

`video_error` 是 **<u>整批</u>** 失败时的一句说明。只在父图上出现，例如：

- 开拍前找不到 FFmpeg：`"找不到 FFmpeg"`（此时还没有 `video_jobs`）
- 有镜头没有 `path`：`"分镜未完成：shot_01、shot_03"`
- FFmpeg 拼接失败

**final_video_path**

`final_video_path` 只在全部镜头都有 `path`、并且拼接成功时写入。值是相对项目根目录的成片路径，形如 `outputs/videos/{folder}/final.mp4`

### 1.3 service

简化实现，只实现一个 `VideoService`，直接调用方舟。省略：

1. 协议
2. fake实现
3. 按环境变量切换供应商

另外 `VideoService` 里面调方舟主要是提交视频生成任务以及查询状态，下载 mp4 和视频合成是在 `VideoService` 内部完成的。

新增 `video/video_service.py` 文件，完整代码如下：

```py
"""方舟视频任务与本地 MP4。"""

import base64
import os
import shutil
import subprocess
from pathlib import Path
from urllib.request import urlopen

from arkruntime import Ark

from server.schema.image_reference import ImageReference
from server.storage import AssetStore


class VideoService:
    def __init__(self, store: AssetStore):
        self.store = store

    def submit(self, job: dict) -> str:
        content = [{"type": "text", "text": job["prompt"]}]
        for role, frame in zip(("first_frame", "last_frame"), job["frames"]):
            image = self.store.read_reference(ImageReference.model_validate(frame))
            mime = "png" if image.startswith(b"\x89PNG") else (
                "jpeg" if image.startswith(b"\xff\xd8\xff") else "webp"
            )
            content.append({
                "type": "image_url",
                "role": role,
                "image_url": {"url": f"data:image/{mime};base64,{base64.b64encode(image).decode()}"},
            })
        with self._client() as client:
            task = client.content_generation.tasks.create(
                model=os.environ["ARK_VIDEO_MODEL"],
                content=content,
                ratio=job["ratio"],
                duration=job["duration"],
                resolution=os.getenv("VIDEO_RESOLUTION", "720p"),
                generate_audio=False,
            )
        return task.id

    def query(self, task_id: str):
        with self._client() as client:
            return client.content_generation.tasks.get(task_id)

    @staticmethod
    def _client():
        return Ark.volc(api_key=os.environ["ARK_API_KEY"], timeout=60, max_retries=0)

    def download(self, url: str, folder: str, shot_id: str) -> str:
        directory = self.store.output_root / "videos" / folder
        directory.mkdir(parents=True, exist_ok=True)
        path = directory / f"{shot_id}.mp4"
        partial = path.with_suffix(".part")
        try:
            with urlopen(url, timeout=60) as response, partial.open("wb") as file:
                shutil.copyfileobj(response, file)
            partial.replace(path)
        finally:
            partial.unlink(missing_ok=True)
        return path.relative_to(self.store.project_root).as_posix()

    def compose(self, folder: str, paths: list[str]) -> str:
        directory = self.store.output_root / "videos" / folder
        manifest = directory / "concat.txt"
        manifest.write_text("".join(f"file '{Path(path).name}'\n" for path in paths))
        subprocess.run(
            ["ffmpeg", "-nostdin", "-hide_banner", "-loglevel", "error", "-y",
             "-f", "concat", "-safe", "1", "-i", manifest.name,
             "-c", "copy", "final.part.mp4"],
            cwd=directory, check=True, capture_output=True, text=True,
        )
        final = directory / "final.mp4"
        (directory / "final.part.mp4").replace(final)
        return final.relative_to(self.store.project_root).as_posix()
```

**注意点1**

```py
for role, frame in zip(("first_frame", "last_frame"), job["frames"]):
  ...
```

`zip` 是 python 里面的库函数，作用是按相同位置把多个序列配成一组一组。

序列长度不同时，它在最短的那个结束处停下。例如

```py
roles = ("first_frame", "last_frame")
frames = ["首帧.png", "尾帧.png"]

for role, frame in zip(roles, frames):
    print(role, frame)
```

输出是：

```
first_frame 首帧.png
last_frame 尾帧.png
```

这里每次循环拿出一对：`roles` 的第 1 项配 `frames` 的第 1 项，第 2 项配第 2 项。

回头再看项目里面的代码：

```python
zip(("first_frame", "last_frame"), job["frames"])
```

`job` 的形式如下：

```py
job = {
  "prompt": "4 秒镜头：林晚把热汤从身前推到摊位边缘；镜头保持固定。",
  "duration": 4,
  "ratio": "9:16",
  "frames": [
      {"local_path": "outputs/images/shot_start/...", "content_sha256": "ab12..."},
      {"local_path": "outputs/images/shot_end/...", "content_sha256": "cd34..."},
  ],
}
```

两次循环分别是：

- 第 1 次：`role = "first_frame"`，`frame = frames[0]`，也就是已批准的首帧
- 第 2 次：`role = "last_frame"`，`frame = frames[1]`，也就是已批准的尾帧

**注意点2**

`compose` 方法用于合成分镜视频，用到了 `ffmpeg`，这是一个工具，需要在本机安装。

```bash

```

#### 1.4.1 4-1. `generation.py`

该节点对应一个子图：

<img src="https://picgo-1300696809.cos.ap-beijing.myqcloud.com/obsidian/1794730192850_2026-11-10-070401.png" alt="image-20261110150401168" style="zoom:50%;" />

这里重点说一下 `wait` 和 `query`：

`query` 只向方舟查一次，自己不等待。

1. 查完后按结果走三条路：已经生成好并拿到地址，就去 `download`；
2. 任务失败、被取消，或查询次数到达 30 次，就进入 `__end__`；
3. 还在排队或生成，就进入 `wait`。

`wait` 把这一镜的进度交出去，暂停时外面看到的例如：

```py
{
  "type": "video_wait",
  "shot_id": "shot_01",
  "task_id": "cgt-20261110140530-abcde",
  "status": "running",
  "queries": 3
}
```

推荐客户端传 `"continue"`，但其实不检查用户输入的文字，因为恢复后固定走回 `query`，再查同一次任务。

因此还没完成的镜头会沿 `query` → `wait` → `query` 反复走，下一次看到的 `queries` 变成 `4`。

5 个镜头就是 5 份同时运行的子图。某一轮里有几个镜头还没好，就会同时出现几个中断。

完整代码如下：

```py
"""单分镜视频任务的提交、查询、等待和下载节点。"""

from typing import TypedDict

from arkruntime._exceptions import ArkError
from langgraph.types import interrupt

from server.services import VideoService


class ShotVideoState(TypedDict, total=False):
    job: dict
    task_id: str
    queries: int
    status: str
    video_url: str
    video_results: dict[str, dict]


class ShotVideoOutput(TypedDict):
    video_results: dict[str, dict]


def shot_video_result(state, *, path=None, error=None):
    shot_id = state["job"]["shot_id"]
    return {"video_results": {shot_id: {
        "task_id": state.get("task_id"), "path": path, "error": error,
    }}}


def make_submit_shot_video(service: VideoService):
    """通过闭包注入视频服务。"""

    def submit(state):
        try:
            return {"task_id": service.submit(state["job"]), "queries": 0}
        except (ArkError, OSError, ValueError, KeyError) as exc:
            return shot_video_result(state, error=f"提交失败：{type(exc).__name__}")

    return submit


def make_query_shot_video(service: VideoService, max_queries: int = 30):
    """通过闭包注入视频服务和查询次数上限。"""

    def query(state):
        try:
            response = service.query(state["task_id"])
        except (ArkError, OSError) as exc:
            return shot_video_result(state, error=f"查询失败：{type(exc).__name__}")
        update = {"queries": state["queries"] + 1, "status": response.status}
        if response.status == "succeeded" and response.content and response.content.video_url:
            return {**update, "video_url": response.content.video_url}
        if response.status not in ("queued", "running"):
            error = getattr(response, "error", None)
            code = getattr(error, "code", None)
            return {**update, **shot_video_result(state, error=f"查询结果：{response.status} {code or ''}".strip())}
        if update["queries"] >= max_queries:
            return {**update, **shot_video_result(state, error="达到查询次数上限，停止跟踪")}
        return update

    return query


def wait_shot_video(state):
    interrupt({
        "type": "video_wait",
        "shot_id": state["job"]["shot_id"],
        "task_id": state["task_id"],
        "status": state["status"],
        "queries": state["queries"],
    })
    return {}


def make_download_shot_video(service: VideoService):
    """通过闭包注入视频服务。"""

    def download(state):
        job = state["job"]
        try:
            path = service.download(state["video_url"], job["folder"], job["shot_id"])
        except OSError as exc:
            return shot_video_result(state, error=f"下载失败：{type(exc).__name__}")
        return shot_video_result(state, path=path)

    return download
```

#### 1.4.2 4-2. `batch.py`

```py
"""派发批准的镜头，汇总后生成整部漫剧。"""

import shutil
from subprocess import CalledProcessError
from uuid import uuid4

from langgraph.graph import END
from langgraph.types import Send, interrupt

from server.schema.shot_frame_task import ShotFrameTask
from server.services import VideoService


def prepare_videos(state):
    decision = interrupt({"type": "video_start", "shots": len(state["frame_tasks"])})
    if decision != "start":
        return {"current_stage": "video_cancelled"}
    if shutil.which("ffmpeg") is None:
        return {"current_stage": "video_failed", "video_error": "找不到 FFmpeg"}
    folder = uuid4().hex
    jobs = []
    for raw in state["frame_tasks"]:
        task = ShotFrameTask.model_validate(raw)
        shot = task.shot
        frames = [
            state["approved_frames"][f"{shot.shot_id}:{kind}"]
            for kind in ("start", "end")
        ]
        jobs.append(
            {
                "shot_id": shot.shot_id,
                "order": shot.order,
                "folder": folder,
                "prompt": shot.video_prompt,
                "duration": shot.duration_seconds,
                "ratio": task.aspect_ratio,
                "frames": [
                    {k: frame[k] for k in ("local_path", "content_sha256")}
                    for frame in frames
                ],
            }
        )
    return {"current_stage": "generating_videos", "video_jobs": jobs}


def dispatch_videos(state):
    if state["current_stage"] != "generating_videos":
        return END
    return [Send("generate_video", {"job": job}) for job in state["video_jobs"]]


def make_compose_videos(service: VideoService):
    def compose_videos(state):
        jobs = sorted(state["video_jobs"], key=lambda job: job["order"])
        results = state.get("video_results", {})
        failed = [
            job["shot_id"]
            for job in jobs
            if not results.get(job["shot_id"], {}).get("path")
        ]
        if failed:
            return {
                "current_stage": "video_failed",
                "video_error": "分镜未完成：" + "、".join(failed),
            }
        try:
            path = service.compose(
                jobs[0]["folder"], [results[job["shot_id"]]["path"] for job in jobs]
            )
        except (CalledProcessError, OSError) as exc:
            return {
                "current_stage": "video_failed",
                "video_error": getattr(exc, "stderr", None) or str(exc),
            }
        return {"current_stage": "video_ready", "final_video_path": path}

    return compose_videos
```

### 1.5 图的编排

#### 1.5.1 5-1. 生成视频子图

在 `workflows` 目录下，新增 `shot_video.py` 文件，该文件用于负责单镜头视频子图。

代码如下：

```py
"""单镜头视频子图：提交、查询、等待和下载。"""

from langgraph.graph import END, START, StateGraph

from server.nodes import (
    ShotVideoOutput,
    ShotVideoState,
    make_download_shot_video,
    make_query_shot_video,
    make_submit_shot_video,
    wait_shot_video,
)
from server.services import VideoService


def route_after_submit(state: ShotVideoState):
    return END if state.get("video_results") else "query"


def route_after_query(state: ShotVideoState):
    if state.get("video_results"):
        return END
    return "download" if state.get("video_url") else "wait"


def build_shot_video_graph(service: VideoService, max_queries: int = 30):
    """第3张子图，负责一个镜头从提交到下载的过程。"""

    builder = StateGraph(ShotVideoState, output_schema=ShotVideoOutput)
    builder.add_node("submit", make_submit_shot_video(service))
    builder.add_node("query", make_query_shot_video(service, max_queries))
    builder.add_node("wait", wait_shot_video)
    builder.add_node("download", make_download_shot_video(service))

    builder.add_edge(START, "submit")
    builder.add_conditional_edges("submit", route_after_submit, ["query", END])
    builder.add_conditional_edges(
        "query", route_after_query, ["download", "wait", END]
    )
    builder.add_edge("wait", "query")
    builder.add_edge("download", END)
    return builder.compile()

```

用户对首尾帧审核通过后，会进入到视频生成阶段。

用户输入 `start` 确认开始生成视频，之后会向火山提交 5 个分镜生成任务，用户可以输入 `continue` 查询当前分镜生成情况。 恢复后子图走 `wait -> query`，向方舟再查一次这个任务：

1. `succeeded` 且有 `video_url`：去 `download`，这一镜不再进入 `wait`
2. `failed` 或 `cancelled`：写入错误并结束，不再进入 wait
3. 查询次数到达 `30`：停止跟踪，不再进入 wait
4. 仍是 queued 或 running：再次进入 wait。下一次看到的 queries 会 +1
