模型只会"说"它想调用什么工具，真正执行要靠代码。LangGraph 里这件事实现在**工具节点**中：模型返回 `tool_calls`，工具节点负责逐个执行，再把 `ToolMessage` 写回消息列表。

工具的底层语义与手写 JSON Schema 的做法见 [[【实战】Tool Calling]]，本文只讲 LangGraph 场景下的用法。

## 1. 用 @tool 定义工具

```python
from langchain.tools import tool

@tool
def get_weather(city: str):
    """获取某个城市的天气，返回摄氏温度。

    参数：
    - city: 城市名称
    """
    return {"city_name": city, "temperature": 25, "weather": "cloudy"}
```

`@tool` 做了三件事：

1. 把普通函数包装成 `Runnable`，因此可以直接 `invoke` / `ainvoke`；
2. 从函数签名和文档字符串生成 `tool_call_schema`，供模型理解参数；
3. 保留 `name`、`description`，作为绑定工具时发给模型的元数据。

```python
get_weather.tool_call_schema.model_json_schema()
get_weather.invoke({"city": "北京"})
```

### 1.1 用 Pydantic 精确约束参数

当参数需要类型校验、默认值、字段说明时，传入 `args_schema`：

```python
from pydantic import BaseModel, Field

class WeatherInput(BaseModel):
    """查询天气的输入参数"""
    city: str = Field(description="城市名称")

@tool(args_schema=WeatherInput)
def get_weather(city: str):
    """获取某个城市的天气"""
    return {"city_name": city, "temperature": 25}
```

这样模型看到的是完整的 JSON Schema，工具执行前也会做参数校验，错误能在调用模型之后立刻暴露。

## 2. 绑定工具

工具本身不会自动生效，需要在调用模型时绑定：

```python
model_with_tools = model.bind_tools([get_weather])
response = await model_with_tools.ainvoke("伦敦天气如何？")
response.tool_calls
```

`tool_calls` 的结构大致是：

```python
[{"id": "call_123", "name": "get_weather", "args": {"city": "伦敦"}}]
```

## 3. 工具节点做什么

工具节点（`ToolNode`）接收当前状态里的消息，找到最后一条 `AIMessage` 的 `tool_calls`，逐个执行，然后把每个结果包装成 `ToolMessage` 追加回状态。

```python
from langgraph.prebuilt import ToolNode

builder.add_node("tools", ToolNode([get_weather]))
builder.add_conditional_edges("model", should_continue, ["tools", END])
builder.add_edge("tools", "model")
```

这条 `model → tools → model` 的回路，就是 LangGraph 版的 ReAct 循环。循环工程的相关讨论见 [[【概念】循环工程]]。

## 4. 常用工具

Agent 常用的工具可以直接用现成封装：

```python
from langgraph_python.tools.web import web_search, fetch_url

await web_search.ainvoke({"query": "黄金价格"})
await fetch_url.ainvoke({"urls": ["https://example.com"]})
```

- `web_search`：面向 LLM 的搜索，返回结构化结果而不是整页 HTML；
- `fetch_url`：抓取指定页面并抽取正文，避免把导航、广告塞进上下文。

搜索工具的设计动机见 [[【实战】Agent 接入搜索引擎]]；跨进程的工具协议见 [[【基础】MCP 协议]]。
