### **一、 情侣点单系统 - 完整思维导图**

这个思维导图涵盖了从前后端到三个客户端的完整功能模块。

**核心系统 (Next.js 后端 + 通用功能)**
1.  **用户认证**
    *   邮箱/用户名注册
    *   登录 / 登出
    *   JWT Token 管理
2.  **情侣关系管理**
    *   发起绑定（生成唯一邀请码）
    *   通过邀请码绑定
    *   解除绑定
    *   获取伴侣信息
3.  **菜品管理**
    *   创建菜品（名称、图片、描述、难度、预估时间）
    *   读取菜品（列表、详情）
    *   更新菜品
    *   删除菜品
    *   菜品分类（如：早餐、午餐、晚餐、甜点）
4.  **点单系统**
    *   发起点单（选择菜品、指定日期、添加备注）
    *   查看当前/历史点单
    *   伴侣确认/完成点单
    *   点单状态流（已下单 -> 已接收 -> 制作中 -> 已完成）
5.  **AI 烹饪助手**
    *   集成 OpenAI / 文心一言等 API
    *   根据现有食材生成菜谱
    *   根据菜名生成详细步骤和技巧
    *   对话式烹饪问答
6.  **数据存储 (数据库设计)**
    *   `users` 表： id, name, email, avatar, partnerId
    *   `relationships` 表： id, user1Id, user2Id, inviteCode, status
    *   `dishes` 表： id, name, imageUrl, description, difficulty, time, category, creatorId
    *   `orders` 表： id, dishId, requesterId, receiverId, status, scheduledDate, note
    *   `ai_cooking_sessions` 表： id, userId, prompt, response

---

**移动端 App (React Native)**
1.  **登录/注册页**
2.  **主页 / 仪表盘**
    *   今日待办点单
    *   伴侣状态
    *   快速操作入口
3.  **点单模块**
    *   `点单广场`： 浏览所有菜品
    *   `发起点单`： 选择菜品、日期、写备注
    *   `我的点单`： 查看我发起和接收的点单列表及状态
4.  **菜品模块**
    *   `菜品库`： 查看所有已上传的菜品
    *   `上传菜品`： 表单上传新菜品
5.  **情侣空间**
    *   伴侣信息展示
    *   绑定/解绑伴侣
    *   恋爱日记/纪念日（可选扩展）
6.  **AI 厨房**
    *   输入食材，生成菜谱
    *   与AI对话，询问做法
7.  **个人中心**
    *   个人信息修改
    *   设置

---

**PC 管理系统 (React)**
1.  **登录页**
2.  **数据总览**
    *   用户数、点单数、热门菜品统计图表
3.  **用户管理**
    *   查看所有用户列表
    *   禁用/启用用户
4.  **菜品管理**
    *   所有菜品的 CRUD 操作
    *   审核用户上传的菜品
5.  **点单管理**
    *   查看所有点单记录
    *   手动修改点单状态
6.  **系统设置**
    *   AI API 密钥配置
    *   全局开关

---

**大屏展示端 (Vue)**
1.  **情侣主页**
    *   浪漫背景，双方头像和昵称
    *   大幅展示 `今日特供点单`（最新或指定的点单）
    *   点单的菜品大图、状态动画（如“爱心制作中...”）
2.  **动态时间线**
    *   以时间流形式展示历史的点单记录
    *   带有照片和文字的甜蜜瞬间
3.  **数据可视化**
    *   本月点单统计（柱状图）
    *   最常点菜品排行榜（饼图）
4.  **全屏模式**
    *   自动轮播展示以上视图

### **二、 页面样式与 UI/UX 设计**

这里将描述每个核心页面的布局、关键元素和设计风格建议。

**设计风格基调：**
*   **主色调：** 浪漫的粉红色 (`#ff4d94`)、温暖的橙色 (`#ff7e5f`)、纯洁的白色 (`#ffffff`)。
*   **辅助色：** 浅灰色 (`#f5f5f5`)、深灰色 (`#333333`) 用于文字。
*   **字体：** 无衬线字体，如 `PingFang SC`, `Helvetica Neue`, `Inter`， 标题可使用手写体字体（如 `Dancing Script`）增加浪漫感。
*   **设计元素：** 大量使用圆角、卡片阴影、心形图标、柔和的渐变背景。

---

#### **A. 移动端 (React Native) 页面设计**

**1. 登录/注册页**
*   **布局：** 居中垂直布局。
*   **上方：** App Logo（一个可爱的心形厨帽图标）和 App 名称（如“Couple's Menu”）。
*   **中部：** 两个输入框（邮箱、密码），圆角设计。
*   **底部：** 一个填充主色的“登录”按钮。下方有“还没有账号？立即注册”的链接。
*   **背景：** 极简的白色或非常浅的粉色渐变。

**2. 主页 / 仪表盘**
*   **顶部状态栏：** 显示“欢迎回来，[用户名]”和一个消息图标。
*   **核心卡片1 - 今日点单：**
    *   标题：“今日点单”
    *   内容：如果有点单，显示菜品图、名称、状态（“待接收”、“制作中”）。如果没有，显示“今天还没有点单哦，快去点一个吧！”和一个“+”按钮。
*   **核心卡片2 - 我的伴侣：**
    *   显示伴侣的头像和昵称，以及状态（如“在线”、“忙碌”）。
*   **底部导航栏 (Tab Bar)：** 图标 + 文字，包含 `首页`、`点单`、`菜品`、`我们`、`个人中心`。

**3. 点单广场页**
*   **顶部：** 搜索栏和分类筛选器（早餐、午餐等）。
*   **主体：** 瀑布流或网格布局的菜品卡片。
*   **菜品卡片：**
    *   菜品大图（占卡片的70%）
    *   底部：菜品名称、难度图标（一颗辣椒代表难度）、收藏按钮（心形）。
*   **悬浮按钮 (FAB)：** 右下角的“+”号按钮，点击跳转到“发起点单”页。

**4. 发起点单页**
*   **步骤式设计：**
    1.  **选择菜品：** 一个模态弹层，从菜品库中选择。
    2.  **指定日期：** 日期选择器，默认今天。
    3.  **添加备注：** 多行文本输入框，placeholder: “可以少辣吗？或者给我一个惊喜！”
*   **底部：** 一个大的“为亲爱的下单”按钮。

**5. AI 厨房页**
*   **顶部：** 标题“你的AI厨房助手”。
*   **输入区：** 一个大的文本输入框，placeholder: “我有鸡蛋、番茄和米饭，能做什么？”
*   **发送按钮：** 位于输入框右侧。
*   **对话区：** 一个类似聊天界面的区域，用户问题和AI回复以气泡形式展示。AI回复可以很好地格式化步骤和材料列表。

---

#### **B. PC 管理系统 (React) 页面设计**

**1. 数据总览页**
*   **布局：** 顶部数据卡片 + 下方图表。
*   **顶部卡片 (4个)：** 总用户数、总点单数、今日点单数、活跃情侣对数。
*   **下方左：** 折线图 - 近30天点单趋势。
*   **下方右：** 饼图 - 热门菜品分类占比。
*   **设计风格：** 采用 Ant Design 或 Material-UI 等专业UI库，布局清晰，数据突出。

**2. 菜品管理页**
*   **顶部工具栏：** “新增菜品”按钮、搜索框、筛选下拉框。
*   **主体：** 表格形式。
*   **表格列：** 菜品ID、缩略图、菜品名称、分类、创建者、状态（上架/下架）、操作（编辑、删除）。
*   **点击“编辑”** 会弹出表单模态框。

---

#### **C. 大屏展示端 (Vue) 页面设计**

**1. 情侣主页**
*   **背景：** 全屏高清的、模糊处理的浪漫背景图（如一起做饭的场景）。
*   **顶部中央：** 双方头像（用心形图案连接）和昵称，如 `❤️ 小明 & 小红 ❤️`。
*   **中央主体：**
    *   一个大卡片，背景半透明毛玻璃效果。
    *   大字标题：“今日特供”
    *   超大菜品图片。
    *   菜品名称和状态，状态用动态的爱心图标点缀。
    *   下方可有一句浪漫语录，如“爱就是在一起，吃很多很多顿饭”。
*   **底部：** 一个不显眼的导航栏，提示当前页面（如“主页”、“时间线”、“数据”）。

**2. 动态时间线页**
*   **布局：** 垂直时间线，居中显示。
*   **每个节点：** 一个圆形图标（爱心），右侧是内容卡片。
*   **内容卡片：** 日期、点单的菜品图、简单的文字描述（如“小红为小明点了爱心早餐”）。
*   **动画：** 节点和卡片可以有淡入和向上滑入的动画效果。

**3. 数据可视化页**
*   **布局：** 将屏幕分为左右或上下两个主要区域。
*   **左区：** 3D柱状图，展示“本月点单统计”，双方用不同颜色区分。
*   **右区：** 甜甜圈图，展示“最爱菜品排行榜”。
*   **设计：** 使用 ECharts 或 D3.js，配色明亮活泼，动画流畅。

### **技术实现建议**

1.  **状态管理：**
    *   React/RN: Redux Toolkit 或 Zustand。
    *   Vue: Pinia。
2.  **UI 库：**
    *   RN: React Native Paper 或 React Native Elements。
    *   React: Ant Design 或 Material-UI。
    *   Vue: Element Plus 或 Vant。
3.  **图表库：**
    *   PC & 大屏： ECharts (功能强大) 或 Chart.js (轻量易用)。
4.  **通信：**
    *   前端与 Next.js API 使用 `axios` 或 `fetch`。
    *   大屏和PC管理端如需实时更新（如点单状态改变），可使用 WebSocket。
